## 1. Argus: A General-Purpose Agentic Runtime for Long-Horizon Reasoning

**Topics:** GUI Agent, Long-Horizon Reasoning, Agentic Runtime, Self-Evolution, Verification
**Authors:** Boxiu Li, Zimo Wen, Yijia Fan, Junxiang Lei, Sufeng Guo, Jiaao Wu, Ruize Tang, Mukai Li, Yifei Shen, Xiaoyu Chen, Wanbo Zhang, Runjing Gu, Yifei Gao, Yuheng Wu, Xuyao Huang, Zelong Zhao, Jiachen Zhang, Shibo Hu, Hangxi Guo, Yilin Chen, Yuzhe Zhang, Fan Yang, Chuan Wen, Xian Zhang, Xuanhe Zhou, Zhijie Deng
**Venue / Year:** arXiv:2608.05144v1, Aug 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.05144v1) | [PDF](http://arxiv.org/pdf/2608.05144v1.pdf) | [Code](https://github.com/lbx154/Argus)

### 1. 一句话结论

Argus 是一个持久化、自演化的通用智能体运行时，通过验证门控的持久化和转向机制，在固定模型权重下实现长时域推理，在 SWE-Bench Pro 上达到约 78% 准确率，相比 Direct Copilot 的 59% 有显著提升。

### 2. 为什么重要

该工作解决了长时域推理中目标漂移与失败合理化的核心矛盾，提出了一种可验证的转向机制，使得智能体能够在证据支持下调整目标或路径，同时保持可审计性。这为构建可靠、可积累的自主研究系统提供了关键基础设施。

### 3. 研究问题

1. 如何设计一个智能体运行时，使其能够在长时域推理中根据证据持久化当前路径或转向新路径，同时避免目标漂移？
2. 验证门控的运行时自演化机制能否在固定模型权重下，通过持久化状态和策略实现跨任务的能力积累和成本降低？

### 4. 背景与问题设定

长时域推理任务中，初始目标往往不完整或存在错误，智能体需要根据执行过程中的证据调整目标或方法。然而，允许转向可能导致目标漂移，即智能体因失败而合理化地降低目标。现有系统（如 ReAct、SWE-agent）通常固定目标并优化执行，但无法处理目标本身需要修正的情况。Argus 提出通过验证门控的转向机制来解决这一矛盾，确保每次转向都有证据支持、经过角色审核并记录在案。

### 5. 方法概览

- 任务 / 环境: 七个基准测试环境，包括 SWE-Bench Pro（软件修复）、AARRI-Bench（研究助手任务）、GPU 内核优化、语言模型训练、数学数据合成等。
- 变量 / 干预设计: Argus 运行时包含四个角色：Manager（锚定目标）、Planner（选择工作单元）、Engineer（执行与评估）、Reviewer（审查工件与输出）。任务被分解为有界任务（bounded missions），在持久项目状态上执行。运行时通过验证门控机制允许目标或路径的调整，调整需经过角色审核和证据支持。
- 评价指标: 各基准的原生指标，如 SWE-Bench Pro 准确率、AARRI-Bench 准确率、数学数据合成差距、令牌使用量、主动工作流时间等。
- 模型比较: 与 Direct Copilot 在 SWE-Bench Pro 上对比，Argus 准确率约 78% vs 59%，令牌使用量为 1.41 倍。
- 我的理解: Argus 的核心创新在于将验证作为转向的准入机制，而非事后质量过滤。通过分离稳定用户意图与操作目标、约束和验证标准，并引入角色所有权和审计跟踪，使得运行时能够在固定模型权重下自演化，积累可复用的技能、验证器和路由决策。

### 6. 关键发现

- 验证门控的运行时自演化降低后续任务成本: 在 SWE-Bench Pro 的成熟波次中，每个任务的解决输入令牌使用量减少 21%，主动工作流时间减少 15%，同时记录了 34 次验证器恢复和 22 次严格审查循环救援。
- Argus 在多个基准上达到或超越现有水平: SWE-Bench Pro 准确率约 78%（Direct Copilot 为 59%），AARRI-Bench 准确率 76.8%，数学数据合成差距 28.0 分，GPU 内核和语言模型训练结果具有竞争力。
- 运行时拒绝在目标不明确时继续执行: 专家用户报告，Argus 的实际价值部分在于其停止点：系统拒绝在未明确目标上继续，从而揭示用户未陈述的约束。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: Argus 的设计表明，智能体系统应内置验证机制以区分合理转向与失败合理化，从而在长时域任务中保持可靠性。
- 对 Skill: 验证门控的技能积累机制使得智能体能够跨任务复用已验证的技能，降低后续任务成本。
- 对 Memory: 持久化状态不仅存储成功经验，还保留失败路径和验证结果，为未来决策提供更丰富的上下文。
- 对评测: 评估应关注智能体在目标调整过程中的行为，而不仅仅是最终结果，以衡量其鲁棒性和适应性。

### 11. 局限性

- 论文未提供受控的学习消融实验，运行时自演化的纵向证据是观察性的，而非因果性的。
- 基准测试中使用的 GPT-5.5 模型可能限制了泛化性，其他模型上的表现未知。
- 专家用户报告的价值部分基于定性观察，缺乏公开的前瞻性用户研究结果。

### 12. 我的看法 / 个人笔记

Argus 提出了一种优雅的解决方案来应对长时域推理中的核心挑战——如何在允许目标调整的同时避免漂移。验证门控机制和角色分离的设计既实用又具有理论深度。然而，其有效性高度依赖于验证器的质量和任务原生验证的可用性，在缺乏明确验证标准的开放域任务中可能受限。未来工作可探索如何自动生成或学习验证器，以及如何将运行时自演化与模型微调相结合。

## 2. Skill-Use: Can LLMs Actually Use Skills in Agentic Harnesses?

**Topics:** LLM Agent, Skill-Use, Benchmark, Progressive Disclosure
**Authors:** Jinyi Han, Yuanjian Xu, Ying Liao, Xinyi Wang, Zishang Jiang, Zixiang Di, Fanyang Lu, Zhichao Hu, Yanghua Xiao
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.04828v1) | [PDF](http://arxiv.org/pdf/2608.04828v1.pdf) | [Code](https://github.com/JinyiHan99/Skill-Use-Bench)

### 1. 一句话结论

最强配置（GPT-5.5 + Claude Code）的Skill-Use综合得分仅0.613，触发与合规执行是独立瓶颈，且技能使用能力高度依赖智能体框架而非模型固有属性。

### 2. 为什么重要

该研究首次将技能使用分解为触发、合规和边界三个维度，在渐进式披露场景下系统评估智能体自主识别和应用技能的能力，揭示了现有评估忽略的关键瓶颈，对构建可靠智能体系统具有重要指导意义。

### 3. 研究问题

1. LLM智能体能否在仅看到技能名称和简短描述时自主识别并检索相关技能？
2. 智能体在检索到技能后，能否忠实遵循其规定的操作流程并避免禁止操作？
3. 技能使用能力是模型的固有属性，还是依赖于智能体框架？

### 4. 背景与问题设定

LLM智能体越来越依赖技能文档（结构化文档，规定何时行动、遵循什么流程、允许哪些工具）。现有评估要么判断技能质量或其对任务成功的贡献，要么预加载完整技能文档，忽略了智能体自主识别和检索技能的过程。Skill-Use基准填补了这一空白，在渐进式披露机制下评估智能体的技能使用能力。

### 5. 方法概览

- 任务 / 环境: 隔离的Docker沙箱，提供真实文件、工具和依赖，智能体可执行读取文件、调用工具、编辑工件等操作。
- 变量 / 干预设计: 智能体初始仅接收任务、环境和技能元数据（名称、简短描述、文件路径），必须自主判断技能相关性并检索完整流程。评估分三个维度：触发（是否检索技能）、合规（是否遵循规定流程）、边界（是否避免禁止操作）。
- 评价指标: Skill-Use (SU) 得分 = 触发 × (0.7×合规 + 0.3×边界)，其中α=0.7赋予合规更大权重，因其衡量技能规定流程的执行。此外报告触发率、合规率、边界率及其在触发轨迹上的条件版本。
- 模型比较: 评估8个LLM（Claude Opus 4.7/4.8, GPT-5.5, DeepSeek-V4-Pro, GLM-5.1, MiniMax-M3, Kimi-K2.6, Qwen3.6-Max）在Claude Code和Codex两个智能体框架下的表现。
- 我的理解: 该方法通过渐进式披露模拟真实使用场景，将技能使用分解为识别、执行和约束三个独立维度，并采用门控得分机制确保只有正确触发技能的执行才被计入。数据构建包含掩码技能筛选（去除可从提示推断的通用要求）和多智能体对抗审查（不同模型家族审查员确认技能专属要求）等质量控制步骤，确保评分项真正反映技能使用能力。

### 6. 关键发现

- 可靠技能使用仍遥不可及: 最强配置（GPT-5.5 + Claude Code）的SU得分仅0.613，触发和合规执行是独立瓶颈：即使触发技能，最高合规率也仅0.638。
- 技能使用能力依赖于智能体框架: 模型在Claude Code和Codex下的SU得分和排名均发生显著变化，技能使用是模型-框架配置的属性，而非模型的固定能力。
- 边界遵守普遍优于流程合规，但安全领域例外: 所有模型-框架配置下，边界得分均高于合规得分，说明智能体避免禁止操作比完成完整规定流程更可靠。但在安全与合规领域，边界得分低于合规得分，模型遵循了流程但未能尊重禁止操作。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 智能体系统设计需同时优化技能识别和流程执行两个环节，不能仅依赖模型能力，框架设计对技能使用影响显著。
- 对 Skill: 技能文档应设计得更易于触发和遵循，例如提供更清晰的触发信号和可验证的执行步骤。
- 对 Memory: 技能检索机制需要改进，当前模型在仅凭名称和描述判断技能相关性时表现不佳。
- 对评测: 评估技能使用应包含触发、合规和边界三个维度，并考虑框架影响，避免单一指标误导。

### 11. 局限性

- 基准覆盖9个领域，但可能未涵盖所有实际应用场景。
- 评分依赖轨迹级规则和LLM评判，可能存在评判偏差。
- 仅评估两个智能体框架（Claude Code和Codex），更多框架下的表现未知。

### 12. 我的看法 / 个人笔记

该工作系统性地揭示了LLM智能体在技能使用上的关键瓶颈，特别是触发和合规的独立失败模式，以及框架依赖性的发现对实际部署具有重要警示。数据构建中的掩码筛选和多智能体对抗审查等质量控制步骤增强了基准的可靠性。未来可探索技能检索增强、流程引导机制以及跨框架泛化能力。

Skill-Use基准通过79个真实技能（来自社区仓库和现有基准）和177个可执行任务，在渐进式披露机制下评估LLM智能体的技能使用能力，分解为触发、合规和边界三个维度。评估8个模型在2个框架下的表现发现，最强配置SU仅0.613，触发和合规是独立瓶颈，且技能使用能力高度依赖智能体框架，而非模型的固定属性。数据构建采用掩码技能筛选（去除可从提示推断的通用要求）和多智能体对抗审查（不同模型家族审查员确认技能专属要求）等质量控制步骤，确保评分项反映技能专属要求。

## 3. Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning

**Topics:** LLM, long-horizon reasoning, skill switching, benchmark, reinforcement learning
**Authors:** Yinghui He, Ling Yang, Jiarui Liu, Yongjin Yang, Lechen Zhang, Yingcheng Wu, Zhenfei Yin, Mengdi Wang, Sanjeev Arora
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.05139v1) | [PDF](http://arxiv.org/pdf/2608.05139v1.pdf) | [Code](https://github.com/Gen-Verse/Skill-Entropy-RL)

### 1. 一句话结论

提出技能熵（Skill Entropy）量化跨技能切换难度，构建Skill²-Bench基准并设计Skill-Entropy RL训练框架，显著提升模型在长程推理中的技能切换能力。

### 2. 为什么重要

现有基准多评估单一技能，缺乏对模型在长程推理中跨技能切换能力的系统度量。本文首次形式化跨技能长程任务，提出技能熵作为任务难度度量，并据此构建基准和训练信号，揭示了模型在技能切换上的结构性缺陷，提供了可复用的训练方法。

### 3. 研究问题

1. 如何量化长程推理中不同技能之间切换的难度？
2. 现有LLM在跨技能长程任务上的表现如何？是否存在技能切换能力缺口？
3. 能否将技能熵作为训练信号，通过强化学习提升模型的技能切换能力？

### 4. 背景与问题设定

长程推理要求模型在推理链中切换不同技能（如先数学推导，再用结果规划日程）。现有基准多评估单一技能，缺乏对技能切换能力的度量。尽管前沿模型在单技能任务上表现优异，但在组合性长程任务中仍显脆弱，且这种脆弱性在技能切换时尤为突出。

### 5. 方法概览

- 任务 / 环境: 跨技能长程任务：多步任务，每一步需要不同推理技能，且依赖前一步输出。任务长度2-10步，技能来自9个领域（数学、科学、编程、逻辑、规划、信息抽取、创意写作、上下文检索、指令遵循），共558个技能。
- 变量 / 干预设计: 提出技能熵（SkE）度量从技能a切换到技能b的难度，基于参考模型在单技能与跨技能任务上的准确率比值。构建Skill²-Bench基准，按任务级技能熵分为低、中、高三个难度等级。提出Skill-Entropy RL框架：模型每一步不仅预测答案，还预测所用技能标签；奖励结合步骤正确性与技能熵奖励（衡量预测技能序列与真实技能序列的对齐程度）。
- 评价指标: Skill²-Bench得分：模型在跨技能任务上的平均每步得分（可验证步骤用符号等价或单元测试评分，开放步骤用LLM裁判按评分标准打分）。
- 模型比较: 评估8个前沿模型（Claude-haiku-4.5, Claude-sonnet-4.5, Claude-opus-4.7, Gemini-3.1-flash, Gemini-3.1-pro, GPT-5.4-mini, O4-mini, GPT-5.5）和4个开源模型（Qwen3-4B, Qwen3-8B, Qwen3-32B, Olmo-3-7B-Think）。训练实验在Qwen3-4B-Instruct和Qwen3-1.7B上进行，对比基线包括标准RL等。
- 我的理解: 本文的核心创新在于将技能切换难度形式化为一个可计算的量（技能熵），并同时将其用于评估和训练。评估方面，技能熵揭示了模型在单技能与跨技能任务间的性能差距；训练方面，通过让模型显式预测技能标签并优化技能熵奖励，迫使模型学习识别和切换技能，从而提升跨技能推理能力。

### 6. 关键发现

- 技能熵有效度量跨技能任务难度: 技能熵基于参考模型在单技能与跨技能任务上的准确率比值，高技能熵表示切换困难。任务级技能熵与模型准确率呈单调递减关系，验证了其作为难度度量的有效性。
- 模型存在技能切换能力缺口: 所有评估模型在跨技能设置下的准确率均低于单技能设置，平均下降4-13%。高技能熵任务上性能下降更显著，且该缺口在模型擅长领域依然存在。主要失败模式：模型在后续步骤倾向于复用前一步的技能和答案格式。
- Skill-Entropy RL显著提升跨技能推理: 在Qwen3-4B-Instruct上，Skill²-Bench得分从34.4%提升至68.4%；在Qwen3-1.7B上从14.6%提升至40.1%，超越强基线。该框架可应用于现成训练数据（如OpenR1-Math），表明技能熵是可复用的训练信号。

## 4. ArtAnno: Annotating Implicit Semantics in Artworks through LLM Agent-Driven Bidirectional Human-AI Augmentation

**Topics:** Human-AI Collaboration, Multi-Agent Systems, Artwork Annotation, LLM Agents
**Authors:** Xiaoyan Gu, Yifang Wang, Wenqing Zheng, Haozhong Liu, Yixia Zheng, Peiyi Jiang, Wenjie Ning, Wei Zhang, Wei Chen
**Venue / Year:** UIST '26
**Links:** [Abstract](http://arxiv.org/abs/2608.05026v1) | [PDF](http://arxiv.org/pdf/2608.05026v1.pdf)

### 1. 一句话结论

提出双向人机增强框架BiHAA并实现ArtAnno系统，通过LLM多智能体实现艺术品隐式语义标注的闭环协作与知识积累。

### 2. 为什么重要

现有标注工具缺乏对隐式语义的支持，且人机协作多为单向流程，导致效率低下。BiHAA框架将人机协作重构为双向增强闭环，使AI实时辅助标注的同时，自动从交互中提取专家知识并复用，显著降低信息检索与验证成本，为领域标注系统设计提供了新范式。

### 3. 研究问题

1. 如何设计双向人机增强框架，使AI在辅助当前任务的同时，自动从人类交互中积累可复用知识以提升未来任务效率？
2. 在艺术品隐式语义标注场景中，用户对AI辅助的具体需求是什么？系统应捕获哪些类型的知识以实现持续进化？

### 4. 背景与问题设定

艺术品标注需要解析对象的文化象征、隐喻等隐式语义，这依赖深层领域知识。现有工具要么无辅助，要么仅提供单向支持（如专家手动校准模型），导致重复劳动和效率瓶颈。LLM智能体虽能辅助或从反馈中学习，但两者分离，缺乏实时双向增强机制。

### 5. 方法概览

- 任务 / 环境: 艺术品隐式语义标注任务，涉及传统中国画等作品，需识别对象的文化含义与象征意义。
- 变量 / 干预设计: 基于BiHAA框架，ArtAnno包含两个模块：主动智能体支持模块（Proactive Agentic Support Module）提供语义挖掘与标签建议；交互驱动进化模块（Interaction-Driven Evolution Module）将标注轨迹蒸馏为可复用的技能库与知识库。
- 评价指标: 标注效率（时间）、知识积累与复用效果、跨领域迁移能力、用户主观评价。
- 模型比较: 与现有单向辅助工具（如仅提供界面加速的VIA、Label Studio）和需额外校准的交互式系统（如KMTLabeler）对比，ArtAnno通过闭环双向增强减少信息检索与验证开销。
- 我的理解: 该方法的核心创新在于将人机协作从单向辅助或单向反馈升级为实时双向增强：AI主动提供语义建议，同时自动从用户交互中提取领域知识与操作策略，形成持续进化的闭环。这类似于一个‘边用边学’的系统，用户无需额外操作即可让系统变得更聪明。

### 6. 关键发现

- BiHAA框架有效性验证: 通过20名参与者的Wizard-of-Oz形成性研究，验证了双向增强框架的可行性：系统从用户交互中积累知识并在后续轮次复用，显著减少重复信息检索时间。
- 用户对AI辅助的具体需求: 用户期望AI在任务初期提供主动引导，并在过程中按需提供多模态解释；同时希望系统不仅捕获领域知识，还能学习用户的搜索策略与操作流程。
- ArtAnno系统提升标注效率与知识积累: 用户研究与案例研究表明，ArtAnno相比基线系统提高了标注效率，实现了知识积累与跨领域迁移，降低了非专业用户的领域知识门槛。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: BiHAA框架可推广至其他需要领域知识的标注或分析任务（如医学影像、历史文献），使智能体在辅助过程中持续进化。

- 系统进化依赖于用户交互的丰富性，对于极少交互的新用户，初始辅助效果可能有限。

该工作将人机协作从单向辅助升级为双向增强闭环，思路清晰且实用。ArtAnno通过多智能体架构实现了实时辅助与知识蒸馏的整合，形成性研究与用户研究的设计严谨。未来可探索如何减少对LLM推理的依赖，以及如何支持跨会话的长期知识积累。

## 5. When Does Latent Communication Pay? A Causal Audit of Relayed KV Caches in Multi-Agent LLMs

**Topics:** 多智能体系统, 潜在通信, 因果审计, KV缓存
**Authors:** Jiaming Cheng, Subhransu Das, Rajiv Ramnath
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.04893v1) | [PDF](http://arxiv.org/pdf/2608.04893v1.pdf)

### 1. 一句话结论

多智能体LLM系统中中继KV缓存的性能提升主要源于通用接口效应，而非传递了示例特定的潜在思想。

### 2. 为什么重要

该研究通过因果审计揭示了潜在通信归因的漏洞，表明仅凭基准测试提升无法证明缓存中继传递了内容，为多智能体系统的评估设立了新标准。

### 3. 研究问题

1. 多智能体LLM系统中中继KV缓存的性能提升是否真正源于传递了示例特定的潜在思想？
2. 如何通过因果干预区分中继缓存的内容效应和通用接口效应？

### 4. 背景与问题设定

多智能体LLM系统通过中继KV缓存（而非文本）进行通信，并将性能提升归因于传递的“潜在思想”。然而，这种归因是因果性的：它声称中继的是特定示例的缓存内容，而非仅仅是中继行为本身。现有基准测试的改进无法区分内容效应和通用接口效应，因此需要直接的因果测试。

### 5. 方法概览

- 任务 / 环境: 两种实验条件：校准条件（接收者需要发送者的私有信息才能完成任务）和自然条件（接收者可独立解决标准基准任务）。
- 变量 / 干预设计: 对中继的KV缓存进行干预：替换为错配示例的缓存（deranged）、零缓存（zeroed）、矩匹配随机缓存（random），以及无私有信息的缓存（intact-no-private）。
- 评价指标: 准确率（accuracy），主要估计量为配对效应τ = 真实缓存准确率 - 错配缓存准确率。
- 模型比较: 测试了三个模型家族（Qwen3-4B/8B/14B、Mistral-Nemo-12B、phi-4）和三个系统（LatentMAS、KVComm、C2C）。
- 我的理解: 该方法通过精心设计的干预对照，分离了缓存内容效应和通用接口效应，并利用校准条件确保仪器灵敏度，从而在自然条件下进行等价性检验。

### 6. 关键发现

- 接收者必要性分离: 在接收者需要发送者私有信息的校准条件下，真实缓存与错配缓存的准确率差异接近天花板（约75-77个百分点）；而在自然条件下，该差异被等价性检验限制在±2.8个百分点以内。
- 大缓存效应不等于配对效应: 在自然条件下，零缓存导致准确率下降14.7个百分点，但错配缓存仅下降0.4个百分点，表明缓存效应主要来自通用接口而非内容配对。
- 系统间差异: 在相同测试下，LatentMAS的原生中继显示天花板效应，KVComm显示部分转移，C2C未检测到示例特定转移。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 多智能体系统设计者应谨慎归因性能提升，需通过错配内容控制实验验证通信内容是否真正被利用。
- 对 Skill: 潜在通信可能不传递示例特定技能，而是提供通用计算优势，因此技能传递需更直接的证据。
- 对 Memory: 中继缓存作为记忆机制时，其内容特异性需通过因果审计验证，否则可能高估记忆共享的价值。
- 对评测: 基准测试改进不足以证明潜在通信的有效性，评估应包含错配内容控制实验。

### 11. 局限性

- 审计仅针对已发布系统，未涉及训练过程或跨模型投影器的学习动态。
- 自然条件下的等价性检验仅适用于Qwen3家族，其他模型家族未建立等价边界。
- 校准条件使用程序生成的任务，可能无法完全代表真实世界场景。

### 12. 我的看法 / 个人笔记

该研究通过严谨的因果审计揭示了潜在通信归因的常见谬误，为多智能体系统评估提供了重要方法论。其核心贡献在于分离了内容效应和接口效应，并展示了基准测试改进的局限性。未来工作应扩展至更多系统和任务，并探索如何设计真正传递内容的中继机制。

### 14. 总结

本文通过因果审计多智能体LLM系统中中继KV缓存的性能提升，发现当接收者需要发送者私有信息时，缓存内容效应显著；但在标准基准任务上，性能提升主要来自通用接口效应而非示例特定内容传递。研究提出了错配缓存控制实验作为评估标准，并在三个系统中验证了该结论。
