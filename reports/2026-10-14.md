## 1. SkillScaffold: Scaffolding Agentic Reinforcement Learning with Policy-Adaptive Skill Credit Assignment and Selective Injection

**Topics:** GUI Agent, Agentic Reinforcement Learning, Skill-Based RL, LLM Agents
**Authors:** Wenlin Zhong, Hao Wang, Kun Yuan, Fan Yang, Jinluan Yang, Dian Jin, Xu Tan, Yiquan Wu, Kun Kuang
**Venue / Year:** 
**Links:** [Abstract](http://arxiv.org/abs/2610.18807v1) | [PDF](http://arxiv.org/pdf/2610.18807v1.pdf) | [Code](https://github.com/Vaidurya00/SkillScaffold)

### 1. 一句话结论

SkillScaffold 通过策略自适应的技能效用估计与选择性注入，在无需额外环境回滚的情况下显著提升智能体强化学习的样本效率和任务性能。

### 2. 为什么重要

现有技能增强的强化学习方法要么盲目注入技能，要么依赖昂贵的回滚评估，导致效率低下且不稳定。SkillScaffold 提出了一种低成本、策略自适应的技能效用估计方法，并支持选择性注入，使得技能生成与执行器策略协同进化，为智能体在复杂多步任务中的高效学习提供了新范式。

### 3. 研究问题

1. 如何在不进行额外环境回滚的情况下，低成本且稳定地估计候选技能对当前策略的效用？
2. 如何根据策略当前能力自适应地决定是否注入技能以及注入哪个技能，以最大化学习收益？

### 4. 背景与问题设定

智能体强化学习（Agentic RL）使 LLM 能够通过与可验证结果的多轮交互进行学习。文本技能通过将先前的交互提炼为可重用的指导，可以改善探索。然而，现有基于技能的方法要么假设技能注入总是有益的，要么依赖间接反馈或需要大量回滚的评估，这些方法成本高且在小样本下不稳定。此外，技能收益因候选技能而异，并取决于当前策略在每个查询上的能力。

### 5. 方法概览

- 任务 / 环境: ALFWorld、WebShop、ScienceWorld 和 τ²-Bench，涵盖短时和长时任务。
- 变量 / 干预设计: SkillScaffold 包含一个 Generator 和一个 Executor。Generator 从结果验证的训练轨迹中生成候选技能，并通过结果感知的似然比较估计其效用（无需候选特定回滚）。具体地，对于每个候选技能，计算在给定技能条件下执行轨迹的似然与无技能条件下的似然之比，作为效用估计。根据效用决定是否注入技能以及注入哪个技能，当没有候选被估计有帮助时保留无技能执行。联合训练使 Generator 适应不断演化的 Executor。
- 评价指标: 任务成功率（成功率）以及可能的其他标准指标（如平均奖励）。
- 模型比较: 与强 agentic-RL 基线（如 RFT、DAPO）和基于技能的方法（如假设注入有益或使用回滚评估的方法）进行比较。
- 我的理解: 该方法的核心创新在于利用已有的结果验证轨迹进行效用估计，通过比较有技能和无技能条件下的似然来推断技能效用，从而避免了昂贵的回滚。同时，选择性注入机制允许策略在技能无益时保持无技能执行，提高了鲁棒性。联合训练使得技能生成与策略学习相互促进，最终实现技能内化，推理时无需技能。

### 6. 关键发现

- SkillScaffold 在多个基准上取得显著性能提升: 在 ALFWorld、WebShop、ScienceWorld 和 τ²-Bench 上，SkillScaffold 均优于强 agentic-RL 和基于技能的方法，具体提升幅度见原文实验部分。
- 效用估计与选择性注入至关重要: 消融实验表明，移除效用估计（随机注入）或选择性注入（总是注入）会导致性能下降，验证了基于效用的选择和弃权机制的有效性。
- 联合训练促进技能内化: 通过联合训练，Generator 生成的技能更适应 Executor 的当前能力，且 Scaffolded RL 鼓励技能内化，使得推理时无需技能也能保持高性能。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: SkillScaffold 提供了一种可扩展的框架，使智能体能够根据自身能力动态调整技能使用，提高学习效率和适应性。
- 对 Skill: 技能不再被视为静态资产，而是需要根据策略状态进行效用评估和选择性应用，这改变了技能生成和注入的方式。
- 对 Memory: 技能可以视为一种外部记忆，通过效用估计决定何时读取，类似于记忆的选择性检索，有助于提升记忆利用效率。
- 对评测: 提出了一种无需回滚的技能效用评估方法，为评估技能价值提供了新思路，可应用于其他需要评估外部知识或工具的场景。

### 11. 局限性

- 效用估计基于似然比较，可能对生成模型的校准敏感，在分布外场景下可能不准确。
- 方法依赖于可验证的结果，对于无法提供明确奖励的任务可能不适用。
- 实验主要在模拟环境，真实世界应用效果未知。

### 12. 我的看法 / 个人笔记

SkillScaffold 提出了一种优雅且实用的技能效用估计方法，解决了技能注入中的关键问题。其选择性注入机制类似于元学习中的自适应，使得策略能够灵活利用技能。未来工作可以探索更复杂的效用估计模型，以及将方法扩展到更广泛的任务类型。

## 2. OmniCompass: A Holistic Benchmark for Omni-Modal Video Grounding and Understanding

**Topics:** 多模态大语言模型, 视频理解, 基准测试, 时间定位, 空间定位, 问答
**Authors:** Xuyang Liu, Shihao Wang, Xinyu Wei, Minghan Li, Zeqing Wang, Zuhao Yang, Zichen Wen, Lei Zhang
**Venue / Year:** 
**Links:** [Abstract](http://arxiv.org/abs/2610.18829v1) | [PDF](http://arxiv.org/pdf/2610.18829v1.pdf)

### 1. 一句话结论

OmniCompass 是一个全面的多模态视频定位与理解基准，包含视觉和音视频两个轨道，评估时间定位、空间定位和问答，发现开源模型在音视频理解上仍落后于专有模型，且精确的时空定位对领先模型也具挑战性。

### 2. 为什么重要

现有视频理解基准仅覆盖部分评估维度，缺乏对全模态（视觉+音频）视频理解能力的系统诊断。OmniCompass 通过双轨道、三任务设计，提供了更全面的评估框架，有助于识别模型在时间、空间和语义理解上的具体短板，推动多模态模型的发展。

### 3. 研究问题

1. 如何设计一个全面的基准来评估多模态大语言模型在视频理解中的时间定位、空间定位和问答能力？
2. 在需要联合音频-视觉证据的任务中，开源模型与专有模型的表现差距有多大？
3. 当前领先模型在精确时间定位和空间定位上的表现如何？在不同目标指定方式（文本 vs 文本+图像）下是否一致？

### 4. 背景与问题设定

随着多模态大语言模型（MLLMs）的快速发展，评估其视频理解能力变得日益重要。然而，现有基准往往只覆盖部分评估维度，例如仅关注视觉问答或时间定位，缺乏对全模态（包括音频）视频理解的系统评估。这限制了对模型能力的全面诊断，也无法指导模型改进。因此，需要一个更全面的基准来评估模型在时间、空间和语义层面的理解能力，并考虑音频信息的作用。

### 5. 方法概览

- 任务 / 环境: 视频数据来自多个领域，包含短、中、长三种时长类型。OmniCompass-VL 包含 820 个视频和 2460 个实例，OmniCompass-AV 包含 240 个视频和 720 个实例（叙事和音频丰富）。
- 变量 / 干预设计: 每个实例在两种配对设置下评估：仅文本和文本+图像，通过文本或视觉语言指导指定同一目标，以测试模型在不同输入条件下的表现一致性。
- 评价指标: 对于时间定位和空间定位，可能使用准确率或 IoU 等指标；对于问答，使用准确率。具体指标未在摘要中明确，但通常此类基准会采用这些标准。
- 模型比较: 评估了 50 个多模态大语言模型，包括开源和专有模型，比较它们在两个轨道、三个任务上的表现。
- 我的理解: 该基准通过双轨道（视觉 vs 音视频）和三任务（时间定位、空间定位、问答）设计，全面评估模型对视频内容的理解。配对设置（文本 vs 文本+图像）用于测试模型在不同目标指定方式下的鲁棒性。这种设计有助于分离视觉和音频的贡献，并揭示模型在时空定位上的弱点。

### 6. 关键发现

- 开源模型在音视频理解上落后于专有模型: 在 OmniCompass-AV 轨道上，开源模型的表现明显低于专有模型，表明音频-视觉联合理解是开源模型的短板。
- 精确时间定位和空间定位对领先模型仍具挑战性: 即使是最先进的模型，在时间定位和空间定位任务上的表现也不理想，说明这些任务需要更精细的时空推理能力。
- 模型在不同目标指定方式下表现不一致: 当目标通过文本或文本+图像指定时，模型的预测存在不一致性，表明模型对输入模态的依赖和鲁棒性有待提高。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 对于视频理解代理系统，该基准强调了时间定位和空间定位的重要性，代理需要更精确的时空推理能力，以在动态环境中做出正确决策。
- 对 Skill: 模型需要发展联合音频-视觉理解技能，而不仅仅是视觉理解，以应对真实世界中的多模态信息。
- 对 Memory: 长视频中的时间定位需要模型具备长期记忆能力，以跟踪目标出现的时间点。
- 对评测: 评估应涵盖多模态、多任务，并考虑不同输入条件，以全面衡量模型能力。

### 11. 局限性

- 基准仅覆盖视频理解，未涉及其他模态（如文本、3D）的联合理解。
- 评估的模型数量虽多，但可能未涵盖所有最新模型。
- 音频-视觉轨道仅包含 240 个视频，规模相对较小，可能影响统计显著性。

### 12. 我的看法 / 个人笔记

OmniCompass 提供了一个全面的视频理解基准，其双轨道设计有助于分离视觉和音频的贡献。然而，基准的规模（尤其是音视频部分）可能限制了其泛化性。未来工作可扩展音频-视觉数据，并增加更多任务类型（如视频生成）。此外，该基准可促进开源模型在音视频理解上的改进。

OmniCompass 是一个全面的多模态视频定位与理解基准，包含视觉（VL）和音视频（AV）两个轨道，每个轨道包含时间定位、空间定位和问答三个任务。基准包含 820 个视频（VL）和 240 个视频（AV），所有实例均经过人工标注和多轮质量验证。评估了 50 个多模态大语言模型，发现开源模型在音视频理解上落后于专有模型，且精确的时空定位对领先模型仍具挑战性，模型在不同目标指定方式下表现不一致。该基准为多模态视频理解提供了更全面的评估框架，有助于推动模型在时空推理和音频-视觉联合理解方面的发展。

## 3. BLADE: Auditing Information Use for Failure Attribution in LLM Multi-Agent Systems

**Topics:** LLM多智能体系统, 失败归因, 依赖追踪, 信息审计
**Authors:** Xiaoguang Guo, Yaohao Long, Chuxu Zhang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.18780v1) | [PDF](http://arxiv.org/pdf/2610.18780v1.pdf) | [Code](https://github.com/GXG-CS/BLADE)

### 1. 一句话结论

BLADE通过审计源-决策交接处的信息使用，而非仅追踪依赖，显著提升了多智能体系统失败归因的准确性。

### 2. 为什么重要

多智能体系统协作复杂，失败难以诊断。BLADE提供了一种无需训练的框架，通过显式审计信息使用，区分错误引入、传播和修复，为可解释和可靠的智能体系统铺平道路。

### 3. 研究问题

1. 如何超越依赖追踪，审计信息在智能体间的实际使用以准确归因失败？
2. 如何利用概率依赖选择关键交接点进行审计，并整合全局诊断以确定决定性错误？

### 4. 背景与问题设定

大语言模型多智能体系统通过角色协作扩展能力，但协作导致失败难以诊断：一个智能体可能误解正确结果，而其他智能体继续传播错误。现有方法追踪依赖，但知道信息来自哪里不等于知道哪里出错。因此，需要审计信息使用，区分错误引入、传播和修复。

### 5. 方法概览

- 任务 / 环境: 多智能体系统执行复杂任务，产生失败轨迹（事件序列），每个事件记录消息、动作或观察。
- 变量 / 干预设计: BLADE框架：1) 重建依赖图；2) 基于依赖概率选择源-决策交接点进行审计；3) 结合全局诊断，所有事件保持候选资格。
- 评价指标: 步骤级归因准确率（step accuracy），比较不同策略在五个基准子集上的表现。
- 模型比较: 与All-at-once、依赖追踪方法（如FALAT、DeFA）等八种策略比较，BLADE在准确率上最优或并列最优。
- 我的理解: BLADE的核心创新在于将依赖追踪与信息使用审计结合，通过概率选择关键交接点，避免穷举，同时保留全局诊断的灵活性。

### 6. 关键发现

- 审计信息使用优于单纯依赖追踪: 在五个基准子集上，BLADE的步骤准确率比All-at-once高2.2-11.1个百分点，且依赖信息单独使用效果不稳定，而审计信息一致提升准确率。
- 选择性审计高效且有效: 依赖引导的审计仅检查13-23%的交接点，但性能匹配或超过穷举审计，表明关键交接点的选择至关重要。

### 7. 最重要的图

- 图来源: 图1：示例展示错误传播链，其中代码执行正确识别Braintree和Honolulu，但后续智能体误读为Honolulu和Quincy，导致最终错误。
- 为什么重要: 该图直观说明了失败归因的挑战：错误可能源于信息使用而非信息本身，强调审计信息使用的重要性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: BLADE提供了一种可解释的失败归因机制，有助于调试和提升多智能体系统的可靠性。
- 对 Skill: 审计信息使用可作为一种通用技能，帮助智能体识别和纠正误解，提升协作质量。
- 对 Memory: 依赖图和审计结果可作为记忆结构，支持长期诊断和改进。
- 对评测: BLADE的评估方法可推广到其他智能体系统，作为标准归因基准。

### 11. 局限性

- 依赖重建和审计依赖LLM判断，可能受模型偏差影响。
- 仅评估了Who&When基准，泛化性有待验证。
- 阈值θ和最大源数K需要手动设定，可能影响性能。

### 12. 我的看法 / 个人笔记

BLADE创新性地将信息使用审计引入失败归因，解决了依赖追踪的盲点。其选择性审计策略高效且有效，但依赖LLM判断可能引入不确定性。未来可探索更鲁棒的审计方法或结合训练信号。

- FALAT: 基于依赖的失败归因

  为什么重要：结合依赖和传播分析，是BLADE的对比方法之一。

  与当前论文关系：BLADE在实验中与DeFA比较，并强调审计信息使用。

### 14. 总结

BLADE是一个无需训练的框架，通过审计多智能体系统中源-决策交接处的信息使用，区分错误引入、传播和修复，从而准确归因失败。在五个基准子集上，BLADE优于现有方法，证明了审计信息使用的重要性。

## 4. ProAS: A Progress-Aware Advantage Shaping Framework for Multi-Turn Agentic Reinforcement Learning

**Topics:** GUI Agent, Reinforcement Learning, LLM Agent
**Authors:** Bowen Ding, Mingda Wan, Yuhan Chen, Jiyao Yuan, Qi Zhu, Futing Wang, Heyuan Deng, Fei Mi, Lifeng Shang, Tao Lin
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.18683v1) | [PDF](http://arxiv.org/pdf/2610.18683v1.pdf) | [Code](https://github.com/LINs-lab/ProAS)

### 1. 一句话结论

ProAS 通过动态演化的 Agentic Reference Graph 对轨迹级优势进行非对称整形，解决了无评论家 RL 中的均匀信用分配困境，显著提升了多轮智能体任务的性能与训练效率。

### 2. 为什么重要

该工作揭示了 GRPO 等无评论家 RL 算法在长程智能体任务中的根本缺陷——均匀信用分配，并提出了无需额外评论家的轻量级解决方案，为提升 LLM 智能体的训练效率和最终性能提供了新思路。

### 3. 研究问题

1. ProAS 能否在不同模型规模和环境下持续提升任务成功率并加速训练收敛？
2. ProAS 是否作为即插即用模块与主流基于组的 RL 基线（如 GRPO、DAPO、GiGPO）兼容？
3. MUI 和 APR 各自是否必要且协同，Future-Drift 重分配是否优于简单掩码启发式？
4. ProAS 在参考图随机、不完整、静态或蒸馏的情况下是否保持鲁棒？

### 4. 背景与问题设定

强化学习（RL）已成为优化 LLM 智能体的主要范式，但高效的免评论家算法（如 GRPO）存在均匀信用分配困境：将轨迹级优势均匀分配给所有动作，导致在偏好轨迹中强化无效动作，在非偏好轨迹中忽略早期关键动作的下游级联影响。现有方法如 MiGPO 虽引入段级信用分配，但需要额外评论家或复杂设计。

### 5. 方法概览

- 任务 / 环境: ALFWorld（文本具身家务任务）和 WebShop（HTML 在线购物环境），均为长程多轮智能体任务。
- 变量 / 干预设计: ProAS 框架包含两个核心机制：MUI（掩码不合理激励）在偏好轨迹中将无效动作的优势置零；APR（非对称惩罚重分配）根据 Future-Drift 对非偏好轨迹中的早期关键动作施加更重惩罚。
- 评价指标: 成功率（SR）和任务得分（TS），以及训练效率（达到目标 SR 所需的环境交互步数加速比）。
- 模型比较: 与 GPT-5.6-Sol、SFT、PPO、GRPO、DAPO、GiGPO、MiGPO 等基线对比，在 Qwen2.5-1.5B-Instruct 和 Qwen2.5-7B-Instruct 上评估。
- 我的理解: ProAS 通过构建动态演化的 ARG 作为任务进度的参考图，对每个动作进行合理性和进展性标注，从而在无需评论家的情况下实现细粒度信用分配。其核心创新在于利用结构化的子目标图来指导优势整形，既避免了无效动作的强化，又对导致级联失败的早期动作进行重点惩罚。

### 6. 关键发现

- 性能提升: ProAS 在 ALFWorld 上达到 91.9% 和 94.3% 的成功率，在 WebShop 上达到 66.7% 和 70.8%，均超过现有基线，包括 MiGPO。
- 训练加速: ProAS 将训练收敛速度提升 1.12 至 2.44 倍，显著减少达到目标成功率所需的环境交互步数。
- 即插即用兼容性: ProAS 作为模块可无缝集成到 GRPO、DAPO、GiGPO 等主流算法中，普遍提升其性能。
- 机制有效性: 消融实验表明 MUI 和 APR 各自必要且协同，Future-Drift 重分配优于简单掩码启发式。
- 鲁棒性: ProAS 在 ARG 随机、不完整、静态或蒸馏的情况下仍保持有效，表明其鲁棒性。

## 5. Can an Agent Learn to Predict Its Own Failure? Outcome-Grounded Confidence Calibration in LLM Agents

**Topics:** LLM Agent, Confidence Calibration, Reinforcement Learning, GRPO, Selective Execution
**Authors:** Ashutosh Hathidara
**Venue / Year:** 
**Links:** [Abstract](http://arxiv.org/abs/2610.18614v1) | [PDF](http://arxiv.org/pdf/2610.18614v1.pdf)

### 1. 一句话结论

通过GRPO将LLM智能体每步的置信度校准到整个回合的最终结果，显著提升了对任务失败的预测能力，且不损害任务成功率。

### 2. 为什么重要

该研究解决了LLM智能体在长程任务中缺乏可靠的分步置信度信号的问题，使得智能体能够在关键时刻选择放弃或交给人类，从而提升整体系统的安全性和可靠性。

### 3. 研究问题

1. 如何将LLM智能体的分步置信度校准到整个回合的最终结果？
2. 这种校准能否提升智能体对自身失败的预测能力，并改善选择性执行？

### 4. 背景与问题设定

在长程任务中，LLM智能体需要决定每一步是否信任自己的动作、放弃或交给人类。这需要一个分步置信度信号来预测当前轨迹最终是否成功。智能体自报的言语化置信度是自然候选，但现有强化学习方法仅将其校准到当前步骤决策的正确性，而非最终结果。

### 5. 方法概览

- 任务 / 环境: ALFWorld、TextWorld、WebShop环境，使用Qwen2.5-7B智能体。
- 变量 / 干预设计: 在GRPO框架下，对于每个任务，生成一组rollout，每个rollout的最终成功与否作为该rollout中所有步骤的标签。然后使用适当的评分规则（如Brier score或对数损失）对每一步的置信度与最终结果进行校准，通过优化该评分规则来训练置信度预测。
- 评价指标: AUROC（分步置信度对回合结果的预测能力）、期望校准误差（ECE）、选择性执行的成功率。
- 模型比较: 对比了未训练智能体、仅格式RL控制（只优化格式而不校准置信度）以及提出的校准方法。
- 我的理解: 该方法的核心是将置信度校准从局部（当前步骤）扩展到全局（整个回合），通过GRPO的组内rollout的成功标签来为每个步骤提供监督，从而让智能体学会在早期步骤就识别出可能失败的任务。

### 6. 关键发现

- 离线RL中置信度预测能力显著提升: 在ALFWorld、TextWorld和WebShop中，分步置信度对回合结果的AUROC从接近随机提升到0.68-0.85，且最自信的10%步骤的成功率比平均高约4.3倍。
- 在线RL中校准误差大幅降低: 在ALFWorld在线RL中，四种校准奖励使早期步骤AUROC提升，期望校准误差从0.42降至0.12以下，选择性执行优于未训练智能体和仅格式RL控制，且不降低任务成功率。
- 评估协议揭示能力来源: 新评估协议区分了回合深度、任务难度和尝试级预见性，发现训练后的智能体从第一步就能识别哪些任务会失败，但在同一任务中区分成功和失败尝试更难，TextWorld中出现了早期窗口信号。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 为智能体提供可靠的分步置信度，使其能够在高风险场景中主动放弃或请求人类介入，提升系统的安全性和可控性。
- 对 Skill: 置信度校准可视为一种元技能，帮助智能体评估自身能力边界，从而更有效地选择策略。
- 对 Memory: 置信度信号可作为记忆的一部分，帮助智能体在类似任务中更快识别潜在失败。
- 对评测: 提出的评估协议（区分深度、难度和预见性）为更细致地评估智能体自我认知能力提供了新视角。

### 11. 局限性

- 实验环境为模拟环境，真实世界中的泛化性未知。
- 置信度信号基于言语化输出，可能受模型表达限制。
- 在线RL仅在ALFWorld上验证，其他环境未测试。
- 在同一任务中区分成功与失败尝试的难度较高，早期窗口信号仅在TextWorld中出现，表明跨任务的泛化仍有挑战。

该工作将置信度校准从局部扩展到全局，是一个重要进步。它使智能体能够更早地识别失败，这对于实际部署中的安全决策至关重要。未来可探索更复杂的评分规则和跨环境泛化。
