## 1. ClosureBench: A Benchmark for Reasoning under Closure Assumptions

**Topics:** AI Agent, LLM, 闭世界假设, 开放世界假设, 局部闭世界假设, 基准测试
**Authors:** Francesco Belardinelli, Flavio Corradini, Matteo Leonesi
**Venue / Year:** Proceedings of Machine Learning Research vol 284, 2026, 20th Conference on Neurosymbolic Learning and Reasoning
**Links:** [Abstract](http://arxiv.org/abs/2611.26335v1) | [PDF](http://arxiv.org/pdf/2611.26335v1.pdf) | [Code](https://github.com/)

### 1. 一句话结论

ClosureBench 通过控制闭包契约（OWA/CWA/LCWA）的变化，揭示了 LLM 在缺失信息处理上的系统性缺陷，尤其是局部闭世界假设下的错误。

### 2. 为什么重要

该基准填补了现有评估的空白，将闭包假设从其他推理能力中分离出来，为 AI 代理在真实世界不完整数据上的可靠性提供了关键测试，并指出了改进方向。

### 3. 研究问题

1. LLM 是否能够遵循明确的闭包契约（OWA、CWA、LCWA）来处理缺失信息？
2. 闭包错误是否会传导到代理的决策（如行动选择、源选择、更新）中？

### 4. 背景与问题设定

AI 代理常基于不完整记录回答问题，缺失信息可能被解释为未知或假，取决于源的完整性。现有评估未能区分这两种情况，且常与其他推理需求交织。闭包假设（OWA、CWA、LCWA）在符号 AI 中已有研究，但对 LLM 的适用性尚未系统测试。

### 5. 方法概览

- 任务 / 环境: 基于规则的小型知识库，包含正原子、显式负原子和规则，查询目标原子。每个场景有 OWA、CWA、LCWA 三种变体，仅闭包契约变化。
- 变量 / 干预设计: 设计了三种代理扩展：Ask/Act（动作选择）、SourceScope（多源选择）、ClosureShift（多轮更新）。
- 评价指标: 总体准确率、闭包切换准确率、核心切换准确率、LCWA 闭/开范围准确率、动作准确率、Ask F1、过度询问率、泄漏率、损失率等。
- 模型比较: 评估了 DeepSeek V4 Flash/Pro、Mistral Small/Medium 3.5、Llama 4 Scout/Maverick 六种模型。
- 我的理解: 该基准通过精心设计的场景，将闭包假设作为唯一变量，从而精确测量模型对闭包契约的遵循程度，并通过扩展任务考察错误的下游影响。

### 6. 关键发现

- 总体准确率掩盖闭包错误: 模型总体准确率较高（如 Llama Maverick 99.86%），但核心切换准确率显著下降（如 DeepSeek Pro 77.43%），表明模型在闭包契约变化时容易出错。
- LCWA 是最难的设置: 模型在 LCWA 闭范围（需将缺失视为假）上表现不佳，如 Mistral Medium 仅 56.95% 准确率，而开范围（未知）可达 100%。
- 闭包错误传导至代理决策: 在 Ask/Act 中，模型在应拒绝时过度询问（如 DeepSeek Flash 21.07%）；在 SourceScope 中，模型混淆源的完整性（如 DeepSeek Flash 泄漏率 29.70%）；在 ClosureShift 中，模型未能保持局部闭包。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 代理系统需要显式处理闭包契约，避免在信息缺失时错误地请求或行动。
- 对 Skill: 模型需要训练以区分开放与封闭世界，特别是在局部闭世界假设下。
- 对 Memory: 在更新场景中，模型需根据完整性变化调整记忆中的结论。
- 对评测: 评估应包含闭包切换准确率，而非仅总体准确率。

### 11. 局限性

- 基准仅基于规则系统，未涵盖更复杂的自然语言推理。
- 模型评估限于特定 API，可能不具普遍性。
- 代理扩展的规模较小，可能不足以全面反映真实场景。

### 12. 我的看法 / 个人笔记

ClosureBench 是一个精心设计的基准，有效隔离了闭包假设这一关键因素，揭示了 LLM 在缺失信息处理上的脆弱性。未来工作可扩展至更复杂的逻辑和真实世界数据，并探索如何通过提示或训练提升闭包遵循能力。

ClosureBench 通过 960 个实例和三种代理扩展，系统评估了 LLM 在 OWA、CWA、LCWA 下的推理能力。结果显示，模型总体准确率虽高，但闭包切换准确率显著下降，尤其在 LCWA 下错误频发，且错误会传导至决策。该基准为 AI 代理的可靠性评估提供了重要工具。

## 2. ResVision: Spectrum-Matched Resizing and Context-Preserving Inspection for Visual Reasoning

**Topics:** GUI Agent, 视觉推理, 视觉语言模型, 智能体视觉推理
**Authors:** Guojian Zhan, Jiahao Xu, Yahui Liu, Yao Hu, Chuan Mu
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.26318v1) | [PDF](http://arxiv.org/pdf/2611.26318v1.pdf) | [Code](https://pevek.ai)

### 1. 一句话结论

ResVision 通过频谱匹配缩放（SMR）和上下文保持检查（CPI）两种无需训练的方法，分别解决视觉令牌化中的高频细节衰减和裁剪后全局上下文丢失问题，从而显著提升智能体视觉推理的准确性。

### 2. 为什么重要

该工作揭示了智能体视觉推理中“改变呈现方式”如何影响推理性能的底层机制，并提出了简单有效的改进方案，在多个模型和基准上取得一致提升，为多模态推理系统的设计提供了新思路。

### 3. 研究问题

1. 视觉令牌化过程中的哪些瓶颈限制了智能体视觉推理的性能？
2. 如何在不增加新场景内容的情况下，通过调整视觉呈现方式来提升推理准确性？

### 4. 背景与问题设定

智能体视觉推理通过迭代放大图像区域来提升视觉语言模型（VLM）的推理能力，但放大操作本身不引入新信息，仅改变像素呈现方式。然而，这种改变却能显著影响推理性能，其背后的机制尚不明确。本文通过系统分析视觉令牌化过程，识别出三个关键瓶颈：令牌内高频细节衰减、跨令牌证据检索困难、以及裁剪后全局上下文缺失。

### 5. 方法概览

- 任务 / 环境: 视觉推理任务，涵盖数学与逻辑、图表与OCR、幻觉与计数、具身与空间、医学与世界知识、通用视觉等六类，共29个基准。
- 变量 / 干预设计: 提出两种干预：频谱匹配缩放（SMR）在令牌化前根据图像复杂度自适应调整全局缩放比例，使高频细节落入编码器可有效处理的频带；上下文保持检查（CPI）在每次放大裁剪时，将完整工作视图与裁剪图同时作为输入，保持全局上下文。
- 评价指标: 使用各基准的准确率，并计算跨模型的平均准确率（Macro-29）。
- 模型比较: 在四种前沿VLM（Qwen、Kimi、GLM、DeepSeek）上评估，比较直接推理（Direct）、直接推理+ResVision、智能体推理（Agentic）、智能体推理+ResVision四种设置。
- 我的理解: 该方法的核心在于理解视觉令牌化的信息瓶颈，并通过调整输入图像的呈现方式来优化信息传递，而非增加模型容量或训练数据。SMR和CPI分别从频域和空间上下文两个维度改善视觉信息的可用性。

### 6. 关键发现

- SMR和CPI互补提升性能: 完整的ResVision（Agentic Base+SMR+CPI）在所有模型上均优于直接推理和仅使用Agentic Base，平均提升3.88分（对比Direct Base）和2.28分（对比Agentic Base）。
- SMR解决高频细节衰减: 通过频谱匹配缩放，将图像中的高频细节调整到编码器可有效处理的频带，避免了令牌内高频信息的丢失。
- CPI保持全局上下文: 将裁剪图与完整工作视图同时输入，避免了因裁剪导致的全局上下文缺失，提高了细节定位和比较的准确性。

### 7. 最重要的图

- 图来源: 图2：三种机制示意图
- 为什么重要: 该图直观展示了视觉令牌化过程中的三个瓶颈（令牌内衰减、跨令牌检索失败、全局-细节参考缺失），并说明了SMR和CPI如何分别针对这些瓶颈进行干预，是理解方法核心思想的关键。

## 3. SWE-Recreation: Benchmarking Coding Agents for Software Recreation

**Topics:** GUI Agent, Coding Agent, Benchmark, Software Recreation
**Authors:** Zhiyao Xu, Zhanjie Ding, Hongyao Yu, Jingyu Xiao
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.26311v1) | [PDF](http://arxiv.org/pdf/2611.26311v1.pdf) | [Code](https://github.com/nologistic/recreateanything)

### 1. 一句话结论

SWE-Recreation 基准测试表明，前沿智能体在仅通过像素级交互重建未知软件的任务上表现有限，最高加权保真度仅 0.530，完全复现需求比例不足 23%。

### 2. 为什么重要

该工作首次提出“主动黑盒软件重建”任务，要求智能体仅通过人类可用的视觉和指针交互来理解并重建未知应用，挑战了现有智能体依赖显式规格或结构化接口的假设，为评估自主探索、长期规划和实现能力提供了新基准。

### 3. 研究问题

1. 智能体能否仅通过像素级交互（无 DOM、源码或日志）理解并重建一个陌生软件？
2. 在探索、理解和实现三个环节中，当前智能体的主要瓶颈在哪里？

### 4. 背景与问题设定

现有智能体通常被赋予明确目标（如文本指令、截图或演示），而人类开发者常需通过使用未知产品来理解其功能并重建。SWE-Recreation 填补了这一空白，要求智能体在仅能观察渲染像素和通过指针/键盘操作的情况下，自主探索、生成可运行副本并自我检查。基准包含 54 个真实应用（28 个网站和 26 个 Android 应用），共 1,446 个隐藏需求，覆盖多步骤、有状态的工作流，并明确排除无法在单机复现的行为（如多用户、支付等）。

### 5. 方法概览

- 任务 / 环境: 54 个真实应用（28 个网站和 26 个 Android 应用），智能体通过 MCP 服务器以像素截图和坐标级操作（点击、滑动、输入等）与运行中的应用交互，无 DOM、源码或日志访问。
- 变量 / 干预设计: 智能体需完成四个阶段：探索（自由交互）、生成（构建可运行副本）、自检（验证功能）、评估（由固定法官模型通过像素证据评分）。
- 评价指标: 主要指标：加权保真度（WFS）、探索覆盖率（ECov）、发现到实现率（D2I）、持久性保真度（P-WFS）、非功能率（NFR）等。
- 模型比较: 评估了五个前沿模型-框架组合（如 Kimi、DeepSeek、Opus 等），在 42 个目标（16 个网站 + 26 个应用）上进行 210 次运行，共 5,555 次评分。
- 我的理解: 该任务将软件理解视为一个主动探索过程，智能体需自行决定观察什么、如何操作，并将零散观察整合为完整功能实现。评估不仅关注最终代码，还通过探索覆盖率区分“未发现”与“发现但未实现”的失败，有助于定位瓶颈。

### 6. 关键发现

- 整体性能有限: 最强系统 Kimi 的加权保真度仅 0.530，完全复现需求比例仅 22.9%，表明当前智能体在主动探索和重建方面仍有很大提升空间。
- 探索与实现存在差距: 探索覆盖率（ECov）与发现到实现率（D2I）的相关性分析显示，部分需求虽被探索到但未能实现，说明实现能力是主要瓶颈之一。
- 平台差异明显: 不同模型在网站和移动应用上的表现排序不同，例如 Kimi 和 DeepSeek 在两类平台上均领先，但其他模型的表现受应用类型影响。

## 4. SKILL.PNG: Learning Agent Skills in Pixel Space

**Topics:** GUI Agent, 视觉语言模型, 技能学习, 像素空间优化
**Authors:** Maximilian Seeth, Chengzhi Martin Hu, Marie Kempkes, Paul Röttger, Leo Schwinn
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.26296v1) | [PDF](http://arxiv.org/pdf/2611.26296v1.pdf) | [Code](https://github.com/omseeth/skill.png)

### 1. 一句话结论

SKILL.PNG 通过梯度下降在像素空间中优化技能图像，使冻结的视觉语言模型（VLM）无需修改权重即可获得可迁移的技能，并在多个基准上超越文本技能。

### 2. 为什么重要

该工作首次将技能表示从离散文本扩展到连续像素空间，实现了基于梯度的优化，同时保持了跨模型的可迁移性，为智能体技能的高效获取和共享提供了新范式。

### 3. 研究问题

1. 如何将技能表示为可优化的图像，从而利用梯度下降进行高效优化？
2. 图像技能能否在不同VLM之间迁移，并超越基于大语言模型优化的文本技能？

### 4. 背景与问题设定

AI智能体通常通过自然语言技能（如指令）来适应新任务，但文本的离散性阻碍了连续优化。微调（如LoRA）虽可梯度优化，但模型特定，无法跨模型迁移。由于许多智能体基于VLM，且所有VLM都接受图像输入，因此作者提出将技能编码为图像，通过冻结VLM的视觉编码器进行梯度优化，从而获得可迁移且可优化的技能。

### 5. 方法概览

- 任务 / 环境: 四个基准：SearchQA（问答）、TRAJECT（工具使用）、LiveMath（数学）、T1（旅行规划）。
- 变量 / 干预设计: 将技能图像 I_skill 与文本提示 T_text 和目标答案 T_target 拼接输入冻结的VLM，仅对图像像素进行梯度优化，使用交叉熵损失，并投影回有效图像域。
- 评价指标: 各基准的准确率（exact match或准确率），与无技能、随机图像、LLM技能（SkillOpt）等对比。
- 模型比较: 在四个VLM（Qwen3.5-4B, Qwen3.5-9B, Gemma-4-E4B-it, Nemotron-3）上评估，与文本技能（SkillOpt）和LoRA微调对比。
- 我的理解: 该方法将技能视为一种可优化的视觉提示，通过梯度下降直接调整像素，使模型在特定任务上表现更好，同时保持输入空间的通用性，便于跨模型共享。

### 6. 关键发现

- SKILL.PNG 显著优于文本技能: 在16个设置中，SKILL.PNG在9个设置中显著优于SkillOpt，尤其在T1和LiveMath上提升显著（最高+37.79点）。
- 图像技能更高效: SKILL.PNG仅需64-256个图像token，而文本技能平均需要937-1963个token，推理时更节省计算资源。
- 集成优化实现跨模型迁移: 在Qwen3.5-4B和Gemma-4-E4B-it上联合优化的图像，能提升两个模型的性能，甚至超过单模型优化的图像，但无法迁移到未参与优化的模型。

- 图来源: 图1：三种改进智能体的方式对比
- 为什么重要: 直观展示了SKILL.PNG与文本技能和LoRA的区别，强调其结合了梯度优化和跨模型迁移的优势。

### 8. 如何读这张图

图中对比了文本技能（无法梯度优化）、LoRA（模型特定）和SKILL.PNG（可梯度优化且跨模型迁移），突出SKILL.PNG在输入空间操作，无需修改模型权重。

### 9. 次重要图

- 为什么也重要: 图3展示了技能跨模型迁移的效果，说明集成优化能提升目标模型性能，但无法泛化到未见模型。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 提供了一种新的技能表示方式，使智能体可以通过图像技能快速适应新任务，且无需访问模型权重，便于在封闭模型上部署。
- 对 Skill: 技能不再局限于文本，图像技能可携带更丰富的视觉信息，且可通过梯度优化自动改进。
- 对 Memory: 图像技能可作为外部记忆存储，通过输入空间注入，减少对模型内部记忆的依赖。
- 对评测: 需要新的评估指标来比较不同模态技能的有效性和效率，以及跨模型迁移能力。

### 11. 局限性

- 图像技能在TRAJECT基准上未能提升性能，可能因为工具使用任务更依赖文本逻辑。
- 跨模型迁移仅限于集成中的模型，无法泛化到未见模型。
- 优化过程需要访问模型梯度，对于纯黑盒API可能不适用。

### 12. 我的看法 / 个人笔记

SKILL.PNG是一个创新且实用的方法，将技能优化与输入空间结合，为智能体技能学习提供了新思路。尽管存在迁移限制，但集成优化展示了多模型协同的潜力。未来可探索更通用的图像技能表示，以及结合文本和图像的混合技能。

### 14. 总结

SKILL.PNG通过梯度下降优化像素空间中的技能图像，使冻结的VLM获得可迁移的技能，在多个基准上超越文本技能，且推理时更高效。该方法首次实现了技能的可微优化与跨模型共享，为智能体技能学习开辟了新方向。

## 5. AgentRoboCritic: Understanding the Capability of Frontier Agents on Direct Robot Control

**Topics:** 机器人控制, 多模态语言智能体, 动作级评估
**Authors:** Yiyang Du, Yuxuan Kuang, Qitao Zhao, Yixuan Wang, Zhanqiu Guo, Yi Xu, Xin Li, Wenbin He, Liu Ren, Chenyan Xiong
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.26613v1) | [PDF](http://arxiv.org/pdf/2611.26613v1.pdf) | [Code](adu2021.github.io/blog/AgentRoboCritic)

### 1. 一句话结论

前沿多模态语言智能体（如GPT-6 Astra）在直接机器人控制中展现出闭环恢复、语义接地和零样本操作能力，但存在物理执行瓶颈，且动作级评估需要意图接地框架。

### 2. 为什么重要

现有基准仅报告回合级成功率，无法揭示智能体如何成功或失败。AgentRoboCritic通过意图接地的动作级分析，提供了细粒度的失败归因，有助于理解前沿智能体作为通用机器人策略的潜力与局限，并推动低成本动作级评估。

### 3. 研究问题

1. 前沿多模态语言智能体在直接机器人控制中的动作级能力与失败模式是什么？
2. 如何通过意图接地框架实现细粒度、良定义的动作级评估？

### 4. 背景与问题设定

机器人基础模型主要分为视觉-语言-动作模型（VLA）和世界-动作模型（WAM），但它们在分布外泛化和长时记忆方面存在不足，且需要任务特定微调。前沿多模态语言智能体（如GPT-6 Astra）可直接生成低层数值动作，无需高层原语，展现出零样本泛化潜力。然而，现有评估仅关注回合级成功率，无法揭示动作级行为。由于机器人操作具有多模态性，单个动作的成功与否取决于其局部意图，因此需要意图接地的评估框架。

### 5. 方法概览

- 任务 / 环境: 12个操作基准，包括模拟和真实环境，涵盖抓取、对齐、干扰等任务，具体包括RoboDojo、StationeryBench、Astranomy、UniVTAC、OpenViTac、ContactBench 1.0、LIBERO-MAX、Meta-World+、DexJoCo、RoboWits、RoboTwin 2.0和YAMLab。
- 变量 / 干预设计: 策略智能体在生成每个动作时附带局部意图（自然语言），形成意图接地轨迹；批评者（GPT-6 Astra）基于全局目标、局部意图和多视角观测评估动作结果并归因失败模式。
- 评价指标: 动作级结果（Achieved/Failed/Partial/Unverifiable）、失败模式分类准确率、与人类标注的一致性（Cohen's κ）。
- 模型比较: 比较GPT-6 Astra作为批评者与其他前沿模型（如Claude、GLM等）在人类标注基准上的表现；策略比较包括GPT-6 Astra与VLA/WAM（如π0.5、InternW0-Δ）的零样本成功率。
- 我的理解: 该方法通过让策略智能体自我声明意图，将动作评估从模糊的全局目标中解耦，使批评者能够基于局部意图和物理证据进行验证，从而提供可解释的失败归因。

### 6. 关键发现

- 闭环恢复能力: 49.8%的成功回合包含至少一次局部失败，表明智能体能够从错误中恢复并完成任务，与模仿学习策略的误差累积形成对比。
- 语义接地可靠: 跨不同场景，语义选择错误（CHOICE）罕见，表明智能体能可靠地遵循语言指令中的对象、类别和顺序。
- 物理执行瓶颈: 失败主要集中在抓取（GRASP）、对齐（ALIGNMENT）和干扰（INTERFERENCE）等物理执行环节，且对齐失败恢复率低于抓取失败。
- 批评者有效性: GPT-6 Astra作为批评者与人类标注高度一致（Cohen's κ达到0.80），而消融实验显示，移除意图接地后，失败模式分类准确率从74.24%下降至32.58%，表明意图接地对准确归因至关重要。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 前沿语言智能体可直接作为通用机器人策略，无需任务特定微调，但需改进物理执行能力（如抓取和对齐）。

- 对 Memory: 智能体展现出工作记忆能力，能利用交互历史进行闭环恢复。
- 对评测: 意图接地的动作级评估提供了更细粒度的性能度量，可替代回合级成功率。

### 11. 局限性

- 批评者依赖GPT-6 Astra，可能引入模型偏见；
- 动作级评估需要策略智能体声明意图，不适用于不提供意图的现有模型。

### 12. 我的看法 / 个人笔记

本文通过意图接地框架，系统分析了前沿智能体在直接机器人控制中的动作级行为，揭示了其闭环恢复和语义接地能力，同时指出物理执行瓶颈。该方法为机器人策略评估提供了新范式，但批评者依赖特定模型，且意图声明可能影响策略行为。未来可探索更通用的意图推断方法，并扩展至更多真实世界任务。
