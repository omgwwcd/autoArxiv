## 1. Continuous Actions from Discrete Minds: Latent-Aligned Planning for End-to-End Autonomous Driving

**Topics:** Autonomous Driving, Vision-Language-Action Models, Latent-Aligned Planning
**Authors:** Ruoyu Yao, Yusen Xie, Qingzhao Liu, Pei Liu, Zewei Yang, Yipeng Zhu, Xiaolong Wang, Jun Ma
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.04070v1) | [PDF](http://arxiv.org/pdf/2609.04070v1.pdf)

### 1. 一句话结论

LaPla 通过冻结的 VQ-VAE 解码器作为运动学先验，将连续潜空间规划与离散语义推理对齐，在闭环驾驶中提升成功率 33.34 个百分点并降低推理延迟。

### 2. 为什么重要

该工作解决了 VLA 模型中离散语义与连续动作之间的根本性不匹配：现有方法（动作分词化、双系统、扩散头）分别受限于量化误差、时空脱节或高延迟。LaPla 通过潜对齐规划实现了高效、平滑且物理合理的轨迹生成，为端到端自动驾驶的实际部署提供了新范式。

### 3. 研究问题

1. 如何弥合视觉-语言模型的离散推理与自动驾驶连续、物理约束动作之间的鸿沟？
2. 能否利用预训练的、冻结的运动学潜空间先验来简化 VLA 策略学习，同时避免量化误差和推理延迟？

### 4. 背景与问题设定

现有 VLA 方法面临三大挑战：动作分词化（如 AutoVLA）引入量化误差导致闭环不稳定；松散耦合的双系统设计（如 DriveVLM、Senna）造成时空脱节；扩散动作头（如 VAD）带来高推理延迟。LaPla 旨在通过潜对齐规划统一语义理解与精确运动执行。

### 5. 方法概览

- 任务 / 环境: 端到端自动驾驶，输入多视图图像、历史动作和导航指令，输出未来轨迹；在 nuScenes 数据集（开环）和 NVIDIA AlpaSim 模拟器（闭环）上评估。
- 变量 / 干预设计: 两阶段训练：第一阶段离线预训练残差 VQ-VAE（4 层残差码本，码本大小分别为 64、64、128、128），学习运动学先验并冻结解码器；第二阶段端到端训练 VLM 主干（Emu3-8B），使其直接预测连续潜变量，经冻结解码器生成轨迹，同时辅助 VQA 任务。
- 评价指标: 开环：长时域 L2 误差（米）；闭环：成功率（%）、推理延迟（毫秒）。
- 模型比较: 与现有 VLA 方法（动作分词化、松散耦合 VLM+规划器、扩散动作头）对比，LaPla 在开环长时域 L2 误差降低 15.52%，闭环成功率提升 33.34 个百分点，推理延迟显著降低（单次前向传播 vs. 扩散迭代去噪）。
- 我的理解: LaPla 的核心创新在于将 VQ-VAE 的离散瓶颈仅用于预训练阶段以学习运动学先验，而在规划阶段直接预测连续潜变量，从而既利用了离散表示的语义结构化优势（粗到细的层次化运动基元），又避免了量化误差，实现了高效、平滑的轨迹生成。

### 6. 关键发现

- 潜对齐规划消除量化误差: LaPla 通过直接预测连续潜变量并输入冻结的 VQ-VAE 解码器，避免了离散码本查找带来的量化误差，生成平滑且物理合理的轨迹。与动作分词化方法相比，闭环轨迹更稳定。
- 闭环性能显著提升: 在 AlpaSim 模拟器上，LaPla 将成功率提升 33.34 个百分点（从基线到 LaPla），同时推理延迟大幅降低（单次前向传播 vs. 扩散迭代去噪），优于现有 VLA 方法。
- 开环长时域漂移减少: 在 nuScenes 基准上，LaPla 将长时域 L2 误差降低 15.52%（与 SOTA VLA 方法相比），表明其轨迹预测在长时间范围内更稳定，缓解了误差累积。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: LaPla 的潜对齐范式可推广至其他需要连续控制的智能体系统（如机器人操作），通过预训练运动学先验简化策略学习，避免从零学习基本运动学。
- 对 Skill: 冻结的 VQ-VAE 解码器可作为通用运动技能先验，支持多种下游任务（如不同驾驶风格或机器人操作）而无需重新学习基本运动学。
- 对 Memory: 历史动作通过量化潜变量编码（粗到细层次），提供紧凑且语义丰富的运动记忆表示，有助于长期上下文理解。
- 对评测: 闭环评估（如 AlpaSim）对于验证 VLA 方法的实际稳定性至关重要，开环指标可能掩盖量化误差导致的长期漂移；LaPla 的闭环优势凸显了潜对齐规划的价值。

### 11. 局限性

- VQ-VAE 预训练依赖大规模轨迹数据，可能限制在数据稀缺场景的泛化。
- 当前框架仅考虑单一智能体规划，未处理多智能体交互（如行人、其他车辆）。
- 辅助 VQA 任务仅在训练时使用，推理时未利用，可能未充分挖掘语义理解潜力。

### 12. 我的看法 / 个人笔记

LaPla 通过冻结运动学先验巧妙地解耦了表示学习与策略学习，是 VLA 领域一个优雅且实用的进展。其连续潜预测策略避免了量化误差，同时保持了离散预训练的结构化优势（粗到细层次），闭环性能的大幅提升证明了该方法的有效性。未来工作可探索多智能体场景和更丰富的语义交互。

## 2. Translation as a Decision Space: A Multi-Agent Perspective on Low-Resource Dialect Generation

**Topics:** 多智能体系统, 低资源方言翻译, 可解释人工智能
**Authors:** Hasan Alkhder, Mohammad Abboush, Igor Tchappi, Ahmet Zengin, Amro Najjar
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.04048v1) | [PDF](http://arxiv.org/pdf/2609.04048v1.pdf)

### 1. 一句话结论

将翻译重构为决策空间，通过三种受控翻译路径（智能体）揭示多语言模型在低资源方言生成中的行为差异。

### 2. 为什么重要

传统NMT仅输出单一译文，掩盖了多语言解码中隐含的替代决策轨迹，尤其在低资源方言场景下，多种有效实现可能不同。本文提出将翻译视为决策空间，通过多智能体视角分析模型行为，为低资源方言生成提供可解释性框架。

### 3. 研究问题

1. 受控翻译路径变化能否揭示低资源方言翻译行为中的系统性、可解释性差异？
2. 不同翻译路径（零样本、方言稳定化、枢轴翻译）如何影响方言标记使用、词汇标准化和结构稳定性？

### 4. 背景与问题设定

神经机器翻译系统通常产生单一输出，掩盖了多语言解码中隐含的多种可能翻译轨迹。在低资源方言设置中，多种语言上有效的实现可能在词汇真实性、语域和结构稳定性上存在差异。现有评估指标（如BLEU、COMET）无法捕捉方言语域、标准化压力或路径间的行为差异。本文以土耳其语到叙利亚阿拉伯语翻译为案例，使用三个翻译智能体（零样本直接翻译、轻量微调方言稳定化翻译、通过英语的枢轴翻译）在5000句对话评估集上研究。

### 5. 方法概览

- 任务 / 环境: 土耳其语到叙利亚阿拉伯语的低资源方言翻译任务，评估集包含5000句对话，每个句子有土耳其语、叙利亚阿拉伯语、英语和现代标准阿拉伯语四种对齐表示。
- 变量 / 干预设计: 三个翻译智能体共享同一多语言骨干模型（固定架构和解码参数），仅路径约束不同：零样本直接翻译（无方言适应）、方言稳定化翻译（在5000句土耳其-叙利亚对上进行单周期轻量微调）、枢轴翻译（土耳其语→英语→叙利亚阿拉伯语）。
- 评价指标: 方言标记频率、与现代标准阿拉伯语的词汇接近度、结构长度方差，用于量化行为位移而非传统翻译质量。
- 模型比较: 比较三个智能体在方言标记使用、标准化压力和结构稳定性上的差异：稳定化智能体方言标记频率从0.2266增至0.4988，结构不稳定性显著降低；枢轴智能体引入标准化压力和压缩效应；零样本智能体决策方差最高。
- 我的理解: 本文的核心创新在于将翻译路径视为智能体，通过受控约束探索共享决策空间，从而将智能体间的分歧解释为结构化行为信号，而非错误。这种方法为分析低资源方言生成提供了新的可解释性视角。

### 6. 关键发现

- 轻量方言稳定化显著增强方言标记使用: 在5000句土耳其-叙利亚对上进行单周期微调后，方言标记频率从0.2266增加到0.4988，几乎翻倍，同时结构不稳定性显著降低。
- 枢轴翻译引入标准化压力和压缩效应: 通过英语的枢轴翻译导致输出向现代标准阿拉伯语标准化，并产生可测量的压缩效应（输出长度变化减小）。
- 零样本翻译表现出最高决策方差: 零样本直接翻译在方言标记使用、词汇选择和结构上具有最大变异性，反映了未充分指定的方言表示。

- 对 Agent 系统: 本文的智能体定义（作为受控解码路径）为多智能体系统提供了新视角：智能体可以是同一模型的不同约束配置，用于探索决策空间。

- 对评测: 提出行为指标（方言标记频率、词汇接近度、结构方差）替代传统质量指标，更适合分析方言生成中的权衡。

### 11. 局限性

- 智能体定义是抽象分析构造，而非经典多智能体系统中的自主实体，可能限制其直接应用。
- 仅针对土耳其-叙利亚阿拉伯语对，泛化到其他低资源方言需验证。
- 未评估翻译质量（如BLEU），仅关注行为差异，可能忽略语义准确性。

### 12. 我的看法 / 个人笔记

本文创新性地将翻译路径视为智能体，通过受控约束探索决策空间，为低资源方言生成提供了可解释性框架。其行为指标设计巧妙，但智能体定义的抽象性可能限制实际应用。未来可扩展到更多方言和模型架构。

## 3. Two-Stage Reinforcement Learning for Sound and Adversarial Test Generation in Code LLMs

**Topics:** 代码生成, 强化学习, 测试用例生成, 大语言模型, 推理时扩展
**Authors:** Jiacheng Xu, Wentao Zhang, Zhiyi Lyu, Fuxiang Zhang, Chaojie Wang, Yang Liu, Bo An
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.03955v1) | [PDF](http://arxiv.org/pdf/2609.03955v1.pdf)

### 1. 一句话结论

提出两阶段强化学习框架TCS，通过阶段1学习正确性（与真实解一致）和阶段2学习对抗性（对错误解失败），并利用策略对齐缓冲区动态跟踪求解器失败模式，显著提升代码LLM的测试用例生成质量和推理时选择性能。

### 2. 为什么重要

高质量测试用例是代码LLM可靠验证的关键，但现有方法难以同时保证正确性和判别性。TCS首次将测试生成建模为对抗性RL问题，并给出指数可靠性界（Proposition 1），为代码模型的自我验证和推理时扩展提供了理论支撑和实用范式。

### 3. 研究问题

1. 如何自动生成既正确（对参考解通过）又具判别性（对错误解失败）的测试用例？
2. 两阶段RL课程（先正确性后对抗性）能否比单阶段或离线监督更有效地训练测试生成器？
3. 自生成测试的推理时选择在何种条件下可靠？其错误概率如何随测试数量指数下降？

### 4. 背景与问题设定

代码LLM的强化学习依赖测试用例提供可执行反馈，但高质量测试用例稀缺。现有方法要么只优化代码生成，要么使用固定测试集，无法适应求解器不断变化的失败模式。本文提出在可执行验证的后训练环境中，利用真实解来监督测试生成，将问题形式化为对抗性RL：测试生成器需根据求解器当前失败模式生成反例。

### 5. 方法概览

- 任务 / 环境: 代码生成任务，每个训练实例包含问题描述、真实解C*和测试集T。模型同时扮演求解器（生成代码）和验证器（生成测试用例）。使用TACO数据集（筛选后6318个实例）训练，在TACO验证集（1000问题）和LiveCodeBench上评估。
- 变量 / 干预设计: 两阶段RL：阶段1训练测试生成器生成与C*一致的测试（正确性奖励Rt1，要求Exec(C*,Ig)=Og且(Ig,Og)不在示例测试中）；阶段2限制缓冲区B仅包含当前失败模式（可执行但错误的代码），训练生成反例测试（对抗性奖励Rt2，要求Exec(C*,Ig)=Og且Exec(Cwrong,Ig)≠Og）。使用GRPO更新策略，阶段1→阶段2切换阈值为训练批次测试准确率约0.75（1.5B模型200步，7B模型40步）。
- 评价指标: pass@1（TACO上16样本，LiveCodeBench上32样本）和Best-of-N选择（使用奖励模型InternLM2-7B-reward或自生成测试，N=16/32，M=1个测试/候选）。
- 模型比较: 在DeepSeek-R1-Distill-Qwen-1.5B和7B上评估，与基础模型、联合SFT基线（使用R1-Distill-Qwen-32B教师样本，含候选条件和真实解验证的对抗性测试）对比。
- 我的理解: 该方法巧妙地将测试生成分解为两个可优化目标：正确性（阶段1）和对抗性（阶段2），并通过在线RL循环让验证器跟踪求解器的演化错误分布。策略对齐缓冲区动态存储最近Tb步的求解器输出，确保验证器提示反映当前失败模式，避免了离线监督的静态性。

### 6. 关键发现

- TCS显著提升pass@1和推理时选择性能: 在TACO和LiveCodeBench上，TCS训练的模型在pass@1和自生成测试选择上均优于基础模型和联合SFT基线。例如，7B模型在LiveCodeBench上pass@1从28.56提升至37.03（TCS训练），自生成测试选择进一步达到48.79（无公开测试）和54.75（有公开测试）。
- 自生成测试在TCS后变得与奖励模型排名竞争甚至更强: 基础模型的自生成测试弱于奖励模型（7B：33.46 vs 35.19），但TCS后自生成测试选择在无公开测试时表现更好（48.79 vs 43.01），表明在线RL提升了测试的可靠性和判别性。
- 两阶段课程缓解了对抗性奖励的稀疏性问题: 直接优化阶段2的对抗性奖励（Rt2）会导致早期奖励几乎为零，但阶段1先学习正确性为阶段2提供了初始化，使模型能有效学习生成反例。
- 理论分析证明推理时选择的指数可靠性: Proposition 1给出错误选择概率上界为(N-1)exp(-K(δ-α)²/2)，其中K为测试数，δ为反例率，α为正确性错误率。阶段1降低α，阶段2提高δ，共同扩大指数衰减的速率。

## 4. WorldReward: Reward Modeling for Camera-Conditioned World Models

**Topics:** Camera-Conditioned World Models, Reward Modeling, Vision-Language Models, Video Generation
**Authors:** Yibin Wang, Zehan Wang, Junshu Tang, Zhimin Li, Yujie Zhou, Jiazi Bu, Pengyang Ling, Feng Han, Zhixiong Zhang, Long Xing, Shengyuan Ding, Ziang Li, Cheng Jin, Yuhang Zang, Jiaqi Wang, Tianyu Pang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.03952v1) | [PDF](http://arxiv.org/pdf/2609.03952v1.pdf) | [Code](https://codegoat24.github.io/WorldReward)

### 1. 一句话结论

WorldReward 是一个基于 VLM 的成对偏好奖励模型，通过将长视频分解为动作对齐的块并聚合块级决策，在单一模型中统一评估相机条件世界模型的动作一致性和视觉质量。

### 2. 为什么重要

该工作首次将动作一致性和视觉质量评估统一到单一 VLM 奖励模型中，解决了现有方法分别评估、无法捕捉局部动作证据的问题，为世界模型的强化学习后训练提供了更有效的奖励信号。

### 3. 研究问题

1. 如何设计一个统一的奖励模型，在单一 VLM 中同时评估相机条件世界模型的动作执行准确性和生成视频的视觉质量？
2. 如何通过局部到全局的推理范式，避免长视频中局部动作证据被稀释的问题？

### 4. 背景与问题设定

相机条件世界模型根据用户控制的相机/动作轨迹生成交互式视频，要求视频既准确执行命令动作，又保持几何、外观和时间动态的一致性。现有奖励模型要么只评估几何轨迹（如基于深度估计的方法），要么只评估帧级视觉质量（如 HPSv3），无法同时捕捉动作执行和视觉质量。直接使用 VLM 评估整个长视频会导致上下文过长，局部动作证据被稀释。

### 5. 方法概览

- 任务 / 环境: 相机条件世界模型生成的成对视频，每个视频对应相同的源图像、描述和动作轨迹。
- 变量 / 干预设计: 将长视频按动作序列分解为固定大小的块（每块4个动作），每个块构建结构化视觉输入（源图像、帧网格概览、动作级对比面板），VLM 对每个块分别推理动作一致性和视觉质量偏好，最后通过投票聚合为全局偏好。
- 评价指标: 与人类偏好的一致性（在 WorldReward-Bench 上按动作一致性、外观质量、运动质量三个维度评估）。
- 模型比较: 与 GPT-5.5、Gemini 3.1 Pro、HPSv3、DepthAnything3 等基线比较，WorldReward 在所有三个维度上取得最高一致性。
- 我的理解: 该方法的核心创新在于将长视频评估分解为局部块级推理，每个块包含紧凑的结构化证据，使 VLM 能够聚焦于每个动作的局部视觉变化，避免全局上下文的干扰。投票机制进一步平衡了各块的影响，且通过投票比例可输出连续偏好信号。

### 6. 关键发现

- WorldReward 在人类偏好一致性上超越所有基线: 在 WorldReward-Bench 上，WorldReward 在动作一致性、外观质量和运动质量三个维度上分别超过 GPT-5.5 3.42、1.45 和 3.56 个百分点。
- 块级推理和结构化证据设计至关重要: 消融实验表明，移除源图像、帧网格或动作级面板均会降低与人类偏好的一致性，结构化推理监督比仅偏好监督效果更好。
- 作为 RL 奖励信号有效提升世界模型性能: 使用 WorldReward 对 HY-WorldPlay 1.5 进行 RL 后训练，在短、中、长期生成中均改善了动作执行和视觉质量。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 为基于世界模型的智能体提供了更准确的奖励信号，有助于训练更可靠的动作执行策略。
- 对 Skill: 通过局部动作块推理，可更精细地评估每个动作的执行质量，有助于技能分解和细粒度优化。

### 11. 局限性

- 依赖前沿 VLM 进行数据蒸馏，可能引入教师模型的偏差。

### 12. 我的看法 / 个人笔记

WorldReward 通过巧妙的局部到全局推理设计，有效解决了长视频评估中局部证据稀释的问题，在单一 VLM 中统一了动作和视觉评估。其数据构建流程（蒸馏+代理审计+人工校准）是重要贡献，显著提升了奖励模型质量。未来可探索自适应块大小和连续奖励输出。

WorldReward 是一个基于 VLM 的成对偏好奖励模型，通过将长视频分解为动作对齐的块并聚合块级决策，在单一模型中统一评估相机条件世界模型的动作一致性和视觉质量。在 WorldReward-Bench 上超越所有基线，并有效提升 HY-WorldPlay 1.5 的 RL 后训练效果。

## 5. Bioinfoysis Technical Report
