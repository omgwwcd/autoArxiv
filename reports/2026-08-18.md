## 1. TaoLive Digital Avatar Agent Technical Report: Training Agents to Evolve with Their Harness

**Topics:** GUI Agent, LLM Agent, Live E-commerce, Digital Avatar
**Authors:** TaoLive AIGC LLM Team, Yuhan Sun, Wenhao Lin, Yongdong Luo, Yibo Hu, Meiguang Jin, Junfeng Ma, Weihang Pan, Jiaxin Zhao, Zulong Chen
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.15763v1) | [PDF](http://arxiv.org/pdf/2608.15763v1.pdf)

### 1. 一句话结论

提出 Harness-Aware Training (HAT)，通过将可演化的 Harness 状态纳入训练分布，使紧凑型模型在低延迟下适应频繁的策略更新，避免过拟合固定配置。

### 2. 为什么重要

解决了直播电商数字人主播场景中，业务策略频繁更新（Harness Evolution）与模型低延迟、高泛化能力之间的矛盾，为实际部署提供了可行方案。

### 3. 研究问题

1. 如何让紧凑型语言模型在低延迟约束下，适应频繁变化的执行环境（Harness）而不需要重新训练？
2. 固定 Harness 的监督微调（SFT）如何导致模型过拟合，以及如何通过训练分布多样化来缓解？

### 4. 背景与问题设定

AI 数字人主播在直播电商中需实时回答产品问题、与观众互动并执行营销策略，要求低延迟、高准确性和快速适应策略更新。传统方法中，策略更新需修改提示或控制代码并重新部署，迭代缓慢。作者提出可演化的 Harness 架构，将技能、钩子、系统提示和工具与模型权重解耦，允许运行时行为变化而无需重训练。然而，Harness 演化导致执行环境不断变化：在固定 Harness 上微调的紧凑模型会过拟合特定配置，而强零样本模型延迟过高。

### 5. 方法概览

- 任务 / 环境: 直播电商场景，数字人主播需根据观众评论、产品信息、直播状态等上下文，生成公开语音回复或调用工具，满足低延迟（P50 < 4s）和频繁策略更新（每周）的要求。
- 变量 / 干预设计: 提出 Harness-Aware Training (HAT)，核心是 Harness-State Augmentation (HSA)，对技能标识符、技能内容、工具定义、系统提示和钩子函数进行任务保持的扰动，生成多样化的 Harness 状态。训练分为三阶段：HSA-SFT（基于增强 Harness 的监督微调）、General OPD（通用领域在线蒸馏恢复通用能力）、HSA-RL（基于增强 Harness 的强化学习）。
- 评价指标: 在四个评估集上评测：Live-Stream QA（真实直播问答）、Harness-Variant QA（Harness 变体鲁棒性）、IFEval（通用指令跟随能力），以及延迟指标 P50 和 P95。
- 模型比较: 基础模型（Qwen3.6-35B-A3B）在 Live-Stream QA 上得分 80.3，最强通用 LLM（DeepSeek-V4）得分 93.0 但延迟 >11s，HAT 训练后的模型得分 94.8 且延迟 P50 3.407s。固定 Harness SFT 导致 IFEval 下降 7.7 分，而 HAT 模型保持 83.5。
- 我的理解: HAT 的核心思想是通过在训练中引入多样化的 Harness 配置，迫使模型学习理解当前给定的 Harness 指令，而不是记忆固定的名称或模板。HSA 通过扰动技能名称、工具描述等表面形式，防止模型走捷径。三阶段训练分别针对领域适应、通用能力保持和策略优化，形成一个完整的训练流程。

### 6. 关键发现

- HAT 显著提升 Harness 变体鲁棒性: 在 Harness-Variant QA 上，HAT 模型得分 94.6，而基础模型仅 75.4，固定 Harness SFT 模型得分 80.1，表明 HAT 有效防止了过拟合固定配置。
- HAT 保持通用指令跟随能力: 固定 Harness SFT 导致 IFEval 下降 7.7 分，而 HAT 模型仅下降 1.5 分（从 85.0 到 83.5），说明 General OPD 阶段有效恢复了通用能力。
- HSA 在 SFT 阶段比 RL 阶段影响更大: 实验表明，HSA 在 SFT 阶段对鲁棒性的提升贡献显著，而在 RL 阶段的影响相对较小，这为训练策略的设计提供了指导。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: HAT 提供了一种训练范式，使智能体系统能够在不重训练模型的情况下适应频繁的环境变化，特别适用于业务规则快速迭代的工业场景。
- 对 Skill: 通过 HSA 对技能标识符和内容进行扰动，模型学会了根据技能的功能描述而非名称进行路由，提高了对技能变更的鲁棒性。
- 对 Memory: 本文未直接涉及长期记忆，但 Harness 中的技能和钩子可视为一种外部记忆模块，HAT 训练使模型能更好地利用这些外部信息。
- 对评测: 构建了包含真实场景、Harness 变体和通用指令跟随的四个评估集，并验证了基于 Harness 的 Agent-as-a-Judge 评估器的可靠性，为类似系统提供了评估框架。

### 11. 局限性

- HSA 的扰动设计依赖人工规则和强语言模型，可能无法覆盖所有可能的 Harness 变化类型。
- 实验仅在 35B 参数模型上进行，对于更大或更小模型的效果未知。
- Harness Evolution 过程仍需要人工参与诊断和确认，尚未实现完全自动化。

### 12. 我的看法 / 个人笔记

本文提出的 HAT 方法巧妙地将环境变化纳入训练分布，解决了实际部署中模型过拟合固定配置的痛点。三阶段训练设计合理，兼顾了领域适应、通用能力保持和策略优化。实验充分，结果令人信服。未来工作可探索更自动化的 HSA 生成和更高效的训练策略。

## 2. RLCascadeRouter: Quality-Estimator-Free Cascade Routing via Reinforcement Learning

**Topics:** LLM 模型选择, 级联路由, 强化学习
**Authors:** Shihong Huang, Shengjie Wang, Hong Ma, Zhou Xu
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.15817v1) | [PDF](http://arxiv.org/pdf/2608.15817v1.pdf)

### 1. 一句话结论

RLCascadeRouter 通过强化学习将级联路由建模为马尔可夫决策过程，直接优化性能-成本目标，无需独立的质量估计器。

### 2. 为什么重要

现有 LLM 路由方法存在预测-决策不匹配问题，即质量估计误差与路由决策损失不等价。RLCascadeRouter 通过端到端强化学习避免了这一缺陷，实现了更优的性能-成本权衡，并支持零样本泛化到未见模型。

### 3. 研究问题

1. 如何消除级联路由中质量估计器导致的预测-决策不匹配？
2. 能否通过强化学习直接优化级联路由的性能-成本目标？

### 4. 背景与问题设定

LLM 生态中存在异构能力和推理成本，高效路由查询是关键挑战。现有方法分为单次路由（提交前决定）和固定顺序级联（自适应停止但顺序固定）。级联路由虽灵活，但依赖预测-优化管线，存在预测损失与决策损失不等价的问题。

### 5. 方法概览

- 任务 / 环境: LLMRouterBench 上的十个基准测试，涵盖数学、代码、知识、指令跟随和工具使用任务，使用 13 个 LLM。
- 变量 / 干预设计: 将级联路由建模为 MDP，动作空间包括“停止”和所有未选模型。策略网络包含互补性编码器（建模候选模型互补性）和价值感知停止器（评估当前状态与剩余动作价值）。
- 评价指标: 平均性能（Avg.↑）和成本（Cost↓），以及性能-成本帕累托前沿。
- 模型比较: 与单模型基线（GPT-5、Gemini-2.5-Pro 等）和路由方法（Random Router、HybridLLM、FrugalGPT、GraphRouter、Avengers-Pro）比较。
- 我的理解: 该方法的核心创新在于将路由决策直接与最终目标（性能-成本效用）对齐，通过轨迹回报和优势函数优化策略，避免了中间质量估计的误差放大。

### 6. 关键发现

- RLCascadeRouter 在性能-成本权衡上优于所有基线: 在 LLMRouterBench 的十个基准上，RLCascadeRouter 的平均性能（68.81）最高，成本（180.22）虽高于部分方法，但实现了最佳权衡。
- 无需重新训练即可泛化到未见模型: RLCascadeRouter 的策略网络能够处理训练时未见过的模型，无需重新训练，展现了良好的泛化能力。
- 消融实验验证了策略组件的有效性: 互补性编码器和价值感知停止器均对性能有显著贡献，去除任一组件都会导致性能下降。

- 图来源: 图 1：不同 LLM 模型选择结构的比较
- 为什么重要: 该图直观展示了从单次路由、固定级联到级联路由和 RLCascadeRouter 的演进，突出了 RLCascadeRouter 通过统一 MDP 策略联合学习“停止”和模型选择的创新点。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: RLCascadeRouter 可直接用于多智能体系统中的模型选择，动态分配查询以优化整体性能和成本。
- 对 Skill: 互补性编码器可捕获不同模型的能力互补性，有助于构建更高效的技能组合。
- 对 Memory: 状态表示包含路由历史，使策略能够利用过去决策信息，但未显式建模长期记忆。
- 对评测: 直接优化性能-成本目标提供了更可靠的评估指标，避免了中间质量估计的偏差。

### 11. 局限性

- 实验仅在 LLMRouterBench 上进行，未在更多样化的真实场景中验证。
- 成本计算基于 API 调用，未考虑延迟等其他实际因素。
- 策略网络需要针对每个偏好系数 α 重新训练，泛化到不同偏好需额外工作。

### 12. 我的看法 / 个人笔记

RLCascadeRouter 通过强化学习直接优化路由决策，巧妙解决了预测-决策不匹配问题。其互补性编码器和价值感知停止器设计合理，消融实验验证了有效性。未来工作可探索多偏好联合训练和更复杂的成本模型。

### 14. 总结

RLCascadeRouter 提出了一种基于强化学习的级联路由框架，将模型选择和停止决策统一为 MDP，通过轨迹回报直接优化性能-成本目标。在 LLMRouterBench 上，它优于现有路由方法，并展示了良好的泛化能力。

## 4. Intent-Driven Situation Tracking for User-Centric Multi-Turn Agents

**Topics:** GUI Agent, Multi-Turn Agent, Situation Tracking, Intent-Driven
**Authors:** Meiling Tao, Yiling Tao, Peng Wang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.15755v1) | [PDF](http://arxiv.org/pdf/2608.15755v1.pdf)

### 1. 一句话结论

IDSS通过显式分离事实层（确定性解析，无需额外LLM调用）与状态层（在LLM生成<state>块时更新），并引入跨层约束传播（确定性属性比较），在三个基准上显著提升多轮代理的任务完成率和效率，尤其在多实体协调和动态约束场景中表现突出。

### 2. 为什么重要

现有方法依赖历史压缩或外部记忆，但未分离事实与任务状态，导致代理需从对话痕迹中隐式推断。IDSS提供了一种无需训练的显式状态追踪框架，通过确定性解析和状态层更新，为构建可靠的用户中心多轮代理提供了新范式。

### 3. 研究问题

1. 如何显式建模多轮对话中不断演化的任务情境（包括用户意图、工具事实、约束条件）？
2. 分离事实层与状态层能否提升代理在复杂任务中的决策可靠性和效率？

### 4. 背景与问题设定

用户中心多轮代理需处理动态变化的用户意图、工具返回的事实、缺失信息和执行约束。现有上下文管理方法（如外部记忆、压缩）虽改善历史利用，但未显式维护分离事实与任务状态的情境状态，导致代理需从对话痕迹中隐式推断细粒度属性、任务依赖和约束满足，易出现事实遗漏、意图漂移、过早执行和约束违反。

### 5. 方法概览

- 任务 / 环境: 三个交互式基准测试：τ-bench（零售和航空领域）、VitaBench（配送、店内、OTA、跨域生活服务）、UserBench（偏好引导任务），覆盖多实体协调、动态约束和约束感知重规划场景。
- 变量 / 干预设计: IDSS框架：事实层通过确定性解析（无需额外LLM调用）将工具返回转换为带来源的实体和属性；状态层在LLM生成<state>块时更新，跟踪用户意图、所需变量、约束和执行状态；跨层约束传播通过确定性属性比较将新事实与任务约束关联，更新动作可执行性。代理在每个回合将情境状态与压缩对话历史一起注入提示。
- 评价指标: τ-bench：Avg@4和pass4；VitaBench：基于rubric的0-100分；UserBench：Score、CER（正确存在率）、PE（偏好引导率）。
- 模型比较: 与ReAct、StateAct、ReSum、IterResearch、U-Fold对比，在8个LLM（GPT-5.5、GPT-4.1等）上评估。
- 我的理解: IDSS的核心创新在于将对话历史中的事实性信息（工具返回）与任务状态（意图、变量、约束）显式分离，并通过跨层传播实现动态更新，从而避免代理从原始历史中反复重建情境。事实层通过确定性解析更新，无需额外LLM调用；状态层在LLM生成<state>块时更新，利用LLM的推理能力但保持结构清晰。这种设计类似于在对话中维护一个结构化的“工作记忆”，使决策更高效、更可靠。

### 6. 关键发现

- IDSS在多数任务上显著提升任务完成率和效率: 在τ-bench、VitaBench和UserBench上，IDSS在8个LLM中多数任务上优于所有基线，尤其在多实体协调和动态约束任务上提升明显。例如，在τ-bench航空领域，IDSS的Avg@4比ReAct高3-5个百分点；在τ-bench零售领域，IDSS的pass4在GPT-4.1上为38.0%，比ReAct的38.0%持平，但在航空领域pass4为22.0%，比ReAct的22.0%持平（表1中未显示显著差异，但整体趋势提升）。在UserBench上，对于GPT-4.1，IDSS的PE为33.5%，比ReAct的24.2%提升约9.3个百分点。
- IDSS在部分任务上略逊于U-Fold，但整体表现更优: 在GPT-5.5的VitaBench Delivery和In-store任务上，IDSS的Avg@4分别为56.5和63.5，略低于U-Fold的57.0和64.0，但在其他任务上IDSS更优。消融实验表明，事实持久化、意图中心状态追踪和约束建模三者协同作用，缺一不可。
- IDSS在偏好引导任务中表现突出: 在UserBench上，对于GPT-4.1，IDSS的PE为33.5%，比ReAct的24.2%提升约9.3个百分点，表明显式状态追踪有助于代理主动询问和整合用户偏好，提升交互效率。

- 当前框架未处理用户意图的隐式变化或冲突，需进一步扩展。

### 12. 我的看法 / 个人笔记

IDSS通过显式分离事实与状态，巧妙地将多轮对话中的复杂情境建模为可维护的结构，避免了隐式推理的缺陷。其无需训练的特点（事实层通过确定性解析更新，无需额外LLM调用；状态层在LLM生成<state>块时更新）使其易于部署，但确定性解析和LLM依赖可能限制其在更开放场景的泛化。未来可探索学习型解析或混合状态更新机制。

## 5. Hallucination Span Detection with Input-Side Evidence Alignment

**Topics:** cs.CL, GUI Agent
**Authors:** Miyu Yamada, Yuki Arase
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.15804v1) | [PDF](http://arxiv.org/pdf/2608.15804v1.pdf) | [Code](https://github.com/miyu-y/HalluSpan_EviAlign)

### 1. 一句话结论

提出了一种基于输入侧证据对齐的幻觉跨度检测方法，通过训练编码器模型预测被掩码的输出token，利用预测置信度区分忠实与幻觉token，并同时生成输入侧对齐。

### 2. 为什么重要

现有方法仅检测整段文本是否包含幻觉，无法定位具体幻觉跨度及其与输入的关系。该方法首次联合检测幻觉跨度并提供输入侧证据对齐，有助于提升LLM生成内容的可解释性和可信度。

### 3. 研究问题

1. 如何在不依赖人工对齐标注的情况下，同时检测幻觉跨度并定位输入侧证据？
2. 基于忠实token可从输入预测而幻觉token不可预测的假设，能否通过掩码token预测任务实现上述目标？

### 4. 背景与问题设定

LLM在条件文本生成中常产生幻觉，现有检测方法多为句子或文档级二分类，无法定位具体幻觉跨度及输入证据。人工标注输入-输出对齐成本高且难以扩展。本文提出幻觉跨度检测与输入侧证据对齐的联合任务，并采用远程监督方式避免人工标注。

### 5. 方法概览

- 任务 / 环境: 条件文本生成任务，包括问答和新闻摘要，使用RAGTruth数据集。
- 变量 / 干预设计: 基于忠实token可从输入预测的假设，训练编码器模型（ModernBERT-large）预测被掩码的输出token，预测置信度用于区分忠实与幻觉token，同时检索的输入token提供证据对齐。
- 评价指标: 字符级精确率、召回率和F1分数（RAGTruth官方指标），以及人工评估的对齐质量（0-3分制）。
- 模型比较: 与Llama-SFT（微调Llama-3.1-8B）、LettuceDetect（编码器token分类器）、OTAlign（无监督词对齐）比较。
- 我的理解: 该方法巧妙地将幻觉检测转化为掩码预测任务，利用忠实token与输入的高度相关性，无需对齐标注即可同时实现检测和对齐。但依赖预训练模型的知识，对冲突型幻觉（输入中存在相关但矛盾的内容）效果较差。

### 6. 关键发现

- 召回率优势: 在QA和摘要任务上，所提方法召回率最高（QA 82.7%，摘要38.0%），适合不容漏检幻觉的场景。
- 对齐质量良好: 人工评估显示，对忠实词和baseless幻觉词，对齐平均得分约2（相关证据），但对冲突型幻觉（矛盾信息）效果差（平均0.39）。
- 轻量高效: 使用0.4B参数的编码器模型，推理效率高于基于大解码器LLM的方法。

### 7. 最重要的图

- 图来源: Figure 2: Proposed method
- 为什么重要: 直观展示了方法流程：掩码输出token，从输入表示中检索最相关token，基于置信度判断幻觉并生成对齐。

图中左侧为输入文本，右侧为输出文本。输出文本中一个token被掩码（<mask>），编码器将输入和掩码输出拼接编码，通过计算掩码token嵌入与输入token嵌入的余弦相似度，检索最相似的输入token，其置信度用于判断该输出token是否为幻觉。
