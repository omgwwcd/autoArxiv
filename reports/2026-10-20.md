## 1. RefCraft: Benchmarking Visual-Reference-Conditioned Agentic Generation through Web Development

**Topics:** GUI Agent, 视觉参考条件生成, 网页开发基准
**Authors:** Yuchi Wang, Rongyao Fang, Weihao Yu, Xilin Wei, Tiancheng Gu, Dingkang Yang, Hang Zhang, Dayiheng Liu, Hongsheng Li, Shuai Bai
**Venue / Year:** 预印本（2026）
**Links:** [Abstract](http://arxiv.org/abs/2610.26826v1) | [PDF](http://arxiv.org/pdf/2610.26826v1.pdf) | [Code](https://wangyuchi369.github.io/refcraft/)

### 1. 一句话结论

RefCraft 基准测试表明，当前最先进的多模态大模型在视觉参考条件下的智能体网页生成任务中表现不佳，最佳系统得分仅为 52.12/100。

### 2. 为什么重要

该研究填补了现有网页开发基准的空白，强调视觉参考在智能体生成中的关键作用，为评估和提升 AI 智能体在真实生产力任务中的能力提供了新标准。

### 3. 研究问题

1. 如何评估智能体在视觉参考条件下的生成能力？
2. 当前多模态大模型在视觉参考条件下的网页开发任务中表现如何？

### 4. 背景与问题设定

现有网页开发基准主要关注从文本指令生成或从截图重建，忽略了实际工作中常见的从视觉示例进行开发的工作流。RefCraft 旨在通过结合自然语言指令和参考网页截图的任务，评估智能体选择性解释和利用视觉参考的能力。

### 5. 方法概览

- 任务 / 环境: 使用统一的编码智能体环境（opencode），智能体可渲染、截图、检查并迭代修改网页，最终输出单个自包含的 HTML 文件。
- 变量 / 干预设计: 每个任务包含 1-5 个参考网页截图，要求智能体根据指令复制、改编、反转或忽略参考中的特定视觉维度（如布局、调色板、排版等）。
- 评价指标: 采用双轨评估：程序化评判器验证确定性关键点（如颜色距离、响应式行为），VLM 评判器评估语义和感知关键点。最终得分由基础关键点得分、核心功能得分和参考遵循得分综合得出。
- 模型比较: 评估了 9 个前沿多模态大模型，包括 GPT-6 Astra、Qwen3.8-Max、Grok 4.6 等。
- 我的理解: 该基准通过将任务分解为可验证的关键点，结合程序化检查和 VLM 判断，实现了对开放式生成任务的可靠评估，同时避免了单一相似度指标的局限性。

### 6. 关键发现

- 最佳模型得分仅 52.12: 在 9 个前沿模型中，GPT-6 Astra 得分最高，但总分仅为 52.12/100，表明视觉参考条件下的智能体生成仍远未解决。
- 模型在参考遵循上存在困难: 模型往往能生成视觉上相似的网页，但难以准确实现指令中指定的参考关系（如复制布局、改编调色板），导致参考遵循得分较低。

## 2. Which Model for Which Role? Cost-Efficient Pareto Recommendation for LLM Agentic Workflows

**Topics:** LLM Agentic Workflows, Pareto Recommendation, Cost-Efficient Search, Gittins Index
**Authors:** Qian Xie, Wenyue Hua, Yueli He, Sripad Karne, Armaan Agrawal, Nikos Pagonas, Eugene Wu, Kostis Kaffes, Tianyi Peng, Nairen Cao
**Venue / Year:** Preprint
**Links:** [Abstract](http://arxiv.org/abs/2610.26676v1) | [PDF](http://arxiv.org/pdf/2610.26676v1.pdf) | [Code](github.com/AgentOptimizer/agentopt-research)

### 1. 一句话结论

提出成本耦合Gittins（CC-Gittins）算法，以约10%的穷举评估成本恢复大部分真实Pareto前沿，实现LLM代理工作流中模型分配的多目标成本高效推荐。

### 2. 为什么重要

LLM代理工作流中不同角色使用不同模型，但寻找最优分配需要昂贵的评估。CC-Gittins通过利用评估成本与部署成本的耦合，显著降低搜索成本，同时提供高质量的Pareto推荐，有助于在实际部署中平衡质量、成本和延迟。

### 3. 研究问题

1. 如何在多角色LLM工作流中，以最小评估成本推荐一组覆盖质量-成本权衡的模型分配？
2. 如何利用部署成本与评估成本之间的耦合来指导搜索，从而高效发现Pareto最优分配？

### 4. 背景与问题设定

LLM代理工作流通常包含多个角色（如规划、求解、搜索、验证），每个角色可选用不同模型。由于角色间交互，整体质量不能通过单独评估模型推断，必须将整个工作流作为评估单元。用户希望比较不同质量-成本权衡的分配，但穷举评估所有分配（数量随角色和模型数指数增长）成本过高。现有方法如TeamBench、AgentCARD、AgentOpt等或仅报告已评估分配的边界，或优化单一目标，未提供随时可用的Pareto推荐。

### 5. 方法概览

- 任务 / 环境: 多角色LLM代理工作流，每个角色有候选模型集合，目标是找到质量-成本（及可选延迟）的Pareto最优分配。
- 变量 / 干预设计: 提出CC-Gittins算法，使用两个控制器（质量控制器和成本控制器）交替选择评估分配。每个控制器使用成本感知的Gittins指数，该指数包含评估成本惩罚项。控制器共享观测数据，更新后验分布。当控制器停止时，通过减半其评估成本权重来放松惩罚，继续搜索。推荐集由不确定性调整后的质量下界和成本上界非支配的分配组成。
- 评价指标: 使用超体积遗憾（HV regret）、世代距离（GD）和逆世代距离（IGD）评估推荐集与真实Pareto前沿的接近程度和覆盖度。
- 模型比较: 与五种基线方法比较：随机搜索、贪心搜索、UCB、EHVI和AgentOpt（固定加权和）。
- 我的理解: CC-Gittins的核心创新在于将评估成本显式纳入Gittins指数，并利用部署成本与评估成本的正比关系，使得搜索过程自然偏向低成本分配，同时通过双控制器交替探索质量与成本维度，实现多目标优化。

### 6. 关键发现

- 成本耦合显著提升搜索效率: 在八个基准上，CC-Gittins以约10%的穷举评估成本恢复了大部分真实Pareto前沿，平均召回率88.75%，精确率100%（BIRD Dev）。
- 双控制器设计有效平衡质量与成本: 质量控制器和成本控制器交替工作，分别优化质量与成本，共享观测数据，使得推荐集覆盖广泛的质量-成本权衡。
- 延迟作为第三目标时仍有效: 在HotpotQA和MathQA上，加入延迟目标后，CC-Gittins仍能高效恢复Pareto前沿，表明方法可扩展至更多目标。

## 3. OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory

**Topics:** 多模态大语言模型, 视觉智能体, 工具使用, 多模态记忆
**Authors:** Yu Zhou, Cheng-Fu Yang, Rui Sun, Di Wu, Sibo Peng, Mingyang Zhang, Zhen Yang, Ruiyi Zhang, Nanyun Peng, Zhe Gan, Kai-Wei Chang
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.26860v1) | [PDF](http://arxiv.org/pdf/2610.26860v1.pdf) | [Code](https://github.com/uclanlp/OpenVLHarness)

### 1. 一句话结论

OpenVLHarness通过能力层和持久多模态记忆，将异构工具输出转化为模型可读证据并支持跨步骤复用，在22个基准上平均提升9.7-12.6个百分点，且比现有方法更省token。

### 2. 为什么重要

该工作揭示了单纯增加推理预算对多模态推理提升有限，而通过工具获取外部证据并持久化记忆是突破瓶颈的关键，为构建通用视觉智能体提供了新范式。

### 3. 研究问题

1. 如何统一异构工具接口并使其输出对MLLM可解释？
2. 如何持久化多模态证据以支持跨步骤的复杂推理？
3. 工具获取证据与推理时扩展是否互补？

### 4. 背景与问题设定

多模态大语言模型在视觉推理上进步迅速，但许多真实任务需要模型无法从输入直接推断的证据，如密集场景中的小目标定位、长尾知识检索、数值测量等。现有方法依赖内部推理，但增加推理预算收益甚微。因此需要连接外部工具获取证据，但面临工具异构和证据难以跨步骤复用两大挑战。

### 5. 方法概览

- 任务 / 环境: 22个多模态基准，涵盖接地感知、视觉搜索与深度研究、通用VQA与幻觉、空间推理等任务。
- 变量 / 干预设计: 对比OpenVLHarness与无工具基线、现有工具使用基线（Codex、Visual Sketchpad），并控制推理努力程度（如medium vs max）。
- 评价指标: 各基准的平均得分（%），以及模型token成本（美元）。
- 模型比较: 使用8种开源和专有MLLM骨干，包括Qwen3-VL-8B/32B、Kimi K3、GPT-6 Astra/Luna/Sol等。
- 我的理解: OpenVLHarness的核心是两层设计：能力层提供任务级工具接口和证据渲染，将分割掩码、深度图等异构输出转化为模型可读的视觉+文本描述；持久多模态记忆则存储图像、结构化数据、网页引用等工件，供后续步骤通过句柄调用，甚至支持Python代码对存储数据进行计算。

### 6. 关键发现

- 显著提升多模态推理性能: 在22个基准上，OpenVLHarness平均提升9.7-12.6个百分点，例如Qwen3-VL-8B提升11.2，Kimi K3提升9.7，GPT-6 Astra提升9.9。
- 优于现有工具使用基线且更高效: GPT-6 Luna（medium）配合OpenVLHarness，性能超过基础模型、Codex和Visual Sketchpad在最大推理努力下的表现，且token成本最多仅为它们的37%。
- 推理预算增加收益递减: 基础模型从xhigh到max努力，token花费增加2.7倍，但平均得分仅提升0.7分，说明单纯增加推理计算不如获取外部证据有效。

- 为什么重要: 该图直观展示了OpenVLHarness在性能-成本权衡上的优势，证明其能以更低token成本达到更高得分，凸显了工具获取证据的价值。

横轴为平均模型token成本（美元），纵轴为平均得分（%）。每个点代表不同推理努力设置下的模型配置。OpenVLHarness的点位于左上区域，表明在较低成本下获得较高得分，而基线和现有方法位于右下，成本高且得分低。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: OpenVLHarness提供了一种可复用的工具集成框架，使智能体能够灵活调用异构工具并持久化证据，有助于构建更强大的通用视觉智能体。
- 对 Skill: 能力层的任务级接口设计使得工具可替换、可扩展，支持通过编码智能体自动组合新工具，降低技能开发的成本。
- 对 Memory: 持久多模态记忆是核心创新，它允许智能体跨步骤保留和复用图像、数据等工件，支持复杂推理链，对记忆机制的设计有重要启示。
- 对评测: 该工作提供了22个基准的全面评估，并考虑了成本因素，为评估工具使用智能体提供了更全面的指标。

### 11. 局限性

- 对工具质量的依赖：性能受限于底层工具（如分割、深度估计）的准确性，工具失败可能导致错误证据。
- 记忆管理开销：持久化存储大量多模态工件可能带来内存和计算开销，长期任务中需考虑遗忘或压缩策略。
- 领域泛化：当前评估集中于视觉任务，扩展到其他模态（如音频、3D）或特定垂直领域时可能需要调整接口和记忆格式。

### 12. 我的看法 / 个人笔记

OpenVLHarness通过能力层和记忆机制有效解决了工具使用中的两大难题，实验证明其显著优于现有方法。未来可探索更智能的记忆管理策略和更复杂的工具组合，以及如何将证据获取与推理时扩展更紧密地结合。

### 14. 总结

OpenVLHarness是一个多模态推理框架，通过能力层统一工具接口并渲染证据，通过持久多模态记忆保留可复用工件，支持迭代式证据获取与计算。在22个基准上，它平均提升9.7-12.6个百分点，且比现有工具使用基线更高效，证明了外部证据获取与记忆机制对多模态推理的重要性。

## 4. Cooperative Multi-Agent Reinforcement Learning for Market Making on Prediction-Market Order Books

**Topics:** 多智能体强化学习, 做市策略, 预测市场, 订单簿建模
**Authors:** Skander Lejmi
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.26789v1) | [PDF](http://arxiv.org/pdf/2610.26789v1.pdf)

### 1. 一句话结论

通过将做市商分解为报价员和风险管理员两个协作智能体，并精心设计奖励函数，在预测市场薄订单簿环境下显著提升了做市表现。

### 2. 为什么重要

预测市场（如Polymarket）的订单簿较薄，传统做市模型容易因逆向选择而失效。该研究首次将多智能体强化学习应用于预测市场做市，通过任务分解和奖励塑形解决了信用分配难题，为流动性提供和风险管理提供了新思路。

### 3. 研究问题

1. 如何利用多智能体强化学习在预测市场的薄订单簿环境中进行有效做市？
2. 如何通过任务分解（报价员与风险管理员）和奖励塑形缓解多智能体信用分配问题？

### 4. 背景与问题设定

做市商通过连续报价买卖价差获利，同时管理库存风险。预测市场（如Polymarket）订单簿较薄，存在逆向选择、延迟奖励和缺乏订单级数据等挑战。现有模拟器（如基于布朗运动的模型）低估了逆向选择，导致模拟与真实差距大。本文使用真实历史L2数据重建订单级数据，并在JaxMARL-HFT环境中训练智能体。

### 5. 方法概览

- 任务 / 环境: JaxMARL-HFT环境，基于417个真实Polymarket市场重建的订单簿数据（LOBSTER格式），每个市场为二元合约，到期支付0或1。
- 变量 / 干预设计: 对比多种配置：基线（JaxMARL-HFT默认）、单智能体改进（丰富观测、动作空间、库存控制）、多智能体分解（报价员+风险管理员）及不同奖励塑形（奖励混合、成交后标记）。
- 评价指标: 持有期（held-out）市场上的期末投资组合价值（最终收益）。
- 模型比较: 基线：JaxMARL-HFT默认配置；改进单智能体；多智能体分解（IPPO）及不同奖励设计。
- 我的理解: 该方法将做市任务分解为两个子任务：报价员负责持续报价，风险管理员负责监控库存并调整报价或暂停交易。通过独立训练两个智能体，并设计奖励函数（如混合奖励和成交后标记）来协调它们的行为，从而在薄订单簿环境中实现更稳健的做市策略。

### 6. 关键发现

- 多智能体分解与奖励塑形显著提升表现: 精心设计的奖励塑形（混合奖励和成交后标记）使多智能体分解的做市商在持有期测试中表现最佳，优于未塑形的分解和单智能体配置。
- 丰富观测和动作空间改善单智能体表现: 增加订单簿和近期流观测、允许非对称报价和单边报价，以及引入库存上限和止损，使单智能体比基线更频繁报价且持有期损失更小。
- 所有配置均未实现正平均收益: 尽管改进显著，但所有模型在持有期测试中平均收益仍为负，表明预测市场做市难度大，需要进一步优化。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 多智能体分解（任务分工）可有效处理复杂决策问题，通过独立训练和奖励塑形实现协作，适用于其他需要分工的智能体系统。
- 对 Skill: 做市技能可分解为报价和风险管理两个子技能，分别优化后再协调，有助于技能的可复用性和可组合性。
- 对 Memory: 循环策略（RNN）的使用表明记忆历史信息对处理延迟奖励和部分可观测性至关重要，未来可探索更复杂的记忆机制。
- 对评测: 持有期收益评估比训练集评估更可靠，建议在类似金融场景中采用严格的样本外测试。

### 11. 局限性

- 所有配置均未实现正平均收益，表明策略仍有较大改进空间。
- 仅使用单一随机种子训练，结果可能不稳定，需多次重复实验验证。
- 未对多智能体分解的贡献进行消融分析，无法确定分解本身还是奖励塑形起主要作用。
- 数据重建过程可能引入误差，影响模拟真实性。

### 12. 我的看法 / 个人笔记

该研究为预测市场做市提供了新颖的多智能体框架，通过任务分解和奖励塑形有效缓解了信用分配问题，但结果未盈利，说明问题难度大。未来可尝试更复杂的奖励设计、集中训练或利用市场间关联。

## 5. SpatialScout: Can VLM Agents Actively Explore and Map 3D Scenes?

**Topics:** 视觉语言模型, 主动探索, 3D场景理解, 空间智能, 具身智能
**Authors:** Zhaoxi Zhang, Hao Liang, Linxuan Wu, Yiming Wu, Yifu Yuan, Kun Liang, Chenming Tang, Meiyi Qiang, Wentao Zhang, Weikang Li
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.26659v1) | [PDF](http://arxiv.org/pdf/2610.26659v1.pdf) | [Code](https://github.com/JesseZZZZZ/SpatialScout)

### 1. 一句话结论

SpatialScout基准测试表明，当前最强的VLM智能体在主动探索并构建精确3D物体地图方面仍存在显著不足，最高平均IoU仅41.71%。

### 2. 为什么重要

该工作首次将主动探索与连续3D空间中的物体级建图作为直接评估目标，弥补了现有空间问答基准无法衡量智能体自主构建空间表征能力的缺陷，为空间智能研究提供了更严格的测试平台。

### 3. 研究问题

1. VLM智能体能否通过主动探索在连续3D空间中构建准确的物体级地图？
2. 当前最先进的VLM智能体在主动探索、跨视角关联、几何估计和地图更新等环节中存在哪些具体局限？

### 4. 背景与问题设定

空间智能要求智能体主动获取视觉证据并整合为一致的三维世界表征。现有空间智能基准多采用问答形式，仅评估答案正确性，无法反映智能体自主探索和构建空间表征的能力。SpatialScout提出一个主动物体级3D建图任务，要求智能体在有限的交互预算内，通过控制相机探索场景，并输出目标物体中心的三维坐标，以端到端评估其空间智能。

### 5. 方法概览

- 任务 / 环境: 80个室内场景（来自iTHOR、RoboTHOR、ArchitecTHOR、ReplicaCAD、ProcTHOR），共3140个目标物体，每个场景30-40个目标，场景半径1.95-9.23米。
- 变量 / 干预设计: 智能体通过10种工具与场景交互，包括移动相机、旋转相机、捕获图像、三角测量等。每个场景限制100次模型调用和100张图像。智能体需根据当前观察和已有地图选择下一步动作，并最终提交所有目标物体的中心坐标。
- 评价指标: 以物体尺度IoU为核心指标，计算所有目标（遗漏计0）和已提交目标的平均IoU，并报告IoU>0、>0.5、>0.9的命中率。
- 模型比较: 评估了7个前沿VLM：GPT-6 Astra、GPT-6 Sol、Claude Opus 5.5、Claude Sonnet 5.5、Kimi-K3、Qwen3.8-Max、DeepSeek-V4.1-Flash。
- 我的理解: 该任务设计巧妙，将空间智能分解为探索、感知、关联、几何估计和地图更新等多个环节，并通过最终地图质量进行端到端评估，避免了问答任务中语言先验的干扰。

### 6. 关键发现

- 整体性能有限: 最佳模型Claude Opus 5.5的平均IoU仅为41.71%，IoU>0.5的命中率47.23%，IoU>0.9的命中率仅3.25%，表明精确建图能力严重不足。
- 遗漏是主要问题: 所有模型都存在大量目标遗漏，即使提交的目标中，高精度匹配比例也很低，说明智能体难以全面覆盖场景中的目标。
- 工具使用模式差异: Claude Opus 5.5使用工具最多，性能最好；GPT-6 Astra以较少的调用达到接近的性能；而DeepSeek-V4.1-Flash和Qwen3.8-Max在后期观察减少，导致性能下降。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 当前VLM智能体在长期探索和空间记忆方面存在明显短板，需要开发更有效的探索策略和记忆机制。
- 对 Skill: 智能体需要提升跨视角物体关联和几何估计能力，以支持精确的3D定位。
- 对 Memory: 持续更新和维护3D地图的能力至关重要，模型需要更好地整合多视角信息。
- 对评测: SpatialScout提供了一种可量化的端到端评估方法，可推广到其他空间智能任务。

### 11. 局限性

- 基准场景数量有限（80个），且主要来自合成环境，可能无法完全反映真实世界的复杂性。
- 评估仅关注物体中心位置，未考虑物体朝向、形状等更丰富的空间属性。
- 模型调用和图像数量限制可能限制了智能体的探索深度，但这也反映了实际部署中的资源约束。

### 12. 我的看法 / 个人笔记

SpatialScout是一个设计精良的基准，揭示了VLM智能体在主动3D建图上的巨大提升空间。未来工作可探索更高效的探索策略、更好的跨视图特征匹配，以及利用深度信息或3D先验来提升定位精度。

### 14. 总结

SpatialScout通过主动物体级3D建图任务，评估了7个前沿VLM智能体的空间智能。结果显示，最佳模型平均IoU仅41.71%，高精度匹配率极低，表明智能体在主动探索、跨视角关联和精确几何估计方面存在显著不足。该基准为空间智能研究提供了新的测试平台，并指出了未来改进方向。
