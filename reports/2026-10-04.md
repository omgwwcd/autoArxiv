## 1. Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents

**Topics:** 机器人操作, 具身智能, 多模态大模型, 技能库学习, 仿真到现实迁移
**Authors:** Yen-Jen Wang, Haozhe Jiang, Shuying Deng, Haoru Xue, Weirui Ye, Rocky Duan, Nika Haghtalab, S. Shankar Sastry, Pieter Abbeel, Haozhi Qi
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02204v1) | [PDF](http://arxiv.org/pdf/2610.02204v1.pdf) | [Code](https://rpg-robot.github.io)

### 1. 一句话结论

RPG框架通过从离线数据构建仿真练习任务，利用特权状态和视频分析自主改进共享技能库与系统提示，无需更新模型权重，在22个模拟任务上达到95.0%成功率，并在真实机器人上30/30成功。

### 2. 为什么重要

该工作提出了一种无需权重更新的自主改进框架，通过仿真练习和跨任务验证，使机器人系统在模拟和真实环境中均取得显著性能提升，为降低机器人技能开发的人力成本提供了新思路。

### 3. 研究问题

1. 如何从离线数据中自动构建仿真练习任务以提升机器人操作能力？
2. 如何利用执行反馈和特权状态自主改进共享技能库与系统提示？
3. RPG框架在模拟和真实环境中的任务成功率相比现有方法如何？

### 4. 背景与问题设定

构建可靠的机器人技能通常需要大量人工设计奖励、整合感知与控制。现有方法如Code-as-Policy和Agent-as-Policy各有局限：前者依赖显式程序逻辑，后者频繁调用模型导致速度慢。RPG旨在通过自主练习改进可复用的符号技能和系统提示，无需更新模型权重，从而减少人工干预。

### 5. 方法概览

- 任务 / 环境: 仿真环境基于MuJoCo，使用YAM双机械臂，接受RGB-D观测和14维关节位置指令；真实环境为YAM机器人，执行三项任务（具体任务名称未在摘要中给出）。
- 变量 / 干预设计: RPG包含三个阶段：Reconstruct（从离线数据集构建仿真练习任务）、Practice（通过执行反馈和视频分析诊断失败，生成并验证技能修订）、Go Real（校准并冻结系统用于真实部署）。
- 评价指标: 任务成功率（每个任务5次开发种子和10次评估种子），以及跨任务验证中的平均成功率提升和单任务成功率下降不超过20个百分点。
- 模型比较: 与ASPIRE、CaP-Agent0（GPT-6 Astra Pro）等基线比较，RPG在22个模拟任务上达到95.0%成功率，优于基线。
- 我的理解: RPG的核心在于利用特权状态和视频分析进行失败诊断，生成具体的技能修订建议，并通过跨任务验证确保修订的通用性，从而在不改变模型权重的情况下实现系统自我改进。

### 6. 关键发现

- RPG显著提升模拟任务成功率: 经过15轮练习，RPG在22个模拟任务上的成功率从28.6%提升至95.0%，优于ASPIRE（75.5%）和CaP-Agent0（60.0%）。
- 真实世界部署成功: 在三个物理任务上，RPG系统在30次试验中全部成功，验证了仿真练习的有效性和迁移性。
- 消融实验证实关键组件贡献: 消融实验表明，特权代理（Privileged Agent）和视频分析器（Video Analyzer）对改进效果至关重要，移除任一组件都会导致性能下降。

## 2. AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents

**Topics:** Coding Agent, Context Management, Reinforcement Learning
**Authors:** Xuan Zhang, Longtao Zheng, Cunxiao Du, Bo An, Xin Dong
**Venue / Year:** Preprint 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02163v1) | [PDF](http://arxiv.org/pdf/2610.02163v1.pdf)

### 1. 一句话结论

AutoCompact 通过在线裁判纠正和强化学习，训练编码代理自主决定何时压缩上下文、保留什么工作状态以及如何继续，从而在 SWE-bench Verified 和 SWE-PolyBench Verified 上分别提升 9.2% 和 5.0% 的通过率。

### 2. 为什么重要

长时程编码代理的上下文管理不仅关乎避免溢出，更关乎任务进展中的信息时效性。AutoCompact 将压缩决策纳入策略学习，而非依赖固定阈值或外部规则，为高效上下文管理提供了新范式。

### 3. 研究问题

1. 如何让编码代理自主决定何时压缩上下文？
2. 如何确保压缩后的工作状态准确且可执行？
3. 如何通过强化学习联合优化编码与压缩策略？

### 4. 背景与问题设定

编码代理在解决仓库级软件工程任务时，会产生长轨迹，包含代码检查、搜索、编辑和测试。随着任务推进，早期探索信息变得过时，上下文管理不仅是避免溢出，还需决定何时压缩、保留什么工作状态以及如何继续。现有方法如长度触发压缩（CompactionRL）或基于规则的主动压缩（SelfCompact）未能充分解决压缩时机、内容保留和后续执行的一致性问题。

### 5. 方法概览

- 任务 / 环境: 仓库级软件工程任务，使用 SWE-bench Verified 和 SWE-PolyBench Verified 基准，基于 Qwen3-Coder-30B-A3B-Instruct 模型和终端 REPL 脚手架。
- 变量 / 干预设计: 引入可主动调用的 compact() 动作，通过在线裁判纠正压缩时机、工作状态总结和压缩后行为，收集纠正轨迹用于 SFT，再通过 GRPO 强化学习联合优化编码与压缩。
- 评价指标: 任务通过率（pass rate），并在不同推理预算和上下文窗口（256K 和 16K）下评估。
- 模型比较: 与 Base（无压缩）、Fixed Compaction（长度触发）、CompactionRL（长度触发+RL）、SelfCompact（推理时规则）、SWE-Compressor（离线插入压缩调用）进行比较。
- 我的理解: AutoCompact 的核心创新在于将压缩决策作为策略的一部分，通过在线裁判纠正和强化学习，使代理学会在合适的时机压缩，并生成高质量的工作状态总结，从而提升任务完成效率。

### 6. 关键发现

- AutoCompact 显著提升通过率: 在 SWE-bench Verified 上达到 39.6%（提升 9.2%），在 SWE-PolyBench Verified 上达到 24.5%（提升 5.0%），优于所有基线。
- 主动压缩优于长度触发压缩: 所有主动压缩方法（包括 SelfCompact、SWE-Compressor、AutoCompact）均优于 Base，而 Fixed Compaction 甚至低于 Base，表明主动压缩在长时程任务中更有效。
- 在线纠正优于离线插入: AutoCompact-SFT 比 SWE-Compressor 高 1.2% 和 1.6%，说明在线纠正并执行纠正后轨迹比离线插入压缩调用更有效。
- 强化学习进一步增益: AutoCompact（SFT+RL）比 AutoCompact-SFT 在低预算下提升显著，表明 RL 能优化压缩策略以提升任务成功率。
- 压缩行为质量提升: AutoCompact 的主动压缩率更高（58.5% vs. 44.3%），且总结中缺失关键状态的比例从 3.1% 降至 0.2%，缺失下一步动作的比例从 8.2% 降至 2.2%。

## 3. DuoMind: Enabling Distributed Multi-Robot Coordination with Semantic Communication

**Topics:** 多机器人协调, 语义通信, 视觉语言模型, 视觉语言动作模型
**Authors:** Hanchu Zhou, Dechen Gao, Hang Wang, Brendan Lynch, Boqi Zhao, Qiyao Ma, Raman Goyal, Junshan Zhang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02161v1) | [PDF](http://arxiv.org/pdf/2610.02161v1.pdf)

### 1. 一句话结论

DuoMind通过分层架构（VLM编排器+VLA动作模型）和结构化语义消息，实现了分布式多机器人的高效协调，并在新基准RoboPoly上显著优于基线。

### 2. 为什么重要

该研究将VLM/VLA从单机器人扩展到多机器人系统，解决了分布式控制下的长期任务协调问题，为多机器人协作提供了新范式，并开源了基准和数据集，推动该领域发展。

### 3. 研究问题

1. 如何利用预训练的VLM和VLA实现分布式多机器人的长期任务协调？
2. 语义通信（结构化自然语言消息）如何提升多机器人系统的任务性能和鲁棒性？

### 4. 背景与问题设定

现有VLM/VLA主要针对单机器人，多机器人系统面临长期行为协调和精细执行的双重挑战。传统多智能体方法在复杂操作任务中表现有限，而基于LLM的方法多停留在高层规划，缺乏与低层控制的紧密集成。此外，缺乏专门的多机器人协调基准。

### 5. 方法概览

- 任务 / 环境: RoboPoly（7个多机器人操作任务，两个独立Panda机械臂，分布式观测）和RoboTwin（8个双臂任务，改编为分布式控制）。
- 变量 / 干预设计: 每个机器人配备VLM编排器（负责高层推理和生成低层指令及语义消息）和VLA动作模型（执行低层动作）。编排器接收任务指令、本地观测和来自其他机器人的消息，输出低层指令和结构化消息（意图、子目标、任务信念、不确定性）。
- 评价指标: 任务成功率（Success Rate）。
- 模型比较: 与仅使用π0.5或π0（无编排器）的基线对比，以及消融研究（移除编排器或语义通信）。
- 我的理解: DuoMind的核心是分层解耦：VLM负责“思考”，VLA负责“执行”，通过自然语言作为接口，既利用了VLM的语义理解，又保持了VLA的精细控制，同时通过消息传递缓解了部分可观测性问题。

### 6. 关键发现

- DuoMind在RoboPoly上全面优于基线: 在7个任务中，DuoMind w/π0.5的成功率均高于仅使用π0.5或π0，例如Hang Bag达到78%，而π0.5 only为52.25%。
- 分层架构和语义通信的贡献: 消融实验表明，移除编排器或语义通信会显著降低性能，证明两者对多机器人协调至关重要。
- 在RoboTwin上的泛化能力: DuoMind在改编的RoboTwin双臂任务上也取得改进，验证了框架的通用性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: DuoMind提供了一种可扩展的多智能体框架，通过分层和语义通信，可应用于复杂协作任务，如仓储、家庭服务等。

- 对评测: RoboPoly基准为多机器人协调提供了标准化测试平台，促进公平比较和进展评估。

- 仅验证了两机器人场景，扩展到更多机器人时通信开销和协调复杂度可能增加。
- 依赖预训练VLM/VLA，其性能可能成为瓶颈，且未深入探讨模型微调策略。

## 4. Homomorphic Advantage Operator: Stabilizing Reinforcement Learning Under Fully Homomorphic Encryption Constraints

**Topics:** 隐私保护机器学习, 强化学习, 全同态加密, 多项式激活函数
**Authors:** Abid Mohamed Nadhir, Ahmad Al Hanbali, Beggas Mounir
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02074v1) | [PDF](http://arxiv.org/pdf/2610.02074v1.pdf)

### 1. 一句话结论

提出同态优势算子（HAO），通过零深度线性投影消除贝尔曼漂移，使深度强化学习在仅使用二次多项式激活的轻量级同态加密下保持稳定。

### 2. 为什么重要

首次解决了全同态加密约束下深度强化学习因递归误差放大导致的激活越界问题，无需昂贵的自举操作，为云端隐私保护智能决策系统提供了可行方案。

### 3. 研究问题

1. 如何在全同态加密（FHE）约束下防止强化学习中的多项式近似发散？
2. 能否通过线性投影消除贝尔曼漂移而不增加非线性乘法深度？

### 4. 背景与问题设定

强化学习在云端部署时面临数据隐私问题，全同态加密（FHE）允许在密文上直接计算，但仅支持加法和乘法，因此非线性激活函数（如ReLU）必须用多项式近似。然而，递归的时序差分（TD）学习会放大多项式近似误差，导致预激活值超出多项式收敛域，引发数值爆炸。现有监督学习中的稳定方法不适用于RL的动态目标，而先前隐私保护RL工作未解决此问题。

### 5. 方法概览

- 任务 / 环境: 包括表格型MDP、加密CartPole环境（使用真实CKKS加密操作）以及具有密集连续特征的20节点物流路径规划基准。
- 变量 / 干预设计: HAO框架包含三个组件：1) HAO中心化投影（将Q值投影到优势空间）；2) 客户端奖励缩放（压缩优势流幅度）；3) 解耦权重衰减与梯度裁剪。
- 评价指标: 边界违反率（预激活值超出多项式收敛域的比例）、最优策略准确率、稳定性（在不同随机种子下的表现）。
- 模型比较: 与未稳定基线、仅正则化（L2权重衰减和梯度裁剪）方法对比，并测试了添加DP-SGD风格高斯噪声后的稳定性。
- 我的理解: HAO的核心思想是：贝尔曼漂移主要由状态值基线V(s)驱动，通过线性投影矩阵P将Q值中心化，消除V(s)的影响，从而切断误差放大回路。该投影是线性的，不增加非线性乘法深度，且无需自举。

### 6. 关键发现

- HAO实现0%边界违反: 在所有随机种子下，HAO智能体均未出现预激活值超出多项式收敛域的情况，而仅正则化方法在3/5种子下违反边界，未稳定基线在83.8%的回合中违反。
- 最优策略准确率提升18个百分点: 在表格型MDP中，HAO智能体的最优策略准确率比基线提高18.0个百分点，表明中心化投影不仅稳定训练，还改善了策略质量。
- 与差分隐私兼容: 在梯度裁剪后添加高斯噪声（σ高达1.0）时，HAO仍保持稳定，表明其可与DP-SGD结合，实现隐私保护与差分隐私的双重保障。

## 5. Global Coherence: When Every Agent Is Right and the Team Is Still Wrong - A Local-to-Global Semantic Foundation for Multi-Agent Collaboration

**Topics:** 多智能体协作, 全局一致性, 智能体框架
**Authors:** Xin Heng
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02036v1) | [PDF](http://arxiv.org/pdf/2610.02036v1.pdf)

### 1. 一句话结论

局部正确的智能体可能因共享状态缺失而导致全局错误，必须通过框架（harness）来维护全局状态和一致性。

### 2. 为什么重要

该论文首次将多智能体协作中的全局一致性问题形式化，提出了观察别名不可能定理，并给出了可操作的框架设计原则，对构建可靠的多智能体系统具有重要指导意义。

### 3. 研究问题

1. 局部有效的决策为何会导致全局无效的结果？
2. 如何设计智能体上下文和框架以保证全局一致性？

### 4. 背景与问题设定

在多智能体系统中，每个智能体只能看到局部状态，其决策在局部看来是正确的，但组合起来可能违反全局约束。论文将这一问题定义为“全局一致性问题”，并指出其根源在于共享状态的缺失，而非模型智能不足。

### 5. 方法概览

- 任务 / 环境: 多智能体协作任务，包括修订基准、TeamBench和τ²-bench Telecom等。
- 变量 / 干预设计: 通过隐藏或显示关键事件、实施预算控制、使用框架进行提交时检查等干预，比较不同条件下的性能。
- 评价指标: 任务成功率、预算违规次数、一致性得分等。
- 模型比较: 比较了不同推理策略（如直接推理、角色分解、投票、工具使用）在隐藏关键事件时的表现，以及有无框架强制时的差异。
- 我的理解: 论文通过理论分析和实验验证，展示了局部信息不足时智能体无法保证全局正确性，而框架通过持有共享状态和执行提交时检查，可以有效解决这一问题。

### 6. 关键发现

- 观察别名不可能定理: 当多个世界产生相同观察但需要不同动作时，任何基于该观察的策略都无法保证正确，最佳随机策略的成功率仅为1/k。
- 框架强制提交可消除预算违规: 在TeamBench实验中，普通团队5/5次超支，显示实时计数仍有4/5违规，而框架强制提交时0/5违规，且任务进度未下降。
- 隐藏关键事件导致性能降至随机水平: 在修订基准中，当关键事件被隐藏时，所有测试策略的准确率与随机猜测（1/3）一致，而恢复该事实后准确率回到40/40。
