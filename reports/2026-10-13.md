## 1. A-SAW: The Agentic Software Architecture Workflow

**Topics:** 软件架构文档, 架构即代码, LLM智能体, 人机协同, 工业案例研究
**Authors:** Finn Klatt, Luca Di Grazia, Johannes Schneider
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.13647v1) | [PDF](http://arxiv.org/pdf/2610.13647v1.pdf)

### 1. 一句话结论

A-SAW通过将智能体层嵌入架构即代码流程，并强制人工审查，显著降低了文档质量差异并提升了内在质量，但测量质量与从业者信任之间存在分歧。

### 2. 为什么重要

软件架构文档的维护是软件工程中未被充分服务的关键环节，A-SAW提供了一种可落地的流程级方案，将LLM智能体用于设计阶段，同时通过结构约束和强制人工审查来保证可靠性和信任，对工业实践有直接指导意义。

### 3. 研究问题

1. 如何设计一个流程级工件，使架构文档的维护不再依赖个人纪律，而是由工具和流程强制保证？
2. 在工业环境中，A-SAW能否在提升文档质量的同时，保持从业者对智能体输出的信任？

### 4. 背景与问题设定

AI辅助软件工程主要集中在编码和测试，设计阶段的架构文档维护被忽视。架构即代码（AaC）使文档可版本化、可比较，但并未解决维护负担。知识蒸发（rationale丢失）和文档漂移是常见问题。A-SAW旨在通过持久化智能体层和强制人工审查来解决这些问题。

### 5. 方法概览

- 任务 / 环境: 大型工业软件产品组织，约15名架构师和高级开发人员，已采用C4模型和PlantUML约18个月。
- 变量 / 干预设计: 设计科学研究（DSR），通过三个迭代轮次构建A-SAW工件，并在自然环境中评估。评估包括：45份文档的评分（三个队列：手动、部分AaC、智能体生成），其中13对匹配的源→再生成对；13次任务锚定访谈。
- 评价指标: 文档质量通过自定义评分标准（完整性、一致性、可追溯性、可读性等）评估；统计指标包括标准差、中位数差异、p值和效应量。
- 模型比较: 比较三个队列：手动编写（A）、部分AaC（B）、A-SAW智能体生成（C），以及匹配的源→再生成对。
- 我的理解: A-SAW是一个三层架构：工件层（版本控制的C4模型、元素目录、模板）、智能体编排层（IDE集成，从工件层组装上下文生成草稿）、人工审查层（强制审批门）。智能体通过目录约束和上下文文件夹限制幻觉，并通过自动检查（如幽灵标识符）进一步约束。

### 6. 关键发现

- 质量差异显著降低: 文档评分标准差从19.2降至3.8（比率5.0，95% CI [2.9, 9.2]），表明A-SAW使文档质量更加一致。
- 内在质量提升: 匹配对中位数提升+19分（p=0.001，r=+0.97），表明智能体生成的文档在完整性、一致性等方面优于人工文档。
- 能力边界明确: 完整性、一致性和机器可读性接近满分，但可追溯性（79%）和决策可审计性仍依赖人工补充，表明智能体在需要推断超出仓库信息的方面能力有限。
- 质量与信任分歧: 尽管测量质量高，从业者信任是有条件的，取决于智能体推断程度和可靠生成次数，而非仅凭高分。

## 2. When VLMs Destroy What They Know: Spatial Representations Fall Below Lexical Priors

**Topics:** 视觉语言模型, 空间关系表示, 表征评估, 组合性
**Authors:** Shubh Garg, Chen Shani
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.13910v1) | [PDF](http://arxiv.org/pdf/2610.13910v1.pdf) | [Code](https://github.com/Shubhf/CASP-VL)

### 1. 一句话结论

视觉语言模型（VLM）的内部表示对空间关系的编码远不如词袋（BoW）基线，即使模型在输出层面表现良好，其全局表示中也丢失了局部可用的空间信息。

### 2. 为什么重要

该研究揭示了VLM在输出层面看似正确，但内部表示可能未忠实编码空间关系，这会影响依赖内部表示的下游任务（如多模态推理、具身智能）的可靠性，并指出仅基于输出的评估可能掩盖系统性缺陷。

### 3. 研究问题

1. VLM的内部表示是否忠实编码空间关系？
2. 空间关系信息在表示中是否可解码，以及它在何处丢失？

### 4. 背景与问题设定

尽管VLM在视觉问答等任务上表现良好，但先前研究表明它们可能依赖语言先验而非真正的视觉理解。本文关注内部表示层面，而非仅输出层面，提出因果干预方法，测试表示是否随单一概念变化而稳定变化。

### 5. 方法概览

- 任务 / 环境: 基于Visual Genome场景图构建受控图像-文本三元组，每个三元组仅改变一个概念（属性或空间关系）。
- 变量 / 干预设计: 对场景图进行单概念编辑（如将“on”改为“beneath”），生成原始和扰动后的标题对，保持其他内容不变。
- 评价指标: 提出EICS（评估不变概念稳定性）指标，通过逻辑回归探针在原始标题上训练，测试扰动标题上预测新标签的准确率减去随机水平。
- 模型比较: 比较CLIP ViT-B/32、SigLIP-B/16和LLaVA-1.5-7B，并对比词袋（BoW）基线。
- 我的理解: 该方法通过因果干预和探针分析，将表示变化与特定概念变化关联，从而评估表示是否忠实编码该概念，并区分局部（谓词token）与全局（[EOS]）表示。

### 6. 关键发现

- 空间翻转几乎不改变CLIP的文本表示: 在CLIP ViT-B/32的最后一层，空间关系翻转的余弦相似度为0.992，而颜色翻转仅为0.943，表明表示对空间变化不敏感。
- 空间关系的EICS远低于词袋基线: 在所有测试的VLM中，空间关系的EICS值（CLIP: +0.070, SigLIP: +0.038, LLaVA: +0.115）均低于BoW基线（+0.372），而颜色关系接近BoW（+0.312 vs +0.332）。
- 空间信息在谓词token处可解码，但在全局表示中丢失: 在谓词token处探针EICS高达+0.930，接近理论上限，但在[EOS]或平均池化表示中仅+0.070，表明信息在聚合时被破坏。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 智能体系统若依赖VLM的内部表示进行空间推理（如导航、操作），可能因表示不忠实而失败，需考虑使用局部表示或额外监督。
- 对 Skill: 训练技能时，应关注模型是否真正编码空间关系，而非仅输出正确，可能需要改进训练目标以增强表示的结构性。
- 对 Memory: 记忆系统若存储全局表示，可能丢失空间细节，建议存储局部或结构化表示以保留关键信息。
- 对评测: 评估VLM时应结合表示级指标（如EICS），而不仅依赖输出准确率，以发现隐藏的表示缺陷。

### 11. 局限性

- 仅基于文本编码器，未涉及图像编码器，可能无法完全反映多模态交互。
- 探针方法可能受线性可分性限制，非线性关系可能未被捕捉。
- 基准基于场景图模板，可能无法覆盖真实世界的复杂语言表达。

### 12. 我的看法 / 个人笔记

该研究通过因果干预和探针分析，有力地证明了VLM在空间关系表示上的缺陷，并定位了信息丢失的位置。这提醒我们，输出层面的成功可能掩盖内部表示的不足，对依赖表示的下游应用有重要警示。未来工作可探索改进训练目标或架构以保留空间结构。

## 3. RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

**Topics:** AI Agent, 工具检索, 可靠性感知, 上下文赌博机, 对比学习
**Authors:** Weiliang Chen, Song Liao
**Venue / Year:** CIKM '26
**Links:** [Abstract](http://arxiv.org/abs/2610.13889v1) | [PDF](http://arxiv.org/pdf/2610.13889v1.pdf) | [Code](https://github.com/Elliotes/EcoAgent)

### 1. 一句话结论

RATED通过结合对比微调的双编码器与基于执行反馈的折扣LinUCB上下文赌博机重排序，在工具故障时显著降低故障选择率，同时保持低延迟。

### 2. 为什么重要

现有工具检索方法仅优化语义相关性，忽略运行时工具可用性，导致AI代理在真实动态环境中频繁选择故障工具。RATED首次将执行动态纳入检索框架，实现快速适应，显著提升可靠性，为构建鲁棒AI代理系统提供了新思路。

### 3. 研究问题

1. 如何将工具运行时可靠性信息融入检索过程，以降低故障选择率？
2. 在保持语义检索性能的同时，如何实现低延迟的在线适应？

### 4. 背景与问题设定

AI代理依赖外部工具执行任务，工具检索的准确性至关重要。现有方法（如ToolLLM）仅基于语义相关性进行静态排序，未考虑工具在运行时的可用性。实际中，工具可能因API故障、认证问题等失效，导致代理行为不可靠。因此，需要一种能够动态适应工具状态变化的检索机制。

### 5. 方法概览

- 任务 / 环境: 工具检索任务，环境包含5,172个真实工具，代理根据用户查询选择工具执行，工具可能发生故障。
- 变量 / 干预设计: RATED框架包含两个阶段：1) 语义感知模块：使用DRAGON双编码器，通过对比学习微调，获取语义相关分数；2) 可靠性感知重排序：采用折扣LinUCB上下文赌博机，基于执行反馈动态调整候选工具分数。静态先验由名称-描述一致性、来源可信度和文档质量三个信号加权构成，用于冷启动初始化赌博机参数。
- 评价指标: 离线检索使用MRR、Recall@1、Recall@5；动态可靠性使用故障后成功率（Post-Fail SR）、故障选择率（FSR）和适应步数（AS）。
- 模型比较: 与TF-IDF、BM25、OpenAI Ada-002、BGE-M3、GTE-Large、E5-Large-v2、DRAGON（预训练）、SPLADE-v3、BGE-Reranker、ToolLLM API Retriever等基线比较。
- 我的理解: RATED的核心创新在于将工具检索视为序贯决策问题，通过上下文赌博机在线学习工具可靠性，并利用折扣因子适应非平稳环境，从而在语义相关性和可靠性之间取得平衡。

### 6. 关键发现

- 显著提升检索性能: 在EcoAgent-Syn上，RATED（完整版）的MRR达到0.845，相比ToolLLM API Retriever提升52.2%；在EcoAgent-Real上，MRR为0.618，优于多数基线。
- 大幅降低故障选择率: 在30%故障注入下，RATED的故障选择率降至2.9%，而ToolLLM高达86.2%，降低了约30倍；在20%故障下，FSR为2.5%。
- 快速适应故障: RATED在故障发生后能迅速调整，适应步数（AS）在20%故障下为1603步，而静态方法无法恢复。
- 低延迟开销: RATED（完整版）平均延迟3.395ms，仅比纯编码增加0.172ms，远低于批处理GRPO的17.839ms，适合实时交互。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: RATED为AI代理提供了一种轻量级、可在线适应的工具选择机制，能显著提升在动态环境中的可靠性，可集成到现有代理框架中。
- 对 Skill: 该方法可视为一种技能选择策略，通过执行反馈动态调整技能优先级，适用于技能库管理。
- 对 Memory: 赌博机参数可视为对工具可靠性记忆的编码，折扣因子实现了对旧记忆的衰减，类似记忆的遗忘机制。
- 对评测: 提出的EcoAgent基准和动态故障注入协议为评估工具检索的可靠性提供了标准化方法，可推广到其他代理评估。

### 11. 局限性

- 实验仅在模拟故障注入下进行，未在真实故障场景中验证。
- 依赖工具元数据（如描述、标签）计算静态先验，可能受元数据质量影响。
- 未考虑工具之间的依赖关系或组合使用场景。

### 12. 我的看法 / 个人笔记

RATED巧妙地将上下文赌博机应用于工具检索，解决了静态检索无法适应动态故障的问题，且开销极小。未来工作可探索更复杂的可靠性模型（如考虑故障模式）和扩展到多工具协作场景。

## 4. Tracing and Taming Hallucinated Terms via Subsequence-Association Filtering and Breadth-Aware Selection for LLM Query Expansion

**Topics:** 信息检索, 查询扩展, 大语言模型幻觉
**Authors:** Amit Kumar Jaiswal, Sagar Uprety, Prayag Tiwari
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.13810v1) | [PDF](http://arxiv.org/pdf/2610.13810v1.pdf)

### 1. 一句话结论

SAFE-QE通过子序列关联过滤和广度感知选择，在不损失排序质量的前提下，显著减少LLM查询扩展中的幻觉术语注入。

### 2. 为什么重要

LLM查询扩展虽能提升弱检索器性能，但幻觉术语会损害强检索器。现有方法缺乏机制性解释和选择标准，SAFE-QE首次将幻觉机制理论引入IR，实现无训练、检索器无关的忠实扩展，为可靠查询扩展提供新范式。

### 3. 研究问题

1. 过滤幻觉术语是否会损害检索有效性？
2. SAFE-QE相比生成式和语料引导扩展，能减少多少幻觉术语？
3. SAFE-QE的收益是否集中在强检索器上？
4. SAFE-QE的忠实性收益是否在小模型下依然存在？

### 4. 背景与问题设定

LLM生成的查询扩展术语常包含不存在的实体或离题词，增加排序噪声，尤其损害强检索器。现有缓解方法（如语料接地、互验、偏好对齐）将幻觉视为无差别干扰，依赖启发式过滤，缺乏对术语出现机制的说明和选择数量的原则性标准。

### 5. 方法概览

- 任务 / 环境: 查询扩展任务，使用TREC DL 2019/2020和四个BEIR数据集（TREC-COVID、NFCorpus、FiQA、SciFact），搭配BM25、SPLADE、Contriever三种检索器。
- 变量 / 干预设计: SAFE-QE：1) 用LLM生成N个候选术语；2) 计算每个术语的跨上下文可复现性ρ(t)（随机扰动查询上下文）和语料接地性γ(t)（在伪相关文档中的支持度）；3) 结合两者计算保留分数s(t)；4) 在接地术语上执行子模覆盖最大化，并应用稳定性过滤。
- 评价指标: 有效性用nDCG@10；忠实性用新提出的HETR（幻觉扩展术语率）和幻觉术语负载（HETR×|E(q)|）。
- 模型比较: 对比无扩展、Query2doc、HyDE、CSQE、MILL，使用Gemma-2-9B作为主生成器，并测试Qwen2.5-0.5B、Gemma-2-2B、Qwen2.5-7B以评估模型规模影响。
- 我的理解: SAFE-QE的核心创新在于将幻觉视为子序列关联的产物，通过跨上下文可复现性识别出那些无论上下文如何都出现但缺乏语料支持的术语，并利用子模优化在保证覆盖度的同时限制幻觉术语数量。

### 6. 关键发现

- 有效性无损: SAFE-QE在nDCG@10上与Query2doc、HyDE、CSMI、MILL统计上无显著差异（|Δ|≤0.004，p>0.5），表明过滤幻觉术语不损害排序质量。
- 幻觉术语大幅减少: SAFE-QE平均每查询注入4.3个不支持术语，相比Query2doc的27.8和HyDE的57.5，减少85%和93%；相比CSQE和MILL减少45%和43%。
- 强检索器受益: 在SPLADE和Contriever上，SAFE-QE的nDCG@10与无扩展相当或略优，而其他扩展方法均出现退化，表明SAFE-QE避免了强检索器的性能回退。
- 小模型下依然有效: 使用0.5B和2B模型时，SAFE-QE仍能保持低HETR，而Query2doc和HyDE的幻觉率显著上升，说明方法不依赖模型规模。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: SAFE-QE可嵌入检索增强生成（RAG）流程，减少幻觉术语对下游任务的影响，提升智能体在信息检索中的可靠性。
- 对 Skill: 提供了一种无需训练的幻觉过滤技能，可迁移至其他生成任务，如摘要或对话中的事实性控制。
- 对 Memory: 通过语料接地性γ(t)利用伪相关文档，可视为一种外部记忆访问，增强生成术语与知识库的一致性。
- 对评测: 引入HETR作为查询扩展的忠实性指标，补充了仅依赖排序质量的评估体系，促进更全面的模型评估。

### 11. 局限性

- 依赖伪相关文档的质量，若检索器初始结果差，接地性计算可能不准确。
- 需要多次采样和扰动查询，计算开销较高。
- HETR的验证依赖人工标注或高精度验证器，可能引入额外成本。
- 实验仅在英文数据集上验证，跨语言泛化性未知。

### 12. 我的看法 / 个人笔记

SAFE-QE巧妙地将幻觉机制理论转化为可操作的过滤策略，实现了有效性与忠实性的双赢。其无训练、检索器无关的特性使其易于部署。未来可探索动态调整λ和μ，或结合强化学习进一步优化选择。

### 14. 总结

SAFE-QE基于子序列关联理论，通过跨上下文可复现性和语料接地性评分，结合广度感知的子模覆盖选择，在保持nDCG@10的同时，将幻觉术语注入减少85%以上，且对强检索器无损害，为LLM查询扩展提供了可靠的忠实性保障。

## 5. UkrMeme: Multimodal Explainable Persuasion Detection in Ukrainian Memes

**Topics:** 多模态学习, 说服检测, 可解释人工智能, 乌克兰语
**Authors:** Nazar Andrushko, Vera Schmitt, Veronika Solopova
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.13783v1) | [PDF](http://arxiv.org/pdf/2610.13783v1.pdf) | [Code](https://github.com/eingrid/persuasion-techniques-ua-memes)

### 1. 一句话结论

本文构建了乌克兰语模因数据集UkrMeme和翻译基准PTM-UA，评估了多种视觉语言模型在零样本说服技术检测中的表现，并对比了LRP与模型自生成词归因两种解释方法的一致性。

### 2. 为什么重要

该研究填补了非英语、低资源语言环境下多模态说服检测与可解释性研究的空白，为战时社交媒体内容分析提供了新数据集和方法论参考。

### 3. 研究问题

1. 视觉语言模型在乌克兰语模因说服技术检测中的表现如何？
2. LRP与模型自生成词归因在解释模型决策时的一致性如何？

### 4. 背景与问题设定

模因在政治冲突中广泛用于传播说服性信息，但现有检测基准多为英语，且缺乏对模型决策可解释性的关注。本文针对乌克兰语模因，构建数据集并评估多种视觉语言模型，同时对比两种解释方法。

### 5. 方法概览

- 任务 / 环境: 乌克兰语模因说服技术检测，包括图像、文本和图像+文本三种输入模态。
- 变量 / 干预设计: 零样本提示设置，使用四个模型（Qwen3-VL-4B/8B、GPT-4.1-mini、Gemma 3 4B）在UkrMeme和PTM-UA数据集上进行检测，并对Qwen模型进行LRP和词归因分析。
- 评价指标: 层次化F1（微平均、宏平均、每样本平均），以及Jaccard相似度用于解释一致性比较。
- 模型比较: 比较了不同规模的开源模型（Qwen3-VL-4B/8B）与闭源模型（GPT-4.1-mini）及轻量模型（Gemma 3 4B）的性能。
- 我的理解: 该方法通过翻译现有基准和构建原生数据集，结合多种模型和解释技术，系统性地评估了多模态说服检测的可行性和可解释性。

### 6. 关键发现

- 跨数据集性能差距显著: 所有模型在UkrMeme上的性能均低于PTM-UA，微平均F1最高仅0.342（Qwen3-VL-8B，图像+文本），而PTM-UA上最高为0.613（GPT-4.1-mini，图像+文本）。
- 翻译对性能影响有限: 对于GPT-4.1-mini和Gemma 3 4B，原始英文与乌克兰语翻译版本之间的性能差异在±0.03 F1以内，表明翻译本身对检测影响不大。
- 解释方法一致性较低: LRP与模型自生成词归因的Jaccard相似度较低，表明两种方法强调的证据不同，需要进一步研究其可靠性。
