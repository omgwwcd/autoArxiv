## 1. When Every Rollout Fails: Splicing Learner-Conditioned Options into Long-Horizon Agent RL

**Topics:** Agentic RL, Long-horizon Agent, Reinforcement Learning
**Authors:** Haowen Hou, Yicheng Liu, Zhen Huang, Jiaqi Wang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.34777v1) | [PDF](http://arxiv.org/pdf/2611.34777v1.pdf)

### 1. 一句话结论

SPLICE 通过在线拼接当前策略失败轨迹中的局部选项，并利用当前策略续评价值加权训练，显著提升长程智能体 RL 在全部失败组中的学习效率与性能。

### 2. 为什么重要

长程智能体任务中，稀疏二元奖励常导致整组轨迹全部失败，使 GRPO 等组相对方法失去梯度信号。SPLICE 提供了一种无需完整专家轨迹的在线局部引导方案，既降低计算成本又缓解分布偏移，为长程智能体 RL 的探索与利用提供了新思路。

### 3. 研究问题

1. 在长程智能体任务中，当一组采样轨迹全部失败时，如何构造有效的学习信号？
2. 如何利用当前策略的续评价值来评估和加权外部模型提出的局部选项，从而提升策略性能并降低计算开销？

### 4. 背景与问题设定

基于可验证奖励的组相对策略优化（如 GRPO）在长程智能体任务中常因所有轨迹奖励为零而失效。现有补救方法依赖完整专家轨迹，但生成成本高且存在分布偏移。SPLICE 针对此问题，仅从当前策略的失败轨迹中选取拼接点，由提议模型生成短选项，并用当前策略续评价值加权，实现局部监督。

### 5. 方法概览

- 任务 / 环境: 长程智能体任务，包括软件工程（SWE-bench Verified）和深度研究（BrowseComp-Plus），环境提供可验证的二元奖励（如测试通过或答案正确）。
- 变量 / 干预设计: 对每个全失败组，随机选择一条失败轨迹，由提议模型在记录的拼接点（每 C 步记录一次）处生成 K 个有界选项（长度自适应），每个选项用当前策略续跑 M 次，以平均奖励估计选项价值，保留正价值选项并标准化为权重。
- 评价指标: 主要指标为任务解决率（SWE-bench Verified 的 resolve rate 和 BrowseComp-Plus 的准确率），以及训练集上的提案命中率、毕业率和提议模型生成轮数。
- 模型比较: 与 SFT、RL（GRPO）、SFT+RL、ReLIFT 等基线比较，在相同数据预算下评估性能。
- 我的理解: SPLICE 的核心是“局部选项 + 当前策略续评”，将外部引导限制在短片段，并通过当前策略的续跑结果来过滤和加权，从而避免直接模仿可能不适用的完整轨迹，同时减少计算开销。

### 6. 关键发现

- SPLICE 在所有设置中均优于基线: 在 SWE-bench Verified 和 BrowseComp-Plus 上，SPLICE 比 GRPO 提升 2.8–9.8 个百分点，比 SFT+RL 高 1.3–2.6 个百分点，比 ReLIFT 高 2.1–6.0 个百分点。
- SPLICE 在失败任务恢复上更高效: 在初始失败的 SWE 任务上，SPLICE 的毕业率（18.9%）比 ReLIFT（15.9%）高 3.0 个百分点，比 RL（8.1%）高 10.8 个百分点，同时使用更少的提议模型轮数（93.5k vs 113.4k）。
- SPLICE 在中等难度任务上提升最大: 在 Medium 任务上，SPLICE 比 GRPO 提升 24.3 个百分点，而 Easy 任务已接近饱和，Hard 任务提升有限。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: SPLICE 提供了一种在稀疏奖励下利用外部引导的通用框架，可应用于各类长程智能体任务，提升训练效率。
- 对 Skill: 局部选项的监督有助于策略学习更细粒度的技能，尤其是在中等难度任务上效果显著。
- 对 Memory: 当前策略续评机制隐式利用了策略的长期记忆能力，但未显式设计记忆模块，未来可结合记忆增强。
- 对评测: SPLICE 的评估指标（解决率、毕业率）为长程任务提供了更细致的度量，但需注意任务难度分布的影响。

### 11. 局限性

- 实验仅基于两个任务域（SWE 和 Deep Research），泛化性有待验证。
- 拼接点选择由提议模型完成，但具体选择策略未详细说明，可能影响可复现性。
- 选项长度上限和续跑次数等超参数需要调整，可能影响性能。
- 论文未报告方差或显著性检验，结果稳健性需进一步验证。

### 12. 我的看法 / 个人笔记

SPLICE 是一种务实且高效的解决方案，通过局部化外部引导和当前策略续评，巧妙平衡了探索与利用。其设计思想可推广到其他稀疏奖励场景，但需注意计算开销和超参数敏感性。

## 2. SOLVE: Sparse, Ordered Keyposes Make LLM Agents Versatile and Efficient Robot Manipulator

**Topics:** 机器人操作, LLM智能体, 稀疏关键位姿
**Authors:** Xiang Li, Hongyu Zhou, Ya-Li Li, Tao Li, Rui Zhang, Junjie Lai, Weihua Zhang, Shengjin Wang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.34750v1) | [PDF](http://arxiv.org/pdf/2611.34750v1.pdf) | [Code](https://serenos.github.io/solve-website)

### 1. 一句话结论

SOLVE通过让多模态LLM输出稀疏有序的6自由度末端执行器关键位姿，结合运动规划器插值，实现了无需训练、跨平台的高效机器人操作，相比逐步控制智能体成本降低12倍。

### 2. 为什么重要

现有LLM智能体在机器人操作中面临推理成本高、控制密集和工具瓶颈等问题。SOLVE提出稀疏关键位姿表示，显著减少模型调用次数和推理成本，同时保持高成功率，为训练免费、跨平台部署提供了新范式。

### 3. 研究问题

1. LLM智能体在机器人操作中应使用何种动作粒度？
2. 如何利用稀疏关键位姿实现高效且鲁棒的机器人操作？
3. 在缺乏深度传感器的情况下，如何准确获取关键位姿的3D坐标？

### 4. 背景与问题设定

现有机器人操作策略（如VLA、WAM）依赖大量遥操作数据，泛化能力差。LLM智能体虽无需训练，但要么逐小步控制（成本高），要么依赖代码库（瓶颈）。作者通过分析遥操作数据发现，大多数操作可压缩为少量关键位姿，因此提出SOLVE框架。

### 5. 方法概览

- 任务 / 环境: 仿真环境RoboDojo（双臂）和RoboLab（单臂），以及真实UR12e机器人上的16个挑战性零样本任务。
- 变量 / 干预设计: SOLVE智能体每次调用输出最多5个关键位姿（位置、方向、夹爪开合），由运动规划器插值执行；通过稀疏度量查询（跨视角三角化或单目深度）获取3D坐标；通过自我反思生成任务规则。
- 评价指标: 成功率（SR）和每集平均成本（美元）。
- 模型比较: 与VLA（GR00T、π0.5、WALL-OSS-1.0-lite）、WAM（InternW0-∆）以及代码型智能体（PyRUA-Lean）等对比。
- 我的理解: SOLVE的核心是让LLM在高层规划稀疏动作，而将密集运动交给底层规划器，从而减少推理次数和错误累积。

### 6. 关键发现

- 稀疏关键位姿足以描述操作: 在RoboDojo和DROID数据中，抓取/释放动作平均只需约5-6个关键位姿，且91%的移动距离位于长度超过5厘米的直线段上。
- SOTA性能与低成本: SOLVE在RoboDojo上达到74.5%成功率，在RoboLab上达到84.5%，每集平均成本仅1.7美元，比逐步控制智能体低12倍。
- 跨平台零样本泛化: 同一智能体无需修改即可部署在双臂、单臂和真实机器人上，在16个挑战性零样本任务中达到88%成功率。

## 3. Maco-RL: Scaling Agent Capabilities with Mixed-Task Reinforcement Learning

**Topics:** Reinforcement Learning, Multi-Task Learning, LLM Agent
**Authors:** Jiacheng Zhang, Qixing Zhou, Haiyang Wang, Qipeng Gu, Shuzhe Wu, Feiyang Pan, Lue Fan, Dandan Tu, Zhaoxiang Zhang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.34703v1) | [PDF](http://arxiv.org/pdf/2611.34703v1.pdf)

### 1. 一句话结论

Maco-RL通过混合任务强化学习与三缓冲采样，在多个智能体基准上显著提升27B模型的整体能力，并超越更大规模模型。

### 2. 为什么重要

该工作展示了直接混合任务强化学习（MixRL）作为通用智能体后训练范式的潜力，无需专家模型或蒸馏阶段，即可高效扩展智能体能力，为大规模智能体训练提供了新思路。

### 3. 研究问题

1. 如何稳定且高效地扩展混合任务强化学习（MixRL）至多个异构任务域？
2. 如何在持续扩展任务实例和任务类型时，平衡探索、巩固与保留已有能力？

### 4. 背景与问题设定

大型语言模型智能体在软件工程、终端操作和办公自动化等领域取得显著进展，强化学习（RL）是提升其能力的关键。现有方法通常先独立训练专家模型，再通过蒸馏整合，但效率较低。直接混合任务强化学习（MixRL）联合优化共享策略，但面临任务异质性、奖励分布差异、计算成本高和持续扩展等挑战。

### 5. 方法概览

- 任务 / 环境: 涵盖代码修复（SWE-bench）、终端操作（Terminal-Bench）、办公自动化（Claw）以及特征开发（FeatureBench）等多个任务域，使用Docker容器和Kubernetes管理环境。
- 变量 / 干预设计: 提出Maco-RL框架，包含异步混合任务训练管道和三缓冲采样（TBS）。TBS将采样预算分配给前沿缓冲（探索未解决实例）、强化缓冲（巩固新出现能力）和历史缓冲（保留旧能力）。训练使用RLOO进行优势估计，每个任务实例8次rollout，每次更新256条轨迹。
- 评价指标: 使用各基准的Pass@1或Tests Passed等指标，并计算五个基准的未加权平均Overall分数。
- 模型比较: 与Qwen3.5-27B、Qwen3.6-27B、Qwen3.8-27B基线以及更大规模的前沿模型（如Claude-Opus-5、DeepSeek-V4-Pro等）进行比较。
- 我的理解: Maco-RL通过异步采样和梯度混合，结合TBS的采样策略，有效解决了混合任务训练中的稳定性和效率问题，实现了能力持续扩展。

### 6. 关键发现

- Maco-RL显著提升27B模型性能: 在Qwen3.5-27B上，Maco-RL将Overall分数从43.6提升至60.1（S2阶段），超越Qwen3.6-27B的49.8；在Qwen3.8-27B上，Overall从61.4提升至67.0，达到27B模型中的最优，并超越多个更大规模模型。
- 混合任务训练提高数据效率: 与单任务RL相比，Maco-RL在更少的累计优化器更新次数下达到更高的平均Pass@1，表明混合任务训练能更高效地利用数据。
- TBS促进探索与能力巩固: 消融实验表明，TBS通过前沿缓冲维持探索，强化缓冲集中资源于偶尔成功的实例，历史缓冲保留旧能力，从而提升学习效率和解决未解决实例的能力。

## 4. Do We Still Need Reinforcement Learning When We Can Read the World Model?

**Topics:** GUI Agent, LLM-based Coding Agent, Model-based RL, Policy Synthesis
**Authors:** Mingchao Zhang, Miduo Cui, Kangze He, Yuanjun Li, Dapeng Li, Ce Zhang, Chuanchen Luo, Xue Yan, Mingzhe Xing, Zhumin Chen, Hangyu Mao, Bin Zhang, Zhiwei Xu
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2611.34656v1) | [PDF](http://arxiv.org/pdf/2611.34656v1.pdf)

### 1. 一句话结论

通过让LLM编码智能体直接阅读环境源代码来合成控制策略，可以在无需任务特定强化学习训练的情况下，达到或超越传统RL方法的性能，同时大幅减少环境交互次数。

### 2. 为什么重要

这项工作挑战了强化学习在顺序决策中的必要性，提出了一种利用可读世界模型（环境源代码）直接合成策略的新范式，有望显著提高样本效率，并为LLM在自主决策中的应用开辟新途径。

### 3. 研究问题

1. 当环境源代码可读时，LLM编码智能体能否直接合成有效的控制策略，而无需任务特定的强化学习训练？
2. 与传统的强化学习方法相比，这种策略合成方法在性能和交互效率上表现如何？

### 4. 背景与问题设定

强化学习在顺序决策中取得了显著成功，但通常需要大量交互经验。基于模型的强化学习通过世界模型来减少这种依赖，但通常仍用于规划或策略优化。本文提出一种替代范式：利用LLM编码智能体直接阅读环境源代码（可读世界模型），通过推理环境机制来合成可执行的控制策略，无需任务特定的RL训练。

### 5. 方法概览

- 任务 / 环境: 涵盖多智能体协调（SMAC、MPE）、单智能体决策与控制（MiniGrid、Box2D）、离线强化学习（D4RL）以及指令跟随（BabyAI）等多样化基准。
- 变量 / 干预设计: 使用LLM编码智能体（如Codex、Claude Code）读取环境源代码，生成初始策略代码，并通过在线反馈或离线数据迭代优化策略。
- 评价指标: 策略性能（如回合回报、任务成功率）和交互效率（达到目标性能所需的环境交互次数）。
- 模型比较: 与传统的强化学习基线（如PPO、DQN等）在相同基准上进行比较，同时对比无源代码访问的策略生成。
- 我的理解: 该方法将环境源代码视为可读的世界模型，LLM编码智能体通过代码推理直接生成策略，而非通过试错学习。这类似于让智能体“读懂”游戏规则后直接编写策略，而不是通过大量游戏对局来学习。

### 6. 关键发现

- 策略合成性能媲美或超越传统RL: 在多个基准上，由LLM编码智能体合成的策略在性能上与传统RL方法相当或更优，且所需交互次数显著减少。
- 交互效率大幅提升: 在部分任务中，无需任何交互即可合成有效策略；在其他任务中，仅需少量反馈迭代即可达到高性能，远低于RL训练所需的样本量。
- 可解释的决策规则: 生成的策略代码具有可读性，能够清晰展示环境知识如何转化为具体的决策规则，便于理解和调试。

- 对 Skill: 策略以代码形式呈现，便于复用和组合，可能促进技能库的构建。
- 对 Memory: 环境源代码作为外部知识，可视为一种静态记忆，减少了对交互记忆的依赖。
- 对评测: 评估方式需要从样本效率转向代码质量和推理能力，可能需要新的基准。

### 11. 局限性

- 依赖环境源代码的可读性和可访问性，在真实世界中可能不总是可用。
- LLM编码智能体的性能受限于其代码生成和推理能力，复杂环境可能难以处理。
- 离线数据质量对策略合成的影响未深入探讨。

### 12. 我的看法 / 个人笔记

这项工作提出了一个有趣且实用的范式，将LLM的代码理解能力与决策制定结合，可能改变我们对RL必要性的看法。然而，其适用性依赖于源代码的可用性，且对于高度动态或部分可观测的环境，代码推理可能不够。未来可探索将源代码与交互学习结合，以应对更复杂场景。

## 5. Diverse Alternative Reasoning Traces for Hard Math Problems

**Topics:** 数学推理, 大语言模型, 后训练
**Authors:** Lukas Aichberger, Adam Golinski, Arno Blaas, Arwen Bradley, Jacob Springer, Mehrdad Farajtabar, Michael Kirchhof, Sinead Williamson
**Venue / Year:** NeurIPS 2026 Workshop
**Links:** [Abstract](http://arxiv.org/abs/2611.34928v1) | [PDF](http://arxiv.org/pdf/2611.34928v1.pdf)

### 1. 一句话结论

DART通过从被拒绝的推理轨迹中挖掘多样化的替代推理步骤，显著提高了难题的覆盖率，并降低了生成成本。

### 2. 为什么重要

该方法解决了蒙特卡洛采样在难题上难以获得正确轨迹的问题，为后训练提供了更高效的数据挖掘手段，有望提升LLM的数学推理能力。

### 3. 研究问题

1. 如何从被拒绝的推理轨迹中有效挖掘多样化的替代推理步骤？
2. DART相比蒙特卡洛采样在难题覆盖率和生成成本上有何优势？

### 4. 背景与问题设定

在数学推理任务中，LLM的后训练通常依赖于通过验证器接受的推理轨迹。然而，对于难题，蒙特卡洛采样难以生成正确轨迹，导致数据覆盖不足。现有方法如拒绝微调和STaR存在局限性，需要更有效的轨迹挖掘方法。

### 5. 方法概览

- 任务 / 环境: 数学推理问题，使用DeepMath-103K和OpenMathInstruct-2数据集，模型为Llama-3.1-8B-Instruct。
- 变量 / 干预设计: DART从被拒绝的轨迹出发，分解为推理步骤，基于位置加权不确定性选择步骤，生成多样化替代候选，并贪婪完成轨迹。
- 评价指标: 问题覆盖率（至少有一条接受轨迹的问题数）、生成成本（每条接受轨迹的估计成本）、后训练后的准确率（MATH-500和AIME）。
- 模型比较: 与全轨迹蒙特卡洛采样、步骤级蒙特卡洛采样（贪婪/采样续写）以及DART的消融变体进行比较。
- 我的理解: DART的核心在于利用被拒绝轨迹的结构，通过局部替换不确定步骤来探索替代推理路径，而不是从头采样，从而更高效地发现正确轨迹。

### 6. 关键发现

- DART提高难题覆盖率: 在DeepMath-103K难题上，DART比蒙特卡洛采样多恢复37%的问题，且覆盖率提升可达2倍。
- DART降低生成成本: 每条接受轨迹的估计生成成本比蒙特卡洛采样低30%，尽管每次尝试的成本略高。
- 后训练效果提升: 使用DART挖掘的轨迹进行后训练，在MATH-500和AIME上取得最高点估计，比蒙特卡洛采样高5个百分点。
