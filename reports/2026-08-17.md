## 1. Wyvern: An Agentic Framework for Generating Grounded Multimodal Reports

**Topics:** Multi-agent Framework, Automated Report Generation, Multimodal Content, Grounding, Claims Verification
**Authors:** Beatrice Alessandra Motetti, Emilien Guandalino, Daniele Jahier Pagliari, Alessio Burrello, Lorenz K. Müller, Konstantin Berestizshevsky, Lukas Cavigelli
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.14446v1) | [PDF](http://arxiv.org/pdf/2608.14446v1.pdf) | [Code](https://github.com/huawei-csl/wyvern)

### 1. 一句话结论

Wyvern is a multi-agent framework that generates grounded, multimodal technical reports by integrating web search, image selection, and a claims auto-revision stage, achieving up to 2.3× citation recall and 1.6× citation precision over baselines.

### 2. 为什么重要

As scientific knowledge grows rapidly, automated report generation tools must produce not only coherent text but also trustworthy, evidence-grounded content. Wyvern addresses the critical issue of grounding by explicitly verifying atomic claims against cited sources through a two-stage verification process, which enhances reliability and user trust in AI-generated summaries.

### 3. 研究问题

1. How can a multi-agent framework generate multimodal technical reports that are both informative and grounded in retrieved evidence?
2. Does a claims auto-revision stage, using atomic claim decomposition and two-stage verification, improve the factuality and citation quality of generated reports compared to existing methods?

### 4. 背景与问题设定

The volume of published content, especially in AI, is growing rapidly, making it hard for researchers to keep up. While generative models can synthesize content, they often lack grounding in factual evidence. Existing frameworks for automated report generation either omit images or do not verify the factual support of claims. Wyvern aims to fill this gap by producing multimodal reports with integrated figures and a claims verification step that operates at the atomic claim level.

### 5. 方法概览

- 任务 / 环境: Automated generation of multimodal technical reports on user-specified topics, using web search as the primary information source.
- 变量 / 干预设计: Wyvern uses a multi-agent pipeline with three main modules: search (retrieval and filtering of web documents), report generation (outline creation, section expansion, image insertion, overview table), and grounding (decomposition of text into atomic claims, two-stage verification against cited references—first using summaries, then full text if needed—and revision/removal of unsupported claims).
- 评价指标: Human evaluation (perceived figure informativeness, overall usefulness) and automatic metrics (citation recall and precision computed at the atomic claim level, not sentence level).
- 模型比较: Compared against STORM, WebThinker, and WikiAutoGen. Wyvern's figures were rated more informative in 87% of cases, and reports more useful in 63%–100% of instances. Automatic evaluation shows up to 2.3× citation recall and 1.6× citation precision improvement.
- 我的理解: The framework is designed as a modular pipeline where each agent handles a specific sub-task, enabling focused optimization. The grounding module is particularly innovative: it breaks sentences into atomic claims (finer than sentence-level), checks each against the cited source via a two-stage process (first summary, then full text if needed), and revises or removes unsupported claims. This two-stage verification reduces false positives and ensures only well-supported content remains, addressing partial support issues.

### 6. 关键发现

- Superior perceived figure informativeness: In human evaluation, Wyvern's figures were rated as more informative than those from WikiAutoGen in 87% of cases.
- Higher overall report usefulness: Wyvern's reports were rated as more useful than those from STORM, WebThinker, and WikiAutoGen in 63% to 100% of instances.
- Improved citation quality at atomic claim level: Automatic evaluation using atomic claim-level metrics shows Wyvern achieves up to 2.3× improvement in citation recall and 1.6× in citation precision over baselines, avoiding partial support issues inherent in sentence-level metrics.

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: Wyvern demonstrates that a multi-agent architecture with specialized roles (search, writing, verification) can produce higher-quality, more trustworthy outputs than monolithic models. This modular design can be adapted to other content generation tasks.
- 对 Skill: The framework automates the skill of synthesizing information from multiple sources into a coherent, well-structured report with proper citations. It reduces the manual effort of literature review and report writing.
- 对 Memory: The knowledge database built during the search phase acts as an external memory, storing retrieved documents and summaries. The grounding module uses this memory to verify claims, effectively reducing hallucinations.
- 对评测: The paper compares human evaluation with automatic metrics, showing that citation recall and precision at the atomic claim level correlate with perceived quality. This suggests that automatic grounding metrics can serve as proxies for human judgment in evaluating report generation systems.

### 11. 局限性

- The framework relies on web search quality and parser effectiveness; incomplete or poorly parsed documents may degrade output.
- The claims verification step uses LLM-based NLI, which may still produce false positives/negatives, especially for nuanced claims.
- Human evaluation is limited to a small set of topics and participants; generalizability across domains is not fully established.

### 12. 我的看法 / 个人笔记

Wyvern presents a well-engineered solution to the critical problem of grounding in automated report generation. The modular design and explicit claims verification at the atomic claim level are practical innovations that directly address user trust. However, the reliance on LLM-based verification introduces potential biases, and the computational cost of the multi-agent pipeline may be high. Future work could explore more efficient verification methods or integration with external knowledge bases.

### 14. 总结

Human evaluation shows its figures are more informative and reports more useful than baselines like STORM, WebThinker, and WikiAutoGen. Automatic evaluation using atomic claim-level metrics confirms up to 2.3× improvement in citation recall and 1.6× in citation precision. The framework's modular design and focus on grounding make it a significant step toward trustworthy AI-generated content.

## 2. TimeSage-EV: A Live Benchmark for Agentic Time Series Analysis in Evolving Environments

**Topics:** Time Series Analysis, LLM Agents, Benchmarking
**Authors:** Qingren Yao, Yaxuan Kong, Yuqi Nie, Yichen Li, Stefan Zohren, Anna Vettoruzzo, Qingsong Wen, Ming Jin, Joaquin Vanschoren
**Venue / Year:** arXiv:2608.14270v1
**Links:** [Abstract](http://arxiv.org/abs/2608.14270v1) | [PDF](http://arxiv.org/pdf/2608.14270v1.pdf)

### 1. 一句话结论

TimeSage-EV 是一个实时基准，用于评估 LLM 代理在动态数据发布环境中进行时间序列分析的能力，揭示了现有模型在时间有效性、外部上下文使用和适应性方面的显著缺陷。

### 2. 为什么重要

该基准填补了现有静态时间序列问答基准和代理基准之间的空白，首次系统性地评估了 LLM 代理在重复数据发布、需严格遵循时间截止点的动态工作流中的表现，对金融、公共卫生等高风险领域的实际应用具有重要指导意义。

### 3. 研究问题

1. LLM 代理能否在动态变化的数据环境中，持续进行时间序列分析并遵守时间截止点？
2. 现有前沿 LLM 代理在时间有效性、外部上下文使用和适应性方面存在哪些具体失败模式？

### 4. 背景与问题设定

在高风险领域，时间序列分析并非一次性预测任务，而是需要持续吸收新数据、更新历史背景并综合数值趋势与机构报告的重复性工作流。现有基准（如 ChatTime、Time-MQA）多基于固定快照，无法评估代理在证据随时间变化时的表现。TimeSage-EV 通过构建实时基准，模拟机构定期发布数据的场景，要求代理在每次新数据发布时更新分析并生成报告，同时严格遵循信息截止点。

### 5. 方法概览

- 任务 / 环境: 包含 60 个真实机构场景，覆盖农业、气候、能源、金融、医疗和交通六大领域，数据发布频率包括月、周、日和不定期，时间跨度从 2023 年 2 月到 2026 年 5 月，共 1,485 个场景-周期问答对。
- 变量 / 干预设计: 每个周期，代理接收截止点前的时间序列数据和源文档，而目标周期的发布数据被保留作为真实标签。代理需回答结构化问题并生成基于截止点证据的报告。评估分为独立评估（每周期从头开始）和顺序评估（代理可携带状态）。
- 评价指标: 四个评估维度：关键点准确性（结构化答案与真实标签匹配）、关键点覆盖率（报告中提及关键点）、报告忠实性（报告声明基于截止点有效证据）和报告质量（清晰度、组织性等），每个维度 0-100 分。
- 模型比较: 评估了前沿 LLM 代理（如 GPT-4、Claude 等）以及 TimeSage-1.0（一种具有可重用分析技能库的自进化代理）。结果显示，不同模型层级间性能差距显著，且普遍存在时间误用、外部上下文使用失败和适应性不足等问题。
- 我的理解: 该基准通过严格的时间隔离和累积证据状态，真实模拟了动态分析工作流。多维度评估体系不仅关注答案正确性，还强调报告的证据基础，有助于诊断代理的深层缺陷。

### 6. 关键发现

- 性能差距显著: 前沿 LLM 代理在简单任务（状态识别）上表现较好，但在中等（变化检测、组成分析）和困难（归因、预测）任务上性能大幅下降，且不同模型层级间差异明显。
- 常见失败模式: 代理普遍存在时间误用（使用未来证据）、外部上下文使用失败（忽略文档信息）和适应性不足（无法根据新数据更新判断）等问题。
- TimeSage-1.0 的改进: TimeSage-1.0 通过可重用分析技能库，在部分任务上优于基础代理，但仍无法完全解决时间有效性和报告综合问题。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 代理系统需增强时间感知能力，确保在动态数据环境中严格遵循信息截止点，并能够根据新证据更新历史判断。
- 对 Skill: 可重用分析技能库（如 TimeSage-1.0）有助于提升代理在重复任务中的效率，但需进一步优化以适应不同场景。
- 对 Memory: 代理的记忆管理至关重要，需在顺序评估中有效利用历史状态，同时避免时间误用。
- 对评测: 多维度评估（准确性、覆盖率、忠实性、质量）比单一指标更能揭示代理的深层缺陷，应成为动态任务评估的标准。

### 11. 局限性

- 基准覆盖的领域和场景数量有限（60 个场景），可能无法完全代表所有高风险领域。
- 评估依赖 LLM 判断报告忠实性和质量，可能存在主观偏差。
- 当前基准仅支持英文文档和问题，限制了多语言场景的适用性。

### 12. 我的看法 / 个人笔记

TimeSage-EV 是一个设计精良的基准，首次将动态数据发布和时间截止点纳入时间序列分析评估，揭示了现有 LLM 代理的关键缺陷。其多维度评估体系尤其值得借鉴，但未来需扩展领域覆盖、减少评估主观性，并支持多语言场景。

## 3. Can Language Models Understand mmWave Data? Benchmarking Large Language Models for mmWave Radar-Based Human Understanding

**Topics:** mmWave Radar, Large Language Models, Human Understanding, Benchmark
**Authors:** Jeongwan Shin, Jaehyeon Kim, Donguk Ko, Jaeho Choi
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.14179v1) | [PDF](http://arxiv.org/pdf/2608.14179v1.pdf)

### 1. 一句话结论

通过将毫米波点云序列文本化，无需微调即可让LLM在零样本条件下理解人体动作，且对视觉退化具有鲁棒性。

### 2. 为什么重要

首次系统探索LLM与毫米波雷达的集成，为低光照、遮挡等视觉退化场景提供了一种无需专用编码器的感知方案，并建立了标准化评测基准。

### 3. 研究问题

1. LLM能否直接理解文本化的毫米波点云数据并完成人体动作推理？
2. 毫米波模态在视觉退化条件下是否比RGB更鲁棒？

### 4. 背景与问题设定

毫米波雷达在低光照和遮挡下具有独特优势，但缺乏雷达-语言配对数据、跨数据集异质性严重、缺少基础毫米波编码器，导致现有方法需针对每个数据集重新训练。本文通过最小文本化接口将点云序列转为自然语言，使现成LLM能在问答设置中工作。

### 5. 方法概览

- 任务 / 环境: 六种场景（正常、有家具、雨、烟、暗、遮挡），五种QA任务（动作识别、空间移动验证、时间动作排序、动作基数估计、肢体运动检测），多种毫米波硬件。
- 变量 / 干预设计: 将5D点云（x,y,z,多普勒,强度）序列文本化为坐标格式，直接作为LLM输入；构建mmWave-QA基准，通过校准感知预处理和全局分类对齐整合三个公开数据集。
- 评价指标: 准确率（多选QA），按任务类型和场景条件分别评估。
- 模型比较: 比较零样本、少样本和链式思维推理策略，并与RGB模态在视觉退化下的表现对比。
- 我的理解: 核心创新在于用文本化绕过了毫米波编码器缺失的问题，使LLM能直接处理雷达数据；基准设计考虑了硬件和场景异质性，为后续研究提供了标准化平台。

### 6. 关键发现

- LLM零样本推理能力: 现成LLM在文本化毫米波点云上展现出合理的零样本推理能力，无需任务特定微调即可识别动作。
- 毫米波模态的鲁棒性: 在视觉退化（如暗、遮挡）条件下，毫米波模态比RGB更鲁棒，性能下降更少。
- 基准覆盖多样性: mmWave-QA涵盖139个原始动作标签（精炼为86类）、80名受试者、11种环境设置，包含五种互补的QA任务。

  与当前论文关系：本文专注于单一毫米波模态，但展示了无需专用编码器的更简单集成方式。

### 14. 总结

本文提出mmWave-QA基准，通过文本化毫米波点云使LLM在零样本下理解人体动作，实验表明LLM具备合理推理能力且毫米波模态在视觉退化下比RGB更鲁棒，为雷达-语言集成研究奠定了基础。

## 4. SheetCompass: Hierarchical Relation Graphs for Agentic Spreadsheet Reasoning

**Topics:** GUI Agent, Spreadsheet Reasoning, Multi-Agent Systems
**Authors:** Panjing He, Mingyue Cheng, Yucong Luo, Li Li, Xiaohan Zhang
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.14452v1) | [PDF](http://arxiv.org/pdf/2608.14452v1.pdf) | [Code](https://anonymous.4open.science/r/sheetcompass-411C)

### 1. 一句话结论

SheetCompass通过层次关系图与双级记忆机制显式建模电子表格结构信息，在多个复杂电子表格基准上取得最优性能，显著超越SheetAgent等基线。

### 2. 为什么重要

现有方法将电子表格展平为文本序列，丢失二维空间布局和跨表语义关联，导致LLM在复杂任务中性能骤降。SheetCompass通过恢复结构信息，为自动化电子表格处理提供了更接近人类专家认知的新范式，并在多个基准上验证了有效性。

### 3. 研究问题

1. 如何显式建模电子表格的二维空间布局和跨表语义关联以弥补信息扁平化带来的损失？
2. 如何设计多智能体协作框架，结合记忆机制，实现高保真的电子表格自动化推理？

### 4. 背景与问题设定

电子表格是半结构化数据的重要载体，但现有LLM方法通常将其展平为Markdown或JSON等顺序字符串，导致行/列空间邻接关系丢失、跨表数据依赖被割裂。人类专家依赖视觉扫描快速重建空间拓扑，而模型只能在无维度约束的序列空间中统计近似，造成结构理解鸿沟。

### 5. 方法概览

- 任务 / 环境: 电子表格自动化操作任务，输入为多表工作簿和自然语言指令，输出为目标表格序列。
- 变量 / 干预设计: 构建层次图（表节点+列节点）保留结构边（包含边、邻接边）和语义边（基于余弦相似度与LLM逻辑评分，阈值α和权重β可调），并引入专家知识记忆（领域知识+工具使用经验）和推理经验记忆（动态记录当前任务轨迹，成功轨迹迁移至专家知识记忆）。
- 评价指标: 任务成功率（Task Success Rate），在多个复杂电子表格数据集上评估。
- 模型比较: 与SheetAgent、SheetCopilot、SpreadsheetLLM等基线方法对比，SheetCompass在多个复杂电子表格数据集上取得最优性能，具体数值未在摘要中给出。
- 我的理解: 该方法的核心是将电子表格从扁平文本重构为层次图，使智能体能够像人类一样利用空间线索进行导航和推理，同时通过双级记忆机制减少错误累积，实验数据证实了其有效性。

### 6. 关键发现

- 层次图有效恢复结构信息: 通过表级和列级节点以及结构边与语义边的建模，SheetCompass成功保留了电子表格的二维布局和跨表关联，为下游推理提供了稳定的空间上下文。
- 双级记忆机制提升推理可靠性: 专家知识记忆提供稳定的工具使用和领域知识，推理经验记忆动态记录当前任务轨迹并回传，有效防止连续错误，支持工作流演化。消融实验显示，移除记忆机制后性能显著下降。
- 多智能体协作实现高保真执行: 导航探索器、逻辑程序员和关键反射器三个专用智能体分别负责拓扑感知、代码生成和闭环验证，在复杂跨表任务中显著优于单智能体方法。

## 5. AgentRewind: Recoverable Execution for Long-Horizon LLM Agents

**Topics:** LLM Agent, Long-Horizon Execution, Recovery Framework
**Authors:** Yu Zhuang, Kefei Chen, Yitong Duan, Shuxin Zheng, Jian Li, Xu-Yao Zhang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.14380v1) | [PDF](http://arxiv.org/pdf/2608.14380v1.pdf) | [Code](https://github.com/Futuresis/replay-agent-recorder)

### 1. 一句话结论

AgentRewind通过记录并恢复智能体上下文和环境状态的对齐检查点，显著提升了长周期任务的成功率与清单进度。

### 2. 为什么重要

长周期任务中早期错误会沿轨迹传播，现有方法缺乏运行时恢复能力；AgentRewind首次实现了智能体上下文与可控环境的联合回滚，为长周期智能体可靠性提供了新范式。

### 3. 研究问题

1. 如何使LLM智能体在长周期执行中从早期错误中恢复？
2. 联合恢复智能体上下文和受控环境状态能否提升任务完成率？

### 4. 背景与问题设定

LLM智能体在长周期任务（如软件工程、科学实验）中，早期错误会污染后续上下文和环境状态，导致任务失败。现有方法主要通过计划优化和安全检查预防错误，但缺乏错误发生后的恢复机制。

### 5. 方法概览

- 任务 / 环境: MettleBench：82个工程任务，每个任务包含一系列有序验收标准，环境为可控工作区目录树。
- 变量 / 干预设计: AgentRewind在智能体决策边界记录对齐检查点（上下文+环境状态），当智能体判断无法继续时，可选择回滚到历史检查点，并注入回滚记忆。
- 评价指标: 任务成功率（所有验收标准满足的比例）、平均清单进度（最长满足前缀长度/总标准数）。
- 模型比较: 在GPT-5.4、GPT-5.4 mini、Qwen3.7-Max等7个模型上对比Continue、Restart with Experiences、Safety Review和AgentRewind。
- 我的理解: AgentRewind的核心创新在于将智能体上下文和环境状态作为联合检查点记录，回滚时同时恢复两者，并利用回滚记忆保留先前尝试的有用信息，从而避免重复错误。

### 6. 关键发现

- AgentRewind在所有模型上优于基线: 在GPT-5.4和GPT-5.4 mini上，AgentRewind的任务成功率和平均清单进度均最高，且在中长轨迹任务上优势更显著。
- 回滚在长轨迹任务中收益更大: 按Continue轨迹长度分组，AgentRewind在长轨迹组（>75分位）上的成功率提升远超短轨迹组。
- AgentRewind在Terminal-Bench 2.0上泛化有效: 在非MettleBench基准上，AgentRewind仍取得83.1%成功率，优于Continue的78.7%。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: AgentRewind可作为通用运行时层集成到现有智能体系统中，提升长周期任务可靠性。
- 对 Skill: 回滚记忆可积累失败经验，帮助智能体学习更优策略。
- 对 Memory: 回滚记忆的设计（总结失败假设和替代策略）为智能体记忆系统提供了新思路。
- 对评测: MettleBench的清单进度指标为长周期任务提供了更细粒度的评估维度。

### 11. 局限性

- 仅能恢复受控环境（工作区文件系统），无法撤销网络请求等外部副作用。
- 回滚决策依赖智能体自身判断，可能因错误选择而降低效率。
- MettleBench任务规模有限（82个），泛化性需更多验证。

### 12. 我的看法 / 个人笔记

AgentRewind通过联合恢复上下文和环境状态，有效解决了长周期任务中错误传播的难题，其回滚记忆设计尤为巧妙。未来可探索自动回滚触发机制和跨环境恢复。
