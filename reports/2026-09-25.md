## 1. Jev-Mobile: Jev as an Executor for Mobile GUI Agents

**Topics:** GUI Agent, 移动端智能体, 视觉语言模型, 决策模型
**Authors:** Linghua Zhang
**Venue / Year:** arXiv preprint, 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.30186v1) | [PDF](http://arxiv.org/pdf/2609.30186v1.pdf)

### 1. 一句话结论

Jev-Mobile通过将高频动作执行委托给轻量级决策模型Jev，在保持与SeeAct-V相当任务成功率的同时，显著降低了延迟和API成本。

### 2. 为什么重要

该研究挑战了移动GUI智能体必须依赖VLM逐步推理的范式，提出了一种低频率VLM规划与高频率轻量级执行相结合的新架构，为构建更高效、更经济的自主移动智能体提供了可行路径。

### 3. 研究问题

1. 如何将移动GUI智能体中的高层规划与低层动作执行解耦，以减少VLM调用频率？
2. 轻量级决策模型Jev在AndroidWorld任务套件上的任务成功率、执行时间和成本表现如何？
3. 如何区分覆盖率、选择、交接对失败的影响，以诊断Jev-Mobile的性能瓶颈？

### 4. 背景与问题设定

现有移动GUI智能体通常依赖VLM在每个交互步骤同时进行规划和动作落地，导致高延迟和高模型服务成本。Jev-Mobile提出由VLM低频指定局部目标，而由快速决策模型Jev在可访问性树定义的动作空间中高频选择具体动作，从而在保持自适应交互的同时提升效率。

### 5. 方法概览

- 任务 / 环境: AndroidWorld任务套件，包含多种移动端任务，需通过屏幕截图、可访问性树和设备上下文进行交互。
- 变量 / 干预设计: 比较三种系统：Step-wise VLM（逐步VLM）、SeeAct-V（使用UI-TARS-1.5-7B接地）和Jev-Mobile（VLM规划+Jev执行）。所有系统共享相同的通用VLM（Qwen3.8-Max），但执行机制不同。
- 评价指标: 全任务成功率、成功轨迹的平均总时间、执行模型平均时间、执行模型总成本、平均模型API成本。
- 模型比较: Step-wise VLM: 84%成功率；SeeAct-V: 78%；Jev-Mobile: 79%。Jev-Mobile在成功轨迹上平均总时间132.67秒，比Step-wise VLM低32.7%，比SeeAct-V低18.4%；平均模型API成本0.072744美元，比Step-wise VLM低73.4%，比SeeAct-V低约62.4%（根据原文数据计算）。
- 我的理解: Jev-Mobile的核心创新在于将动作选择从VLM中分离出来，由专门的决策模型处理，而VLM仅负责理解任务和设定局部目标。这种分工使得高频动作执行变得轻量，同时通过重新观察可访问性树确保动作的有效性。

### 6. 关键发现

- 任务成功率接近SeeAct-V: Jev-Mobile在AndroidWorld上达到79%的成功率，与SeeAct-V的78%相当，仅比Step-wise VLM低5个百分点，表明轻量级执行模型可以胜任大部分动作选择任务。
- 显著降低延迟和成本: 成功轨迹的平均总时间减少32.7%（对比Step-wise VLM），执行模型时间减少94.5%，平均模型API成本减少73.4%，展示了分层架构的经济优势。
- 分解分析覆盖率、选择与交接: 论文区分了覆盖率（是否存在可接受候选）、选择（Jev是否正确选择）和交接（是否恰当返回控制），为诊断失败提供了更细粒度的视角。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 表明分层架构（VLM规划+轻量级执行）能有效降低资源消耗，同时保持任务完成能力，为资源受限环境下的智能体部署提供新思路。
- 对 Skill: Jev作为专用执行模型，其训练和优化可能成为独立技能，可复用于不同GUI环境，促进技能模块化。
- 对 Memory: 动作历史的分组记录和压缩机制提示了记忆管理的重要性，未来可探索更高效的历史表示。
- 对评测: 除了成功率，延迟和成本应成为评估GUI智能体的重要指标，以反映实际部署可行性。

### 11. 局限性

- 仅在AndroidWorld任务上评估，未涵盖Web界面，其DOM结构和交互模式可能不同。
- 仅与两个基线比较，未测试将Jev替换为小型VLM的效果，无法区分是决策模型类型还是分层架构带来的优势。
- 依赖可访问性树，对于树中缺失的视觉目标无法处理，限制了在复杂UI上的适用性。

### 12. 我的看法 / 个人笔记

Jev-Mobile提出了一种实用的分层执行框架，通过将高频动作选择交给轻量级模型，显著提升了效率。其成功表明，并非所有步骤都需要VLM的深度推理。未来工作可探索更通用的候选生成机制（如结合视觉信息）以及跨平台适应性，以扩大应用范围。

### 13. 这篇工作引用的近期高影响力相关文章

- SeeAct: Grounding LLM Actions in Web Environments
  为什么重要：SeeAct是SeeAct-V的基础，展示了将LLM规划与视觉接地分离的思路，与Jev-Mobile的分层思想相关。
  核心贡献：提出SeeAct框架，将LLM用于高层规划，视觉模型用于动作接地，提高Web智能体效率。
  与当前论文关系：Jev-Mobile借鉴了SeeAct的分离思想，但将接地替换为可访问性树上的决策模型，并应用于移动端。
- UI-TARS: A Foundation Model for GUI Agents
  为什么重要：UI-TARS是SeeAct-V中使用的视觉接地模型，代表了视觉GUI智能体的先进水平，与Jev-Mobile形成对比。
  核心贡献：提出UI-TARS模型，通过视觉语言预训练实现GUI理解和动作定位。
  与当前论文关系：Jev-Mobile与UI-TARS在动作执行上不同，前者使用可访问性树，后者使用视觉接地，但两者都旨在提高GUI智能体性能。

### 14. 总结

Jev-Mobile通过VLM低频规划与Jev高频执行的分层设计，在AndroidWorld上实现了79%的任务成功率，同时将成功轨迹的平均总时间降低32.7%，模型API成本降低73.4%。该研究验证了轻量级决策模型作为移动GUI执行器的可行性，为高效自主智能体提供了新方向。

## 2. GRASP: Generating, Revising, and Assessing for Strategic Planning with Agentic AI

**Topics:** GUI Agent, LLM Planning, Agentic AI
**Authors:** Arunabh Srivastava, Mohammad A., Khojastepour, Srimat Chakradhar, Sennur Ulukus
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.30147v1) | [PDF](http://arxiv.org/pdf/2609.30147v1.pdf)

### 1. 一句话结论

GRASP 通过将规划流程解耦为生成、修订和评估三个隔离模块，显著提升了复杂任务规划的性能与鲁棒性。

### 2. 为什么重要

该工作有效缓解了 LLM 在复杂任务中因指令冲突和注意力疲劳导致的性能下降问题，为构建可靠的多步骤规划智能体提供了新范式。

### 3. 研究问题

1. 如何通过模块化设计减少 LLM 在复杂规划任务中的错误累积？
2. GRASP 在多任务扩展场景下能否保持性能稳定？

### 4. 背景与问题设定

LLM 在简单任务上表现良好，但随着任务复杂度增加，其可靠性急剧下降，这被称为“指令诅咒”。现有方法如思维链、思维树等虽能增强推理，但缺乏结构化的约束管理，导致长程规划中错误累积。GRASP 旨在通过解耦生成、修订和评估阶段，实现高质量的自然语言可执行计划生成。

### 5. 方法概览

- 任务 / 环境: 涵盖日历调度、逻辑谜题、科学数学和科学问答等多样化的规划任务，通过 RunAgent 执行计划并评估准确性。
- 变量 / 干预设计: GRASP 包含三个模块：GenPlan 生成全局宏指南，RevPlan 在隔离上下文中探索局部策略，VerPlan 独立评估并选择最优计划。
- 评价指标: 使用精确匹配（EM）准确率或标准准确率，通过 LLM 评判器与人工验证一致性。
- 模型比较: 与直接 LLM 规划器、GPT-5-mini 等前沿推理模型对比，GRASP 在多个数据集上取得显著提升。
- 我的理解: GRASP 的核心在于通过上下文隔离和模块化分工，避免单一上下文中的信息过载，从而减少错误传播，类似于人类认知中的“识别-推理-判断”过程。

### 6. 关键发现

- 性能显著提升: 在 Natural Plan Calendar Scheduling 上提升约 12.4%，在 ZebraLogic 上提升约 30.8%，在 SciBench Math 上也有显著增益。
- 多任务鲁棒性: 在双任务交错环境中，GRASP 完全消除了多任务性能下降，而标准规划器则出现崩溃。
- 超越前沿模型: GRASP 在多个基准上优于 GPT-5-mini，平均提升 14.5%。

## 3. World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal

**Topics:** 机器人操作, 视觉语言模型, 智能体系统
**Authors:** Yehang Zhang, Haojian Huang, Yifan Chang, Jianchong Su, Bohan Zhou, Yingjie Xu, Wosong Chen, Tianhao Zhou, Chenxu Wang, Tianyi Zhang, Yangkai Wei, Wenqian Li, Shiyuan Deng, Yinchuan Li, Ying-Cong Chen, Zexi Li
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.29964v1) | [PDF](http://arxiv.org/pdf/2609.29964v1.pdf)

### 1. 一句话结论

WAA 通过视觉动作工作空间，让通用 VLM 直接操控机器人，在 LIBERO-Pro 上达到 75.6% 的平均成功率，并可通过交互轨迹蒸馏训练小型 VLM。

### 2. 为什么重要

该方法无需微调 VLM 即可实现机器人操作，保留了模型的通用能力，同时通过技能库和轨迹蒸馏实现知识获取与迁移，为通用机器人智能体提供了新范式。

### 3. 研究问题

1. 通用 VLM 如何直接利用基本动作原语进行机器人操作并做出决策？
2. 如何通过视觉动作工作空间让 VLM 在操作过程中进行动作预演和修正？
3. 如何从专家视频和人类教学中获取可迁移的操作技能？

### 4. 背景与问题设定

现有机器人操作系统要么将 VLM 用于间接预测约束或编写程序，要么直接让 VLM 控制机器人但缺乏对局部交互的感知和动作预演能力。VLM 微调为动作预测会削弱其通用推理能力。WAA 旨在通过一个视觉动作工作空间，让 VLM 直接观察、预演和修正动作，同时通过技能库和轨迹蒸馏获取操作知识。

### 5. 方法概览

- 任务 / 环境: LIBERO-Pro 基准测试和 robosuite 仿真环境，包含多种操作任务（如抓取、放置、开抽屉等）。
- 变量 / 干预设计: WAA 是一个多智能体框架，包含主智能体、想象智能体、技能智能体。主智能体通过工具调用与视觉动作工作空间交互，工作空间提供接触视图、动作预演和视图内修正功能。
- 评价指标: 任务成功率（平均成功率）。
- 模型比较: 与端到端 VLA 模型（如 OpenVLA）、代码即策略（CaP）智能体、以及视觉工作空间基线（如 Show-Harness）进行比较。
- 我的理解: WAA 的核心在于将 VLM 的决策过程嵌入到一个可视化的、可交互的工作空间中，使得 VLM 能够像人类一样通过观察和试错来完成任务，而不是直接输出动作。

### 6. 关键发现

- SOTA 性能: 在 LIBERO-Pro 上达到 75.6% 的平均成功率，超过 ASPIRE 的 72.0%，且无需微调 VLM。
- 技能可迁移性: 从 LIBERO-90 中演化的技能可直接迁移到 robosuite 环境，无需额外学习。
- 小型 VLM 蒸馏: 通过交互轨迹微调 Qwen3.5-9B，其领域外成功率从 1.7% 提升至 43.3%，证明小型模型也能学会操作。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: WAA 展示了如何利用通用 VLM 构建机器人智能体，无需微调即可适应多种任务，并通过技能库和轨迹蒸馏实现持续学习。
- 对 Skill: 技能库以多模态形式存储操作知识，包括文本程序和参考图像，提高了技能的可解释性和可迁移性。
- 对 Memory: 交互轨迹作为记忆用于微调小型 VLM，实现了知识蒸馏，但未显式设计长期记忆机制。
- 对评测: LIBERO-Pro 和 robosuite 提供了标准评估环境，但真实世界泛化仍需进一步验证。

### 11. 局限性

- 依赖预定义的动作原语和工具，可能限制复杂操作。
- 技能库的演化需要专家视频或人类教学，数据获取成本高。
- 实验主要在仿真环境，真实世界应用需考虑感知噪声和动态环境。

### 12. 我的看法 / 个人笔记

WAA 提供了一种创新的机器人操作框架，通过视觉动作工作空间让 VLM 直接参与决策，避免了微调带来的能力退化。其技能库和轨迹蒸馏机制为知识获取和模型压缩提供了可行路径。未来可探索更复杂的动作原语和真实世界部署。

### 14. 总结

WAA 通过视觉动作工作空间，使通用 VLM 能够直接操控机器人，在 LIBERO-Pro 上取得 SOTA 结果，并展示了技能迁移和小型模型蒸馏的潜力。

## 4. An Empirical Study of VLM Pipelines for Long-Document QA

**Topics:** Long-Document QA, Vision-Language Models, Retrieval, Agentic Systems
**Authors:** Kenan E. Ak, Jay Mohta, Gwang Gook Lee, Yan Xu, Dimitrios Dimitriadis
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.29933v1) | [PDF](http://arxiv.org/pdf/2609.29933v1.pdf)

### 1. 一句话结论

在长文档QA中，图像检索显著优于文本检索（最强图像检索器Hit@5达91.4，最强文本流水线仅82.4），六工具智能体仅在大型VLM上超越静态流水线，且不同流水线在不同问题上互补，Oracle可提升约13个百分点。

### 2. 为什么重要

该研究首次在统一评估协议下系统比较了长文档QA流水线的三个关键设计维度（输入模态、检索器、智能体策略），揭示了图像检索的主导地位和智能体策略的规模依赖性，为实际部署提供了可操作的指导。同时，对现有系统（如SimpleDoc）的重新评估表明，使用官方评分器而非LLM judge可导致约9个百分点的差异，凸显了统一评估的重要性。

### 3. 研究问题

1. 在长文档QA中，输入模态（原始PDF、页面图像、提取文本）如何影响准确率和成本？
2. 检索器的模态（文本vs图像）和具体模型对检索质量的影响有多大？
3. 智能体策略（六工具函数调用）相比静态流水线在何时能带来收益？
4. 不同流水线在不同问题上的互补性如何，能否通过路由机制利用？

### 4. 背景与问题设定

长文档QA涉及数十至数百页的混合内容（文本、图表、表格），现有研究通常只关注单一访问模式，缺乏对输入模态、检索器和智能体策略的联合系统比较。本文在MMLongBench-Doc（较短但视觉多样）和LongDocURL（更长）两个基准上，使用Claude Sonnet 4.5和Qwen3.5系列模型，对多种流水线进行了受控实验，并采用官方评分器统一评估。

### 5. 方法概览

- 任务 / 环境: 两个长文档QA基准：MMLongBench-Doc（135个PDF，1082个问题）和LongDocURL（396个文档，2325个问题），涵盖理解、推理和定位任务。
- 变量 / 干预设计: 系统性地改变三个维度：输入模态（原始PDF、全部页面图像、提取文本）、检索器（BM25、BGE-M3、ColQwen2.5、Nem-CE、重排序流水线）、智能体策略（六工具函数调用智能体 vs 静态流水线）。所有配置使用相同的解码设置（温度0，无思考）。
- 评价指标: 官方评分器（A VG）计算准确率，并记录每个问题的平均输入token数（Tok）。检索质量用Hit@5衡量。
- 模型比较: 比较了Claude Sonnet 4.5（API）和Qwen3.5-4B/9B/27B（本地）作为读者，以及多种检索器。
- 我的理解: 该研究通过控制变量法，在统一评估协议下比较了不同流水线，使得结果具有可比性。关键发现是图像检索显著优于文本检索，且智能体策略的收益依赖于读者模型的规模。

### 6. 关键发现

- 图像检索主导检索性能: 最强的图像检索器（Nem-CE）在Hit@5上达到91.4，比最强的文本流水线（SIRA，82.4）高出9个百分点。具体而言，ColQwen2.5（图像）达到87.2，Nem-CE（图像）达到91.4，而文本检索器如BM25（65.6）和BGE-M3（70.8）明显落后。图像检索的领先在跨基准平均后依然显著，表明模态比具体模型更重要。
- 智能体策略的收益取决于读者规模: 六工具智能体在Qwen3.5-4B/9B上不如静态页面输入，在27B上持平，在Sonnet 4.5上领先11.7个百分点（MMLongBench-Doc）。这表明智能体策略需要足够强大的VLM才能发挥优势。
- 原始PDF输入成本高且随长度崩溃: 原始PDF在LongDocURL上从50-75页到125-150页准确率下降42.6个百分点，主要因为请求失败；而检索和智能体策略在不同长度下保持稳定。
- 流水线间存在互补性: 三个最强流水线在不同问题上成功，Oracle选择最佳流水线可提升约13个百分点，但基于证据类型的路由几乎无法恢复这种增益，说明互补性难以通过简单规则利用。
- 重新评估现有系统: 对SimpleDoc等系统的重新评估显示，其报告的数字在官方评分器下下降约9个百分点，强调了统一评估协议的必要性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 智能体策略并非总是优于静态流水线，其收益依赖于底层VLM的能力。在部署时，应根据模型规模权衡是否采用智能体。
- 对 Skill: 图像检索技能（如ColQwen2.5、Nem-CE）对于长文档QA至关重要，应优先考虑。
- 对 Memory: 智能体通过工具调用动态访问文档，减少了静态输入的内存占用，但增加了推理步骤。
- 对评测: 评估协议对结果影响显著，使用官方评分器而非LLM judge可导致约9个百分点的差异，建议社区采用统一评估标准。

### 11. 局限性

- 仅使用两个基准，可能无法覆盖所有长文档场景。
- 智能体策略的收益可能依赖于特定工具集和提示设计。
- Oracle分析基于固定流水线集合，实际路由可能无法达到相同增益。

### 12. 我的看法 / 个人笔记

该研究提供了宝贵的实证数据，表明在长文档QA中，检索模态比具体检索器更重要，且智能体策略并非万能。未来工作可以探索更智能的路由机制，以利用不同流水线的互补性。

## 5. Graph-Based Inference and Topology-Aware Multi-Agent Reinforcement Learning for Large-Scale Railway Network Management

**Topics:** 多智能体强化学习, 图神经网络, 基础设施管理, 铁路维护规划
**Authors:** Giacomo Arcieri, Gregory Duthé, Christophe Muller, Konstantinos G. Papakonstantinou, Daniel Straub, Eleni Chatzi
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.30150v1) | [PDF](http://arxiv.org/pdf/2609.30150v1.pdf)

### 1. 一句话结论

提出一种基于图神经网络的拓扑感知多智能体强化学习框架，通过零样本迁移实现大规模铁路网络维护规划的高效扩展。

### 2. 为什么重要

该工作解决了基础设施管理中大规模网络维护规划的计算瓶颈，通过图结构编码和零样本迁移，显著降低了训练成本，同时保持优越性能，为实际铁路网络管理提供了可扩展的智能决策支持。

### 3. 研究问题

1. 如何利用图结构建模铁路网络中的空间相关性和协调机制，以提升维护策略的优化效果？
2. 如何通过零样本迁移实现从小型网络训练到大型网络部署的扩展，避免重新训练的计算开销？

### 4. 背景与问题设定

铁路基础设施维护规划是一个长期、随机、系统级交互的序贯决策问题。传统方法要么集中式处理导致计算不可行，要么完全分散而缺乏协调。现有深度强化学习方法在扩展到真实规模网络时面临挑战。本文提出结合图学习的环境推断和拓扑感知的多智能体强化学习，以解决可扩展性和协调性问题。

### 5. 方法概览

- 任务 / 环境: 基于瑞士联邦铁路苏黎世地区10年轨道几何监测数据构建的铁路网络维护环境，网络被离散化为150米长的节点，节点特征包括D1和D2指标，动作空间包括不动作、捣固、再捣固和轨道更新。
- 变量 / 干预设计: 采用分层贝叶斯模型，利用高斯过程在图上的核函数推断环境动态，捕捉空间相关性；随后使用图卷积网络和图Transformer参数化多智能体强化学习代理，实现拓扑感知的协调策略。
- 评价指标: 主要评估长期维护成本（包括维护成本和失效成本）以及训练时间，并与优化启发式方法和标准多智能体强化学习基线进行比较。
- 模型比较: 对比了优化启发式方法（如基于阈值的策略）和标准多智能体强化学习基线（如独立Q学习、VDN、QMIX等），以及集中式和分散式方法。
- 我的理解: 该方法的核心创新在于将图结构嵌入到环境推断和策略学习中，使得代理能够利用局部拓扑信息进行协调，同时通过零样本迁移实现跨网络规模的泛化，这类似于图神经网络在节点分类中的归纳学习能力。

### 6. 关键发现

- 图感知代理显著优于基线: 在训练网络和大型未见网络上，所提出的图感知多智能体强化学习方法在长期成本上显著优于优化启发式方法和标准多智能体强化学习基线，表明拓扑感知的协调策略能有效利用空间相关性。
- 零样本迁移实现高效扩展: 仅在小规模网络（87个节点）上训练的代理，能够零样本部署到大规模网络（如1000个节点）上，性能优于从头训练的基线，且训练时间大幅减少，展示了图结构归纳能力带来的可扩展性。
