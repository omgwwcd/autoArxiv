## 1. Credit Where It Matters: Dependency-Aware Policy Optimization for Terminal Agents

**Topics:** GUI Agent, 强化学习, 信用分配, 终端智能体
**Authors:** Yu Li, Guangfeng Cai, Long-Fei Li, Shuo Han, Shengtian Yang, Han Luo, Kaibing Yang, Lei Feng
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.03634v1) | [PDF](http://arxiv.org/pdf/2610.03634v1.pdf)

### 1. 一句话结论

DepGPO通过追踪命令间的读写依赖，将轨迹级优势重新分配给真正影响任务验证结果的步骤，显著提升终端智能体的任务性能和训练稳定性。

### 2. 为什么重要

现有RL方法在终端任务中常将信用均匀分配给所有步骤，导致无关命令被错误强化。DepGPO利用执行轨迹中的依赖关系，实现细粒度信用分配，为复杂多步终端任务的强化学习提供了新思路，有望提升智能体在编码、调试等场景的效率和可靠性。

### 3. 研究问题

1. 如何利用终端命令间的读写依赖关系进行更精确的信用分配？
2. DepGPO能否在复杂终端任务中提升强化学习的任务性能和训练稳定性？

### 4. 背景与问题设定

终端智能体在编码、调试等多步任务中依赖强化学习，但现有轨迹级和步骤级信用分配方法未显式追踪命令间的读写依赖，导致训练信号可能分配给无关操作，削弱学习效果。

### 5. 方法概览

- 任务 / 环境: 终端任务环境，智能体通过执行命令与环境交互，任务验证器检查最终环境状态并给出奖励。
- 变量 / 干预设计: 提出DepGPO，构建命令依赖图，从验证器读取的资源E反向追踪，为相关写入和支撑读取分配信用，再通过归一化因子将轨迹优势重新分配到各步骤。
- 评价指标: 任务成功率、训练稳定性（如训练损失波动）
- 模型比较: 与GRPO、GiGPO等基线方法对比，在Qwen3.5-9B和Qwen3.6-27B模型上使用SETA和TMAX训练数据评估。
- 我的理解: DepGPO的核心创新在于利用执行轨迹中的读写依赖，将信用集中在真正影响验证结果的命令上，从而避免无关命令的干扰，提升学习效率。

### 6. 关键发现

- 性能提升: 在复杂终端任务上，DepGPO相比基线方法显著提高了任务成功率。
- 训练稳定性增强: DepGPO延迟了训练退化，提高了强化学习的稳定性。

## 2. MobiAgent: Dual-Loop Recursive Policy Self-Improvement for Long-Horizon Mobile Manipulation

**Topics:** Embodied Agent, Mobile Manipulation, Recursive Self-Improvement
**Authors:** Chenzhi Liu, Yue Zhang, Jiehong Lin, Jianan Wang, Bo Wang, Zhongrui Wang, Xiaojuan Qi
**Venue / Year:** CoRL 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.03476v1) | [PDF](http://arxiv.org/pdf/2610.03476v1.pdf) | [Code](https://github.com/kaiknower/MobiAgent)

### 1. 一句话结论

MobiAgent通过双循环智能体框架，将部署时的动态规划与离线的递归策略自改进相结合，在长时程移动操作任务上显著优于现有方法。

### 2. 为什么重要

该工作解决了长时程移动操作中执行误差累积和运动与操作能力干扰的难题，提出了一种无需人工标注的持续学习机制，为机器人自主进化提供了新范式。

### 3. 研究问题

1. 如何设计一个既能鲁棒执行长时程任务又能持续自我改进的移动操作框架？
2. 如何通过原子技能的组合与动态重规划来应对执行失败和空间变化？
3. 如何利用部署数据自动生成训练样本，实现策略的递归提升？

### 4. 背景与问题设定

长时程移动操作需要机器人完成多阶段任务，涉及全局导航和精确操作的无缝切换。现有VLA模型在短时程任务上表现优异，但缺乏层次化推理能力；而层次化智能体存在子任务映射僵化、重规划不灵活、缺乏持续学习等问题。

### 5. 方法概览

- 任务 / 环境: 仿真环境RoboCasa和BEHAVIOR-1K，以及真实世界任务（Astribot S1机器人）。
- 变量 / 干预设计: 提出双循环框架：内循环负责部署时的闭环执行，包括任务规划器（动态组合原子技能）、技能执行器（基于共享VLM骨干的流匹配专家）和反思评论器（视觉验证与错误恢复）；外循环负责离线训练，通过数据策展器、技能生成器和技能训练器实现策略的自动进化。
- 评价指标: 任务成功率（Success Rate）。
- 模型比较: 与CaP-X、π0.5、π0.5-TA等基线比较，在BEHAVIOR-1K上平均成功率提升22.5个百分点。
- 我的理解: 该框架的核心在于将高层语义规划与低层技能执行解耦，并通过内循环的实时反馈和外循环的数据回收形成闭环，实现策略的持续优化。

### 6. 关键发现

- 性能显著提升: 在BEHAVIOR-1K上平均成功率65.0%，比π0.5-TA高22.5个百分点；在RoboCasa上通过6轮自改进，成功率从7.50%提升至27.50%。
- 动态重规划有效: 内循环的反思评论器能够检测执行失败（如物体掉落），并触发全局重规划，实现鲁棒的误差恢复。
- 自动数据回收驱动持续学习: 外循环通过自动分割、验证和聚类部署数据，无需人工标注即可生成训练样本，持续微调技能策略，验证了递归自改进的可行性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 双循环框架为长时程任务提供了一种可扩展的架构，通过原子技能组合和动态重规划增强了鲁棒性，同时外循环的自动数据回收机制使智能体能够持续进化。
- 对 Skill: 技能库的自动发现和标准化降低了人工设计成本，技能共享机制提高了参数效率。
- 对 Memory: 内循环中的情景记忆（episodic memory）记录了子任务执行历史和评论反馈，为规划器提供上下文，支持空间感知的重规划。
- 对评测: 成功率作为主要指标，但未来可考虑更细粒度的过程指标，如错误恢复效率、技能复用率等。

### 11. 局限性

- 实验仅在仿真和有限真实任务上验证，真实世界的泛化性有待进一步测试。
- 技能库的自动聚类可能产生语义不明确的技能，需要人工校验。
- 外循环的持续学习依赖部署数据的质量，若数据噪声大可能影响策略更新。

### 12. 我的看法 / 个人笔记

MobiAgent通过双循环设计有效解决了长时程移动操作的挑战，其自动数据回收机制是亮点。未来可探索更复杂的技能组合和跨任务迁移，以及在实际场景中的长期部署。

## 3. Do Large Language Models Know Colombian Law? A Reliability Benchmark for the Colombian Legal System

**Topics:** 法律人工智能, 大语言模型评估, 哥伦比亚法律
**Authors:** Rubén Manrique, Michelle Castellanos, Jorge Morales, Juan David Gutiérrez, Antonio Barreto Rozo, Joaquín Vélez Navarro
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.03639v1) | [PDF](http://arxiv.org/pdf/2610.03639v1.pdf)

### 1. 一句话结论

当前大语言模型在哥伦比亚法律任务上的事实正确性普遍偏低，且存在“看似合理但错误”的严重风险，亟需专家监督和权威来源 grounding。

### 2. 为什么重要

该研究填补了非英语、大陆法系国家法律 AI 评估的空白，揭示了 LLM 在西班牙语法律场景中的可靠性问题，对法律实践、教育和研究的安全应用具有重要警示意义。

### 3. 研究问题

1. 大语言模型在哥伦比亚法律问答上的可靠性如何？
2. 不同模型、问题类型和法律领域下，模型表现有何差异？
3. 模型回答的相关性与事实正确性是否一致？
4. 封闭式选择题能否预测自由文本回答的正确性？

### 4. 背景与问题设定

LLM 在法律领域的应用日益广泛，但多数评估集中于美国普通法系，对西班牙语大陆法系国家（如哥伦比亚）的可靠性研究几乎空白。已有研究表明 LLM 存在幻觉问题，且商业工具即使使用 RAG 仍有较高错误率。哥伦比亚司法人员已开始使用 AI 工具，但缺乏系统性评估。

### 5. 方法概览

- 任务 / 环境: 哥伦比亚法律问答基准测试，包含 1042 个问题，覆盖 10 个法律领域和 3 种问题格式（封闭式选择题、半开放式、开放式 IRAC）。
- 变量 / 干预设计: 评估 15 个当代专有和开源 LLM，在无网络、无外部工具的条件下，使用温度 0 进行确定性生成。
- 评价指标: 封闭式问题使用准确率；半开放和开放式问题使用 BERTScore、BLEU、ROUGE、RAG 相关性和正确性指标，以及西班牙语可读性指数。
- 模型比较: 比较不同模型在各类问题上的表现，并分析相关性与正确性的关系。
- 我的理解: 该研究通过精心设计的基准和评估流程，系统性地量化了 LLM 在哥伦比亚法律任务上的可靠性，并揭示了表面流畅与事实正确之间的脱节。

### 6. 关键发现

- 封闭式问题准确率差异大: 最佳模型 Gemini 3.1 Pro 准确率达 0.905，最差模型仅 0.577，表明模型间能力差距显著。
- 自由文本回答事实正确性普遍偏低: 所有模型在开放式问题上的事实正确性得分均不超过 0.45（0-1 量表），远低于封闭式准确率，说明生成式回答的可靠性严重不足。
- 回答相关性与事实正确性分离: 模型回答的相关性高但正确性低，Spearman 相关系数为 -0.46，意味着模型可能“答非所问”但表面流畅，对非专家用户极具误导性。
- 封闭式准确率可预测排名但高估绝对可靠性: 封闭式准确率与自由文本正确性排名高度相关（rho=0.94），但封闭式准确率数值远高于自由文本正确性，因此不能直接用于估计实际可靠性。
- 引用规范错误率高: 模型引用的法律规范中约一半是错误的或不存在，进一步证实了幻觉问题的严重性。
- LLM 裁判与人类专家评分一致性高: 基于规则的 LLM 裁判与盲法人类专家评分高度一致（rho>=0.88），验证了自动评估的可靠性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 法律 AI 代理系统在哥伦比亚等大陆法系国家部署时，必须集成权威法律数据库检索和人工审核机制，以降低幻觉风险。
- 对 Skill: 法律专业人士需要培养对 LLM 输出的批判性评估能力，不能盲目信任表面流畅的回答。
- 对 Memory: 模型需要增强对法律规范的结构化记忆和引用准确性，可能通过检索增强生成或知识图谱来改进。
- 对评测: 评估法律 LLM 时，应同时使用封闭式和开放式问题，并区分相关性与正确性，避免单一指标误导。

### 11. 局限性

- 基准测试仅覆盖哥伦比亚法律，可能无法推广至其他大陆法系国家。
- 评估模型时未使用网络检索，可能低估了实际应用中 RAG 系统的表现。
- 开放式问题的评分依赖自动指标，可能无法完全捕捉法律论证的细微差别。
- 专家评估未进行独立双编码，可能引入主观偏差。

### 12. 我的看法 / 个人笔记

该研究提供了宝贵的基准和实证数据，揭示了 LLM 在法律责任上的可靠性短板。未来应探索结合检索增强和专家反馈的混合系统，并扩展至更多语言和法域。

该论文构建了哥伦比亚法律可靠性基准，评估了 15 个 LLM，发现模型在封闭式问题上表现尚可，但自由文本回答的事实正确性极低，且相关性与正确性分离。研究强调了专家监督和 grounding 的必要性，并提供了可复现的评估流程。

## 4. HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents

**Topics:** GUI Agent, Web Browsing, Multilingual, Multimodal, Benchmark
**Authors:** Alham Fikri Aji, Faiz Rizki Ramadhan, Zayd M. K. Zuhri, Seung Hun Eddie Han, Ryandito Diandaru, Qinrong Cui, Jan Christian Blaise Cruz, Badrinath Chandana, Peerawat Chomphooyod, Ahmed Attia, Jonibek Mansurov, Emilio Villa-Cueva, Canh Duong Nguyen, Imran Turganov, Minghao Wu, Peerat Limkonchotiwat, Irina Nikishina
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.03574v1) | [PDF](http://arxiv.org/pdf/2610.03574v1.pdf) | [Code](https://HyperBrowseComp.github.io/)

### 1. 一句话结论

HyperBrowseComp 是一个包含 423 个手工编写、跨 13 种语言的多语言多模态网页浏览基准，旨在通过需要多跳线索和异构证据的难题来测试智能体的持久信息检索能力。

### 2. 为什么重要

现有浏览基准（如 BrowseComp）多为英语和纯文本，而真实网络环境包含多种语言和模态（视频、图片、扫描文档等）。HyperBrowseComp 填补了这一空白，为评估和推动多语言多模态网页浏览智能体提供了更具挑战性和现实意义的测试平台。

### 3. 研究问题

1. 在需要跨语言、跨模态和多跳推理的开放网络检索任务中，当前最先进的语言模型智能体表现如何？
2. 不同的搜索集成方式（内置搜索、Exa、OWL）对多语言多模态浏览任务的准确率和成本有何影响？

### 4. 背景与问题设定

随着 LLM 作为工具使用智能体的普及，网页浏览评估变得重要。现有基准如 GAIA、WebArena、BrowseComp 等，但 BrowseComp 是英语中心且以文本为主，其他多语言或多模态基准要么是翻译构造（如 XBCP），要么只覆盖单一语言（如 BrowseComp-ZH、K-BrowseComp）。HyperBrowseComp 旨在同时结合多语言（13 种）和多模态（视频、图片、音频等）的开放网络检索，且问题由母语者原创，避免翻译偏差。

### 5. 方法概览

- 任务 / 环境: 开放互联网，包含网页、视频、图片、音频、扫描文档、地图等多种来源。
- 变量 / 干预设计: 评估 5 个前沿 LLM（Gemini 3.1 Pro, Gemini 3.7 Flash, GPT-5.6 Terra/Luna/Sol），在三种搜索集成方式下进行：内置搜索（模型自带）、Exa（统一检索工具）、OWL（多智能体框架）。
- 评价指标: 准确率（二元正确性），由 LLM 裁判根据参考答案判断。
- 模型比较: 比较不同模型和搜索集成方式的准确率、成本及失败案例。
- 我的理解: 该基准的设计强调“解释性搜索”，即问题不直接给出关键词，需要智能体自主发现线索、连接多步证据，并处理非文本模态。这比传统问答更难，也更接近真实用户需求。

### 6. 关键发现

- 整体准确率较低，仍有很大提升空间: 最佳模型 Gemini 3.7 Flash 准确率仅 31.68%，Gemini 3.1 Pro 为 25.53%，表明当前智能体在复杂多模态多语言检索上表现有限。
- 多模态证据是主要挑战: 约 64.3% 的问题需要非文本模态（视频、图片、音频等），其中视频/YouTube 占 39%，PDF/书籍/OCR 占 29.8%，图像占 18.4%，这要求智能体具备多模态理解和跨模态推理能力。
- 语言多样性影响性能: 问题覆盖 13 种语言，包括印尼语、泰语、德语、菲律宾语、爪哇语等，不同语言的表现差异可能反映了模型在非英语资源上的检索和推理能力不足。

## 5. HazardWeaver: Scientific Route Selection for Hazard Analysis Agents

**Topics:** AI Agent, 自然灾害分析, 科学路线选择, 大语言模型
**Authors:** Wangshu Zhu, Xueqi Cheng, Liang Wu, Yushun Dong
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.03591v1) | [PDF](http://arxiv.org/pdf/2610.03591v1.pdf) | [Code](https://github.com/LabRAI/HazardWeaver)

### 1. 一句话结论

HazardWeaver 通过将科学适用性与能力可达性相结合，实现了灾害分析代理的状态依赖科学路线选择，并在基准测试中显著优于现有代理系统。

### 2. 为什么重要

该工作首次将灾害分析中的科学路线选择形式化为状态依赖决策问题，并提出了完整的解决方案，显著提升了AI代理在科学任务中的可靠性和适应性，对灾害应急响应和风险降低具有重要意义。

### 3. 研究问题

1. 如何根据当前证据和可用能力，为灾害分析任务选择科学上适用且可执行的路线？
2. 如何评估代理在路线选择过程中的决策质量，而不仅仅是最终产物的正确性？

### 4. 背景与问题设定

自然灾害分析对于备灾和减灾至关重要。尽管大语言模型驱动的AI代理在自动化灾害分析方面展现出潜力，但现有系统缺乏对科学方法适用条件的显式建模，也无法根据执行过程中状态的变化动态调整路线。同一灾害任务往往存在多种科学路线（如经验、物理、统计或学习方法），其适用性取决于科学证据和可用资源。因此，代理需要能够根据当前状态选择并修订科学路线，这是一个状态依赖的决策问题。

### 5. 方法概览

- 任务 / 环境: 基准测试包含141个实例，覆盖7个单一灾害领域（如洪水、野火、地震等）和4个多灾害交互类别（如火灾后泥石流、地震触发滑坡等），每个实例有明确的输出契约和多种可能的科学路线。
- 变量 / 干预设计: HazardWeaver 包含三个核心组件：Hazard Knowledge Compiler (HKC) 从文献中提取证据关联的适用条件；Hazard Capability Graph (HCG) 表示可执行的科学能力及其兼容性；Hazard Weaver Agent (HWA) 结合两者进行路线选择、执行和修订。
- 评价指标: 引入决策约束准确率（DCA），综合评估产物正确性、路线有效性、因果有效性、类型有效性、预算有效性和证明有效性，并允许合理的弃权。
- 模型比较: 与Plan-and-Solve、Self-Consistency、DisasterBench-ToT、MLE-STAR、AutoML-Agent、Reflexion、AIDE、DS-Agent、R&D-Agent和ReAct等10种基线方法进行比较。
- 我的理解: HazardWeaver 的核心创新在于将科学知识（HKC）和计算能力（HCG）分离，并通过代理动态地结合两者，使得路线选择既基于科学证据又考虑实际可执行性，同时支持在状态变化时进行修订，从而提高了决策的鲁棒性和科学性。

### 6. 关键发现

- HazardWeaver 显著优于现有代理系统: 在141个基准实例上，HazardWeaver 的决策约束准确率（DCA）达到最高，尤其在多路线任务上优势明显，表明其能够更有效地选择科学上适用且可执行的路线。
- 状态依赖的路线修订提升适应性: 当执行过程中出现新证据或能力变化时，HazardWeaver 能够及时修订路线，而基线方法往往无法适应，导致最终产物无效或弃权。
- 科学适用性与能力可达性的分离是关键: 通过HKC和HCG的分离，HazardWeaver 能够明确区分科学上不适用和当前不可执行的路线，从而针对性地进行恢复操作，提高了决策的透明度和可解释性。
