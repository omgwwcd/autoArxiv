## 1. PerceptRL: Making Visual Perception Rewardable in MLLMs from Answers to Interactions

**Topics:** GUI Agent, 多模态大语言模型, 视觉感知, 强化学习
**Authors:** Tongkun Guan, Zhibo Yang, Mingkun Yang, Haocheng Wang, Wei Shen, Xiaokang Yang
**Venue / Year:** IEEE TPAMI 投稿
**Links:** [Abstract](http://arxiv.org/abs/2610.37471v1) | [PDF](http://arxiv.org/pdf/2610.37471v1.pdf)

### 1. 一句话结论

PerceptRL 通过将模型自身的感知错误转化为可验证的 QA 数据，并引入坐标注入与接地感知过程奖励，显著提升了 MLLM 的细粒度视觉感知能力。

### 2. 为什么重要

当前 MLLM 的后训练主要聚焦于推理能力，而感知错误成为性能瓶颈。PerceptRL 提供了一种可扩展的、基于错误驱动的感知强化学习框架，使感知训练变得可验证、可奖励，从而在多个基准上超越前沿模型，为多模态后训练提供了新方向。

### 3. 研究问题

1. 如何将开放式的图像描述转化为可验证的奖励信号，以强化 MLLM 的视觉感知？
2. 在多轮工具交互中，如何缓解坐标漂移问题并监督中间空间精度？

### 4. 背景与问题设定

MLLM 的视觉感知能力在预训练后会被后续阶段稀释，而直接优化描述因主观性和信息密集而难以设计奖励。现有方法如基于求解器或代码重建的奖励是间接的，且局限于特定领域。因此，需要一种可扩展的、基于错误驱动的感知强化学习方法。

### 5. 方法概览

- 任务 / 环境: 多模态大语言模型（MLLM）的视觉感知任务，包括计数、颜色、空间关系、状态等，以及需要多轮工具交互的细粒度场景。
- 变量 / 干预设计: 构建感知树组织能力，通过专用和通用两条路线提取模型错误，并转化为链式 QA 和多选题 QA。对于多轮交互，采用坐标注入（CI）修正冷启动轨迹中的空间操作，并设计接地感知过程奖励。
- 评价指标: 在七个基准上使用共享工具协议的平均准确率。
- 模型比较: 与基础模型（使用相同工具）和最强前沿 VLM 进行比较，PerceptRL 分别高出 15.7 和 5.2 个百分点。
- 我的理解: 该方法将感知错误作为训练信号，通过自动化流水线生成可验证的 QA 数据，并针对多轮交互中的空间漂移问题设计了专门的修正和监督机制，从而实现了从单轮到多轮的感知强化。

### 6. 关键发现

- 感知 RL 显著提升单轮感知准确率: 在八个感知基准上，PerceptRL 的感知 RL 阶段将平均准确率从 61.9% 提升至 69.8%。
- 完整流程超越前沿模型: 在七个基准的共享工具协议下，PerceptRL 达到 71.6% 的平均准确率，超过基础模型 15.7 个百分点，超过最强前沿 VLM 5.2 个百分点。

### 11. 局限性

- 多轮交互的奖励设计仍依赖于预定义的接地评估，可能无法覆盖所有空间错误。

### 12. 我的看法 / 个人笔记

PerceptRL 提出了一种新颖的感知强化学习范式，通过错误驱动和可验证奖励解决了感知训练中的关键难题。其多轮交互中的坐标漂移处理具有实际意义，但错误检测的自动化程度和跨语言泛化仍需进一步探索。

### 14. 总结

PerceptRL 通过两级强化学习（单轮感知 RL 和多轮代理 RL）强化 MLLM 的视觉感知。它利用多智能体流水线从模型自身的描述错误中构建可验证 QA，并通过坐标注入和接地感知过程奖励解决多轮交互中的空间漂移。实验表明，该方法在多个基准上显著优于基础模型和前沿 VLM，为感知后训练提供了有效方案。

## 2. From Interaction to Capability: Task Advancement as State and Supervision for GUI Agents

**Topics:** GUI Agent, 任务推进记忆, 跨应用工作流
**Authors:** Ziyang Chen, Qian Li, Chengwei Qin
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.37482v1) | [PDF](http://arxiv.org/pdf/2610.37482v1.pdf)

### 1. 一句话结论

TAM 通过将任务推进定义为可验证的进度，并利用推进监督学习可复用操作，显著提升了 GUI 代理在长时跨应用任务中的成功率与效率。

### 2. 为什么重要

该工作解决了 GUI 代理在长时工作流中难以保留跨应用信息和复用有效操作的问题，通过任务推进状态和监督机制，将部分成功转化为可复用能力，为构建更智能的 GUI 代理提供了新思路。

### 3. 研究问题

1. 如何表示任务推进状态以指导跨应用执行？
2. 如何从成功和失败的任务中提取可复用的操作？

### 4. 背景与问题设定

GUI 代理需要完成跨屏幕和跨应用的长时工作流，但长交互历史中混杂着已完成工作和无效尝试，导致代理难以判断任务进度和剩余目标。现有方法如上下文管理、程序引导和验证状态虽有所改进，但仍无法有效保留跨应用信息并学习可复用操作。

### 5. 方法概览

- 任务 / 环境: 移动端 GUI 环境，包括 MobileWorld 的 GUI-only 任务和 SPA-Bench 的英文 Level 3 单应用任务。
- 变量 / 干预设计: TAM 包含两个核心组件：任务推进状态（在线指导）和推进监督（离线学习）。任务推进状态通过任务编译器构建需求图，并利用推进前沿选择当前可执行的需求；推进监督则从已验证的推进片段中抽象出可复用操作，存入操作图。
- 评价指标: 任务成功率（Success）、平均步数（Steps）、效率-质量面积（EQA@50）以及生命周期 token 消耗（LTS）。
- 模型比较: 与多个基线比较，包括 Qwen3-VL-32B-Instruct 基础模型、AWM、Mobile-Agent-E、StructAgent、GUI-explorer 和 MemGUI-Agent (ConAct) 等。
- 我的理解: TAM 的核心创新在于将任务推进作为显式状态，不仅用于指导当前执行，还作为监督信号来学习可复用操作，从而将部分成功转化为长期能力。

### 6. 关键发现

- 任务推进状态显著提升成功率: 在 MobileWorld GUI-only 任务中，仅使用任务推进状态即可将成功率从 12.0% 提升至 28.2%，表明显式表示任务进度对跨应用执行至关重要。
- 完整 TAM 实现最优性能: 完整 TAM 在 MobileWorld 上达到 34.2% 的成功率，相比最强基线 MemGUI-Agent (ConAct) 的 29.1% 有 17.6% 的相对提升，同时减少了 8% 的步数，并降低了 38.7% 的生命周期 token 消耗。
- 在 SPA-Bench 上达到最先进水平: 在 SPA-Bench 英文 Level 3 单应用设置中，TAM 达到 57.0% 的成功率，优于所有对比方法，包括 GUI-explorer 的 53.7%。

## 3. Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis

**Topics:** GUI Agent, Scaling Laws, Tool-Use Agents, Synthetic Data Generation
**Authors:** Andrew Szot, Samira Abnar, Omar Attia, Abbas Kazerouni, Michael Kirchhof, Cheng-Yu Hsieh, Raviteja Vemulapalli, Alexander Toshev
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.37648v1) | [PDF](http://arxiv.org/pdf/2610.37648v1.pdf)

### 1. 一句话结论

通过可控环境合成，发现工具使用智能体的性能随数据组成（工具、任务、数据库多样性）呈可预测的缩放规律，且最优数据组成随计算预算变化。

### 2. 为什么重要

该研究系统性地揭示了合成工具使用环境中数据组成对智能体泛化性能的影响，并提出了可外推的缩放定律，为大规模训练数据的高效生成提供了理论指导，显著提升了工具使用智能体的性能。

### 3. 研究问题

1. 在合成工具使用环境中，数据组成（工具多样性、任务数量、数据库多样性）如何影响智能体的下游泛化性能？
2. 随着训练计算预算的增加，最优的数据组成策略如何变化？

### 4. 背景与问题设定

大型语言模型作为工具使用智能体需要处理多步、有状态的环境，但高质量训练数据稀缺。现有合成方法要么模拟工具响应（难以模拟复杂状态），要么生成可执行环境但缺乏对数据组成影响的分析。本文旨在通过可控环境合成，研究数据组成对智能体性能的影响，并建立缩放定律。

### 5. 方法概览

- 任务 / 环境: SynthAPI生成包含多个应用（apps）的环境，每个应用由一组Python工具和结构化数据库组成。智能体通过发现工具接口（list_apps, list_tools, get_tool_documentation）并调用工具完成任务。任务由指令、验证器、初始数据库状态组成，Oracle求解器用于验证任务可行性。
- 变量 / 干预设计: 系统性地改变三个控制变量：应用数量A（工具多样性）、每个应用的任务数T（任务多样性）、每个任务的数据库实例数S（数据库多样性），以及任务复杂度D（干扰数据量）。共生成458,752个任务，训练849个模型（4种规模：2B、4B、9B、27B）。
- 评价指标: 下游泛化性能通过多个基准（AppWorld, BFCL, ASTRA-Bench）的归一化得分衡量。缩放定律的拟合使用均绝对误差（MAE）。
- 模型比较: 比较了不同数据组成下的模型性能，并与现有大规模合成数据方法（如Nemotron-Agentic）对比。
- 我的理解: 该方法通过可控环境生成，将数据组成作为可调节的变量，从而能够分离不同因素对性能的影响，并建立预测模型。

### 6. 关键发现

- 数据组成影响性能: 在固定任务总数下，增加应用数量（工具多样性）比增加每个应用的任务数更有效；增加数据库多样性（S）和任务复杂度（D）也能提升性能。
- 缩放定律可预测性能: 提出的数据组成依赖的缩放定律能够准确预测不同计算预算下的性能，MAE仅为0.0285，远优于仅依赖任务数量的模型（MAE=0.1706）。
- 最优组成随预算变化: 随着训练FLOPs增加，最优数据组成倾向于增加工具和数据库多样性，而非单纯增加任务数量。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 为工具使用智能体的训练数据生成提供了可操作的指导，强调在预算有限时优先增加工具和数据库多样性。
- 对 Skill: 表明智能体在多样化工具环境中的训练能提升其泛化能力，可能促进技能迁移。
- 对 Memory: 数据库多样性（S）的引入表明，智能体需要适应不同初始状态，这对状态跟踪和上下文理解能力提出了更高要求。
- 对评测: 提出的缩放定律可作为评估数据生成策略的预测工具，指导基准测试的设计。

### 11. 局限性

- SynthAPI生成的环境仅限于单应用任务，未涉及多应用协作（未来工作）。
- 缩放定律基于特定模型规模和训练设置，可能不适用于其他架构或训练方法。
- 数据生成依赖LLM（具体为Gemini-3.1 Pro），可能引入生成偏差。

### 12. 我的看法 / 个人笔记

该研究为合成数据生成提供了重要指导，强调了数据多样性（工具、数据库）的重要性。未来可探索更复杂的环境生成和跨应用任务，以及将缩放定律应用于其他智能体类型。

### 14. 总结

本文提出SynthAPI，一种可控的合成工具使用环境生成方法，通过系统改变数据组成（工具、任务、数据库多样性），建立了预测智能体性能的缩放定律。实验表明，随着计算预算增加，增加工具和数据库多样性比增加任务数量更有效，且该定律能准确外推至更高预算。基于此，SynthAPI训练出的智能体在多个基准（AppWorld、BFCL、ASTRA-Bench）上显著优于现有方法。

## 4. VideoLVR: Latent Visual Reasoning over Grounded Video Evidence

**Topics:** 视频理解, 多模态大语言模型, 潜在视觉推理, 视觉证据, 强化学习
**Authors:** Shilong Li, Xingyuan Bu, Hao Shi, Yun Xing, Weixin Feng, Qiangpeng Yang, Shilei Wen
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.37613v1) | [PDF](http://arxiv.org/pdf/2610.37613v1.pdf)

### 1. 一句话结论

VideoLVR 通过将局部视频区域编码为潜在视觉证据，并采用视觉标记预测目标，使多模态大模型在推理时能紧凑地回看视觉信息，显著提升细粒度视频理解性能。

### 2. 为什么重要

现有视频推理方法要么依赖文本坐标（丢失视觉语义），要么插入裁剪区域（导致上下文膨胀）。VideoLVR 首次将潜在视觉推理扩展到视频领域，通过分组潜在证据和视觉标记预测，在不增加上下文负担的前提下实现视觉证据的灵活回看，为视频推理提供了新范式。

### 3. 研究问题

1. 如何让多模态大模型在推理过程中紧凑且灵活地回看相关视觉证据，避免视觉遗忘？
2. 如何利用视频中的时空定位标注来监督潜在视觉证据的生成，并区分相似视觉内容？

### 4. 背景与问题设定

多模态大语言模型（MLLMs）在视频理解中常采用思维链推理，但语言推理轨迹无法可靠地回看视觉证据，导致视觉遗忘。现有方法要么用文本坐标（如时间戳、边界框）指代证据，丢失视觉内容；要么将裁剪区域或帧重新插入上下文，导致上下文膨胀。潜在视觉推理（LVR）在图像领域已展示潜力，但视频中单一时刻的证据往往不足，需要跨时间整合，且相邻帧视觉标记高度相似，MSE回归难以区分目标。

### 5. 方法概览

- 任务 / 环境: 视频问答任务，输入为视频和问题，输出为答案及中间推理过程。
- 变量 / 干预设计: 使用教师MLLM合成带证据的推理轨迹，通过拒绝采样和轨迹润色确保证据组与推理步骤对齐。将每个证据组（含多个时空区域）映射为潜在视觉标记序列，并引入视觉标记预测（VTP）目标，使模型从输入视频的视觉词汇中预测目标标记。
- 评价指标: 在多个视频理解基准上评估准确率，并针对细粒度证据任务进行专门分析。
- 模型比较: 与基线MLLM（如Video-R2、Open-o3-Video）以及现有潜在推理方法（如LVR）对比，并消融VTP和RL组件。
- 我的理解: 该方法将视觉证据压缩为潜在向量，通过预测输入视频中的具体视觉标记来监督，相当于让模型在推理时“回忆”相关视觉内容，而不是重新“看”一遍。

### 6. 关键发现

- 潜在视觉证据提升视频推理准确率: VideoLVR在多个视频问答基准上优于现有方法，尤其在需要细粒度视觉证据的任务上提升显著，表明潜在视觉回看有效缓解视觉遗忘。
- 视觉标记预测优于MSE回归: 消融实验显示，VTP目标比MSE回归更有效，因为它能显式区分相似视觉标记，避免模型混淆相邻帧的相似内容。
- 强化学习进一步优化策略: 通过TVPO联合优化文本和视觉动作，模型在最终答案奖励下能更有效地选择关键视觉证据，进一步提升性能。

## 5. Multi-Agent Reinforcement Learning of Co-Adaptive Hip Exoskeleton Control (MARL-Exo) for Metabolic Energy Reduction

**Topics:** 机器人学, 强化学习, 可穿戴机器人, 代谢能量优化
**Authors:** Yifei Yuan, Jakob Wolf, Ghaith Androwis, Xianlian Zhou
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.37441v1) | [PDF](http://arxiv.org/pdf/2610.37441v1.pdf)

### 1. 一句话结论

通过多智能体强化学习与肌肉骨骼模型协同适应，在仿真中训练的髋部外骨骼策略无需个体调参即可在真实用户中降低步行代谢能耗。

### 2. 为什么重要

该研究首次将生理代谢能量模型直接纳入外骨骼控制策略的奖励函数，并通过两阶段协同训练实现从仿真到真实的无个体调参迁移，为外骨骼控制器的开发提供了新范式，有望替代耗时的人机协同优化。

### 3. 研究问题

1. 在仿真中通过协同适应训练的外骨骼策略能否直接迁移到真实用户并降低代谢能耗？
2. 在奖励函数中加入机械功率整形是否会削弱代谢能量降低的效果？

### 4. 背景与问题设定

髋部外骨骼有望减轻行走代谢负担，但人体与设备之间的相互适应使控制器设计复杂。传统的人机协同优化需要针对每个用户进行长时间实验，成本高昂。基于肌肉骨骼仿真的强化学习提供了一种替代方案，但现有工作多使用肌肉激活或功作为代理目标，未直接优化代谢能量。此外，人类与设备的协同训练存在稳定性问题。本文旨在解决这些不足。

### 5. 方法概览

- 任务 / 环境: 仿真环境：DART物理引擎中的全身体肌肉骨骼模型（50关节自由度，304块Hill型肌肉）与双侧髋部外骨骼（4自由度，峰值扭矩±18 N·m）刚性耦合。
- 变量 / 干预设计: 两阶段训练：阶段1仅训练人体策略以稳定行走；阶段2引入外骨骼，联合训练两个策略。外骨骼奖励包含代谢能量项（基于Umberger/Uchida模型），并比较有无机械功率整形（w_p=0.005 vs 0）的两种策略。
- 评价指标: 仿真中评估模型肌肉代谢功率；真实实验中通过间接测热法测量净代谢率，同时记录髋关节活动范围和外骨骼辅助功率。
- 模型比较: 比较了两种外骨骼策略：Metabolic（仅代谢奖励）和Metabolic+Power（代谢奖励加机械功率整形），并与无外骨骼和被动外骨骼条件对比。
- 我的理解: 该方法的核心在于将生理代谢模型作为奖励信号，并通过两阶段课程学习稳定协同训练，最终实现策略的通用性。

### 6. 关键发现

- 仿真中代谢奖励降低模型代谢功率: Metabolic策略在仿真中将模型肌肉代谢功率降低13.8%（相对于无设备行走），而Metabolic+Power仅降低8.8%，表明机械功率整形会削弱代谢优化效果。
- 真实实验中代谢率显著降低: 在8名健康受试者中，Metabolic策略相比被动外骨骼使净代谢率平均降低18.3%（p<0.001），相比无外骨骼条件降低7.4%（其中6名受试者超过设备穿戴惩罚）。
- 髋关节活动范围增大: Metabolic策略使髋关节活动范围相比被动条件增加36.8%，且辅助功率主要为正向（98.5%），表明策略提供了有效的助力。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 多智能体协同训练框架可推广至其他人机协作系统，通过课程学习稳定训练过程。
- 对 Skill: 外骨骼策略能够学习到与人体自然步态协同的助力模式，表明强化学习可自动发现有效的辅助策略。
- 对 Memory: 策略仅依赖当前和过去的运动状态，无需长期记忆，适合嵌入式部署。
- 对评测: 仿真中的代谢模型可作为预筛选工具，减少真实实验成本。

- 策略仅在单一速度（1.25 m/s）下验证，未测试其他行走速度或任务。
