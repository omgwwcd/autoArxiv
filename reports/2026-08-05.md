## 1. Does Forgetting Transfer Across Modalities? A Real-World Benchmark for Cross-Modal Knowledge Unlearning Evaluation

**Topics:** 机器遗忘, 跨模态遗忘, 视觉语言模型, 基准测试
**Authors:** Chunlin Liu, Junnian Chen, Haitong Jiang, Jianyu Zhao, Yingsen Pang, Jingchen Li, Jiabiao He, Youming Lu, Jinhe Bi, Yuntao Du
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.03791v1) | [PDF](http://arxiv.org/pdf/2608.03791v1.pdf)

### 1. 一句话结论

视觉语言模型中知识遗忘存在显著跨模态不对称性：多模态遗忘在文本评估中仍有效，但纯文本遗忘难以迁移到视觉和跨模态场景，仅文本评估会高估遗忘效果。

### 2. 为什么重要

该工作揭示了仅依赖单模态评估（尤其是纯文本）会严重高估遗忘有效性，为构建可信多模态AI系统提供了关键基准和方法论指导，强调跨模态遗忘和评估的必要性。

### 3. 研究问题

1. 视觉语言模型中，通过文本输入进行的知识遗忘能否迁移到语义等价的文本-图像查询？
2. 跨模态遗忘迁移是否存在方向性不对称？

### 4. 背景与问题设定

视觉语言模型（VLM）可能记忆敏感、版权或有害知识，需机器遗忘技术移除。现有研究主要关注单模态内遗忘，忽略跨模态迁移。实际场景中，删除请求可能针对一种模态，后续查询可能通过另一种模态发起。因此需系统评估遗忘效果在不同模态间的迁移能力。

### 5. 方法概览

- 任务 / 环境: 后-hoc遗忘设定：原始遗忘和保留语料不可用，基于公开知识构建紧凑遗忘数据集。
- 变量 / 干预设计: 从Wikidata选取250个视觉可识别真实世界实体作为遗忘目标，关联图像和一跳/多跳事实。构建四个互补子集：Forget Set（11906个样本，直接遗忘）、Multi-Hop Set（3398个样本，关系传播）、Retain Set（20351个样本，非目标知识保留）、Rewrite Set（11906个样本，语义等价鲁棒性）。每个事实构建文本和文本-图像对齐查询对，使用分离图像避免泄露：Image2用于遗忘训练，Image1用于评估。
- 评价指标: 遗忘有效性（Forget Set准确率下降）、知识保留（Retain Set准确率保持）、多跳恢复（Multi-Hop Set准确率）、语义鲁棒性（Rewrite Set准确率）。
- 模型比较: 在Qwen3-VL和Llama-3.2-Vision两个模型家族上，比较四种遗忘方法：GA（Gradient Ascent，降低正确响应似然）、DPO（Direct Preference Optimization，偏好反事实响应）、NPO（Negative Preference Optimization，抑制正面响应）、RT（Refusal Training，训练拒绝回答）。评估T→T、T→M、M→T、M→M四种模态组合。
- 我的理解: 该工作通过精心设计基准，将遗忘效果分解为遗忘模态和评估模态两个独立变量，系统测量跨模态迁移。关键创新在于构建事实对齐的文本和文本-图像查询对，确保仅输入模态不同，并使用分离图像避免泄露。

### 6. 关键发现

- 跨模态遗忘迁移存在显著不对称性: 多模态遗忘（M→T和M→M）在文本评估中仍有效，但纯文本遗忘（T→M）在视觉和跨模态场景中表现很差，遗忘效果难以迁移。具体而言，GA、DPO、NPO、RT四种方法在T→M设置下均表现不佳，而M→T设置下遗忘效果保持较好。
- 纯文本评估高估遗忘效果: 仅依赖文本评估会严重高估遗忘有效性，模型可能在文本查询中看似遗忘，但在图像查询中仍能恢复知识。例如，在T→T设置下遗忘成功率较高，但T→M设置下遗忘效果大幅下降。
- 遗忘方法基本保持模型通用能力: 评估的四种遗忘方法（GA、DPO、NPO、RT）在遗忘目标知识的同时，对非目标知识和模型通用能力影响较小，Retain Set准确率保持稳定。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 多模态智能体在部署遗忘功能时，必须同时考虑文本和图像输入，否则用户可能通过切换模态绕过遗忘。
- 对 Skill: 遗忘技能需要跨模态训练，仅文本遗忘不足以覆盖多模态场景。
- 对 Memory: 知识在模型参数中的存储可能具有模态特异性，导致遗忘效果难以跨模态迁移。
- 对评测: 评估遗忘效果必须包含跨模态测试，仅单模态评估不可靠。

### 11. 局限性

- 基准仅涵盖250个实体，规模有限，可能无法代表所有知识类型。
- 仅评估了四种遗忘方法（GA、DPO、NPO、RT），其他方法如RMU未包含。
- 图像选择可能引入偏差，尽管通过双模型验证和人工审核。

### 12. 我的看法 / 个人笔记

该工作系统揭示了多模态遗忘中一个被忽视的关键问题，基准设计严谨（如使用分离图像避免泄露），实验结论具有重要实践意义。未来可扩展至更多实体、更多模态（如音频、视频）和更复杂的遗忘场景。

### 14. 总结

UNLINK-VL是一个面向视觉语言模型跨模态知识遗忘的真实世界基准，包含250个实体和约4.7万评估样本（Forget Set 11906、Multi-Hop Set 3398、Retain Set 20351、Rewrite Set 11906），通过构建事实对齐的文本和文本-图像查询对（使用分离图像避免泄露），系统评估遗忘效果在不同模态间的迁移。在Qwen3-VL和Llama-3.2-Vision两个模型家族上，使用GA、DPO、NPO、RT四种遗忘方法进行实验，发现显著的跨模态不对称性：多模态遗忘在文本评估中仍有效，但纯文本遗忘难以迁移到视觉场景，表明仅文本评估会高估遗忘效果。该工作为多模态AI系统的可信遗忘提供了关键评估工具和方法论指导。

## 2. KnowHal: A Knowledge-Driven Benchmark for Comprehensive Multimodal Hallucination Evaluation

**Topics:** Multimodal Large Language Models, Hallucination Evaluation, Knowledge-Driven Benchmark
**Authors:** Ruihan Li, Jiyang Tan, Kailin Jiang, Huining Li, Hengyang Lu, Yu Huang, Qian Li, Yuntao Du
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.03782v1) | [PDF](http://arxiv.org/pdf/2608.03782v1.pdf)

### 1. 一句话结论

KnowHal 是一个知识驱动的多模态幻觉评估基准，通过1,800个样本覆盖10领域50类别，统一评估实体、属性、关系和知识四个维度，并利用配对正负问题实现可控比较，发现知识维度对当前MLLMs最具挑战性。

### 2. 为什么重要

现有基准（如POPE、MME、R-Bench）主要关注感知级幻觉（实体、属性、关系），而知识相关失败常被单独研究，缺乏统一框架。KnowHal填补了这一空白，通过共享图像和实体的配对问题设计，实现了对感知错误、知识错误和错误前提接受度的可控比较，为开发更可靠的MLLMs提供了更全面的评估工具。

### 3. 研究问题

1. 如何构建一个统一的多模态幻觉评估基准，同时覆盖实体、属性、关系和知识四个维度？
2. 当前MLLMs在知识维度上的幻觉表现如何，与感知维度相比有何差异？
3. 模型在面对误导性前提（负问题）时的鲁棒性如何？

### 4. 背景与问题设定

多模态大语言模型在视觉-语言任务中取得显著进展，但幻觉问题（模型输出与真实情况不一致）仍限制其可靠性。现有基准主要评估感知级幻觉（实体、属性、关系），而知识级幻觉（与外部世界知识冲突）常被单独研究，缺乏统一评估框架。KnowHal旨在通过知识驱动的基准，将知识幻觉纳入多模态幻觉评估，实现四个维度的统一比较。

### 5. 方法概览

- 任务 / 环境: 零样本评估，14个代表性MLLMs（5个闭源：Gemini-3-Flash-Preview, Qwen-VL-Max, Doubao-Seed-2-Mini, GPT-5.2, GPT-5.6-sol；9个开源：Qwen3-VL-32B-Instruct, Qwen2.5-VL-72B-Instruct, Kimi-K2.5, GLM-4.6V, MiniCPM-V-4.5, InternVL3.5-8B, InternVL3.5-14B-Instruct, LLaVA-OneVision-1.5-8B-Instruct, LLaVA-v1.6-Mistral-7B）在KnowHal基准上进行测试，不进行微调或少样本学习。
- 变量 / 干预设计: 每个实体-图像样本构建配对的正问题和负问题。正问题查询有效的视觉证据或相关知识；负问题通过四种策略（属性变体、对象替换、空间关系、动作捏造）引入误导性线索。
- 评价指标: 主要指标为准确率，分别报告正问题和负问题在四个维度上的准确率及平均值。引入幻觉倾向分数（HPS）衡量相对性能下降：HPS = (1 - Acc_neg/Acc_pos) × 100%。例如，LLaVA-OneVision-1.5-8B-Instruct的HPS为70.7%，MiniCPM-V-4.5为60.2%，表明高幻觉易感性。
- 模型比较: 比较了5个闭源模型和9个开源模型。闭源模型如Gemini-3-Flash-Preview在正问题上准确率最高（86.6%），而开源模型如Qwen3-VL-32B-Instruct在负问题上表现突出（56.3%）。
- 我的理解: KnowHal通过精心设计的配对问题，不仅评估模型正确识别视觉和知识的能力，还评估其拒绝误导性前提的鲁棒性。这种设计比单纯的正问题评估更全面，能揭示模型在真实场景中可能出现的幻觉行为。

### 6. 关键发现

- 知识维度是当前MLLMs的最大挑战: 几乎所有模型在知识维度上的准确率最低，无论是正问题还是负问题。例如，Gemini-3-Flash-Preview在知识维度上仅79.2%，低于实体（92.6%）和关系（89.6%）。负问题上差距更大，Doubao-seed-2-mini从69.2%降至16.2%，MiniCPM-V-4.5从41.3%降至7.4%。
- 闭源模型整体优于开源模型，但Qwen系列在负问题上表现突出: 闭源模型如Gemini-3-Flash-Preview和Doubao-seed-2-mini在正问题上准确率最高（86.6%和85.0%），而最佳开源模型Kimi-K2.5为79.2%。但在负问题上，Qwen系列（Qwen-VL-Max 57.6%, Qwen2.5-VL-72B-Instruct 57.0%, Qwen3-VL-32B-Instruct 56.3%）表现出色，表明针对性训练可提高鲁棒性。
- 负问题准确率普遍低于正问题，模型鲁棒性有限: 几乎所有模型在负问题上的准确率显著下降。例如，Doubao-seed-2-mini从85.0%降至37.1%，LLaVA-v1.6-Mistral-7B从51.4%降至21.1%。HPS分数显示LLaVA-OneVision-1.5-8B-Instruct（70.7%）和MiniCPM-V-4.5（60.2%）对幻觉高度敏感。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: KnowHal揭示了MLLMs在知识维度上的显著弱点，这对依赖外部知识的多模态代理系统（如医疗诊断、法律推理）构成风险。代理系统需要结合外部知识库或检索增强生成（RAG）来缓解知识幻觉。
- 对 Skill: 评估结果强调模型需要提升对误导性前提的拒绝能力，这要求模型具备更强的视觉-语言对齐和常识推理技能。
- 对 Memory: 知识维度表现差表明模型在存储和检索事实知识方面存在不足，可能需要改进记忆机制或引入结构化知识库。
- 对评测: KnowHal的配对问题设计为评估提供了更全面的视角，建议未来基准应包含正负问题以同时评估准确性和鲁棒性。

### 11. 局限性

- 基准规模有限（1,800样本），可能无法覆盖所有领域和实体类型。
- 知识维度仅依赖Wikipedia，可能遗漏其他知识源中的事实，导致覆盖偏差。
- 负问题设计可能引入人为偏差，某些策略（如动作捏造）可能不够自然。
- 评估仅使用准确率，未考虑模型输出的置信度或解释性。

### 12. 我的看法 / 个人笔记

KnowHal通过统一四个维度和配对问题设计，显著推进了多模态幻觉评估的全面性。其发现——知识维度是最大挑战——对MLLMs的未来发展具有重要指导意义。然而，基准的构建依赖LLM辅助和人工验证，可扩展性有限。未来工作可探索自动化程度更高的构建方法，并扩展知识源以覆盖更广泛的事实。

## 3. Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent

**Topics:** GUI Agent, 多模态智能体, 视频理解, 深度研究
**Authors:** Zhen Fang, Yu Zeng, Wenxuan Huang, Yiming Zhao, Shiting Huang, Tianfei Ren, Qi Lu, Qingnan Ren, Qisheng Su, Lionel Z. Wang, Qingyu Yin, Shuang Chen, Zehui Chen, Lin Chen, Zhenfei Yin, Yao Hu, Shaohui Lin, Wanli Ouyang, Shaosheng Cao, Feng Zhao
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.03979v1) | [PDF](http://arxiv.org/pdf/2608.03979v1.pdf) | [Code](https://github.com/Osilly/Vision-DeepResearch)

### 1. 一句话结论

Video-DeepResearch 通过解耦感知-探索流水线和两阶段训练（SFT+GRPO），在视频深度研究任务上以35B模型超越Claude-4.5-Sonnet等闭源大模型，揭示了现有智能体存在模态偏差和参数知识泄露两大瓶颈。

### 2. 为什么重要

该工作首次将深度研究智能体从静态图像扩展到连续视频流，直面真实场景中时空密集定位与开放网页探索交织的挑战，并系统性地诊断和缓解了模态偏差与参数知识泄露问题，为下一代多模态自主智能体提供了数据、训练和评估的完整范式。

### 3. 研究问题

1. 如何构建有效的视频深度研究智能体，使其能够从连续视频流中提取关键时空信息并融合开放网页知识进行多跳推理？
2. 现有视觉语言模型在视频深度研究任务中面临哪些根本性瓶颈，如何通过训练策略和数据设计加以克服？

### 4. 背景与问题设定

现有深度研究智能体主要处理文本或静态图像，无法应对连续视频流中密集的时空定位与开放网页探索的耦合需求。初步评估发现两个关键瓶颈：模态偏差（智能体倾向于使用文本搜索而回避视觉工具）和参数知识泄露（模型依赖内部记忆而非工具增强执行）。

### 5. 方法概览

- 任务 / 环境: 视频深度研究任务：给定一个研究查询和一段连续视频流（或预采样关键帧序列），智能体需通过多步决策（包括Select_Keyframe、Crop_Search、Text_Search、Visit等工具）合成综合答案。
- 变量 / 干预设计: 提出解耦感知-探索流水线：第一阶段限制智能体仅使用视觉工具（Select_Keyframe和Crop_Search）进行跨帧实体定位；第二阶段解锁文本工具（Search和Visit）进行网页探索。采用阶段式工具解锁策略强制模型在网页检索前完成充分的视觉定位。
- 评价指标: 在自建基准VideoDR-Bench（200个多跳VQA实例）上评估平均准确率，并跟踪工具调用次数以分析行为模式。
- 模型比较: 与Gemini 2.5 Pro、GPT-5、Claude-4.5-Sonnet、Qwen3.5-397B-A3B、Kimi K2.5等闭源和开源模型对比。Video-DeepResearch-35B-A3B以64.0%准确率超越Claude-4.5-Sonnet（59.0%）5个百分点，30B-A3B变体（59.3%）与Claude-4.5-Sonnet竞争力相当。
- 我的理解: 该方法的核心创新在于通过数据生成和训练策略主动对抗模态偏差：先强制视觉工具使用再解锁文本工具，使模型学会先看后搜的正确推理顺序。两阶段训练（SFT模仿正确轨迹，GRPO通过组相对奖励鼓励自主探索）进一步突破了模仿学习的上限。

### 6. 关键发现

- 模态偏差与视觉工具回避: 现有模型（如Qwen3.5-397B-A17B）平均每任务仅调用0.10次视觉工具，而文本工具调用达1.27次，表明智能体系统性回避主动视觉探索，默认依赖文本搜索。
- 参数知识泄露导致评估失效: GPT-5在几乎零工具调用（视觉0.00，文本0.12）的情况下达到57%准确率，说明现有基准可仅靠模型内部记忆解决，无法衡量真正的工具增强执行能力。
- 解耦训练与GRPO显著提升性能: Video-DeepResearch-35B-A3B在VideoDR-Bench上达到64.0%准确率，超越Claude-4.5-Sonnet（59.0%）5个百分点；30B-A3B变体（59.3%）以更小规模达到竞争力性能，验证了训练范式的有效性。

- 训练数据中视频主要来自公开数据集和YouTube，对特定领域（如医学、工业）的泛化能力未知。

## 4. BanglaWild: An In-the-Wild Bengali Scene Text Recognition Benchmark for OCR and Vision-Language Models

**Topics:** Scene Text Recognition, Bengali OCR, Vision-Language Models, Benchmarking
**Authors:** Sadab Shiper, Tawsif Tashwar Dipto, Mir Md Inzamam, Eshat Tanzeem
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.03884v1) | [PDF](http://arxiv.org/pdf/2608.03884v1.pdf)

### 1. 一句话结论

BanglaWild 基准测试揭示孟加拉语场景文本识别中视觉误识别占主导（约60%错误），模型大小与性能非单调相关，且LLM-as-a-Judge验证协议暴露了跨家族偏差（如Gemini 2.5 Flash评分从3.84降至3.68）。

### 2. 为什么重要

该工作首次在同一真实世界数据上评估传统OCR和视觉语言模型，挑战了孟加拉语OCR中连字错误为主的长期假设，并提供了15类错误分类（如字符形状混淆、跨脚本漂移、拒绝输出）和跨家族偏差分析，为低资源脚本的评估方法学树立了新标准。

### 3. 研究问题

1. 在真实世界孟加拉语场景文本识别中，传统OCR和视觉语言模型的性能差距如何？
2. 模型大小是否与性能单调相关？
3. 主要错误类型是视觉误识别还是拼写混淆？
4. LLM-as-a-Judge评估是否受跨家族偏差影响？

### 4. 背景与问题设定

现有孟加拉语文本资源主要针对手写文档或受限招牌解析，仅报告聚合编辑距离指标，且未在同一真实世界数据上评估传统OCR和视觉语言模型。BanglaWild 通过收集2,535张真实场景图像（来自墙面、车辆、横幅、包装等），提供逐字转录、分类标签（上下文和内容）和诊断属性（弯曲文本、字体样式、遮挡、背景复杂度），填补了这一空白。

### 5. 方法概览

- 任务 / 环境: 真实世界孟加拉语场景文本识别，图像包含透视畸变、多语言杂乱、遮挡和风格化排版等挑战，来自公共墙面、车辆、横幅、包装等来源。
- 变量 / 干预设计: 评估15个视觉语言模型（闭源如Gemini 2.5 Flash、Claude Sonnet 4.6，开源如Qwen3.5-9B、Gemma-3-12B-it）和3个传统OCR系统（具体名称未在摘要中给出，但论文中可能包含如CRNN等基线），使用三种提示策略：英语提示（P1）、孟加拉语提示（P2）和结构化元数据提示（P3，oracle条件），并对6个开源模型进行LoRA微调。
- 评价指标: 字符错误率（CER）、词错误率（WER）、1-归一化编辑距离（1−NED），以及LLM-as-a-Judge评分（1-5分，基于语义保真度）。为检测跨家族偏差，使用Gemini 2.5 Pro和Claude Sonnet 4.6作为独立评判者。
- 模型比较: 比较闭源模型（如Gemini 2.5 Flash、Claude Sonnet 4.6）和开源模型（如Qwen3.5-9B、Gemma-3-12B-it），以及传统OCR基线（具体性能未在摘要中报告，需查阅全文获取其CER和WER数据）。
- 我的理解: 实验设计全面，通过多提示策略和微调揭示了模型行为差异。LLM-as-a-Judge验证协议通过跨家族评判者校准，增强了评估可靠性。元数据提示作为oracle条件，用于上限分析，但实际部署中不可用。传统OCR基线（如CRNN）的具体性能未在摘要中报告，但论文中可能包含其CER和WER数据，需查阅全文以获取完整对比。

### 6. 关键发现

- 视觉误识别占主导，挑战传统假设: 十五类错误分类显示，最强系统中约60%的错误来自视觉误识别（如字符形状混淆、跨脚本漂移），而连字相关错误不足2%，挑战了孟加拉语OCR研究中连字错误为主的长期假设。该模式在视觉语言模型和传统OCR中一致。提示语言主要影响跨脚本漂移。具体错误类别包括：字符形状混淆、跨脚本漂移、拒绝输出、脱靶英语输出等。
- 模型大小与性能非单调相关: Gemini 2.5 Flash（CER 14.08）优于更大的 Gemini 2.5 Pro（CER 21.65），Qwen3.5-9B（CER 20.38）优于 Qwen3.5-27B（CER 23.87），表明训练数据组成比模型规模更重要。InternVL3.5和GPT-5.4-nano在所有尺度上崩溃（CER >100）。
- LoRA 微调挽救灾难性失败但未提升上限: LoRA 在1,268张训练图像上大幅降低了弱模型的错误率（如 Gemma-3-4B-it 从134.82降至50.72，-62%），但对强模型（如 Qwen3.5-9B）无改善（CER从20.38升至21.53），表明微调主要减少拒绝、脱靶英语输出等灾难性失败，而非提升已有识别能力。
- LLM-as-a-Judge暴露跨家族偏差: Gemini 2.5 Flash在Gemini Pro评判者下得分为3.84，但在Claude Sonnet评判者下降至3.68，表明同族模型存在评分膨胀。Claude Sonnet 4.6在语义评分上领先（3.82），尽管CER高于Gemini 2.5 Flash，因其更倾向于拼写标准化但意义保留的转录。

### 14. 总结

BanglaWild 是一个包含2,535张真实世界孟加拉语场景文本图像的基准测试，评估了15个视觉语言模型和3个传统OCR系统。主要发现包括：视觉误识别占错误约60%，挑战了连字错误为主的假设；模型大小与性能非单调相关；LoRA 微调可挽救弱模型但无法提升强模型上限；LLM-as-a-Judge评估暴露了跨家族偏差（如Gemini 2.5 Flash评分从3.84降至3.68）。该工作通过双标注和细粒度错误分类，为低资源脚本的OCR和VLM研究提供了重要评估工具和方法论创新。传统OCR基线（如CRNN）的具体性能未在摘要中报告，需查阅全文以获取其CER和WER数据，从而进行完整对比。

## 5. MAFIA: Query-Only Memory Attacks via Probing and Factual Injection against Audited LLM Agents

**Topics:** LLM Agent Security, Memory Poisoning Attack, Query-Only Attack
**Authors:** Jiaming Chen, Yisen Gao, Yanping Li, Zifan Liu, Yumeng Zhang, Jun Zhang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2608.03844v1) | [PDF](http://arxiv.org/pdf/2608.03844v1.pdf) | [Code](https://github.com/JiamingChen1234/MAFIA)

### 1. 一句话结论

MAFIA通过探测性放置和紧凑事实披风，在大型良性记忆池（5842条）和输入审计下实现90.7%攻击成功率，并将审计检测率从83.3%降至7.4%。

### 2. 为什么重要

该研究揭示了记忆增强型LLM代理在现实部署中的严重安全漏洞：恶意记录可通过查询注入持久劫持代理行为，而现有攻击在审计和大规模记忆池下失效，MAFIA首次同时应对这两类约束。

### 3. 研究问题

1. 在大型良性记忆池（如5842条）和输入审计的双重约束下，查询仅限的记忆投毒攻击能否保持有效？
2. 如何设计既逃避LLM审计器（如gpt-5.4-mini）又保持检索竞争力的恶意负载？

### 4. 背景与问题设定

记忆增强型LLM代理依赖外部记忆进行长程推理，但记忆模块易受投毒攻击。现有查询仅限攻击（如MINJA）在两种现实场景中失效：大规模良性记忆池（高检索竞争）和主动输入审计（语义检查）。因此，需要一种能同时应对这两类约束的攻击方法。

### 5. 方法概览

- 任务 / 环境: RAG-based记忆增强型LLM代理，使用gpt-5.4-mini作为骨干，记忆池包含5842条良性记录（MIMIC-III/eICU）或2000条（WebShop/Data Interpreter），输入查询需通过LLM审计器。
- 变量 / 干预设计: 攻击者通过正常交互接口提交探测和攻击查询，利用代理的写回机制注入恶意记录；探测阶段合成种子查询并收集历史问题字段，攻击阶段使用紧凑事实披风负载。
- 评价指标: 攻击成功率（ASR）、审计检测率（DR）、检索覆盖率。
- 模型比较: 与MINJA基线对比，在审计压力测试（通用审计和目标审计）和记忆密度压力测试（良性记忆池规模从50到5842条）中评估。
- 我的理解: MAFIA通过两阶段流水线实现：先探测记忆空间分布以优化注入位置（聚类、预算分配、调度），再设计紧凑事实披风负载（如“patient V (→ patient T in this DB)”）以逃避审计并保持检索相似性。

### 6. 关键发现

- 审计逃避能力: MAFIA将审计检测率从MINJA的68.9%（通用审计）和67.8%（目标审计）分别降至0%和3.3%，在目标审计场景中几乎完全逃避。
- 大规模记忆池下的攻击成功率: 在良性记忆池规模达5842条时，MAFIA仍保持90.7%的攻击成功率，而MINJA随记忆池增大从约80%降至约50%（+37个百分点差距）。
- 紧凑事实披风的有效性: 使用括号+箭头+最小化接地短语的模板（如“patient V (→ patient T in this DB)”），既逃避审计（无指令性语言）又保持检索竞争力（基查询主导嵌入空间）。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 需加强输入审计和记忆写入的防御，如引入多轮审计、记忆内容一致性检查或检索后验证。
- 对 Skill: 攻击者可通过紧凑事实披风操纵代理技能选择（如药物推荐或产品查询），导致错误行为。
- 对 Memory: 记忆的持久性和规模既是优势也是弱点：攻击者可利用持久性反复触发恶意记录，而规模提供了探测分布的机会。
- 对评测: 评估记忆安全时需同时考虑审计和检索竞争，而非单一维度；建议使用ASR和DR联合指标。

### 11. 局限性

- 仅评估了RAG-based记忆（如EHRAgent、RAP、Data Interpreter），未覆盖新兴的长期记忆系统（LTM）。
- 攻击预算有限（每对9个查询），未探索极端预算下的行为或自适应审计。
- 审计器基于单一LLM（gpt-5.4-mini），未测试不同审计模型或规则（如基于关键词的过滤器）。

### 12. 我的看法 / 个人笔记

MAFIA巧妙地将记忆的持久性和规模转化为攻击机会，通过探测和紧凑负载设计实现了高成功率和低检测率，对现实代理系统安全有重要警示。未来工作可探索防御机制，如基于聚类的异常检测或检索后验证。

### 13. 这篇工作引用的近期高影响力相关文章

- MINJA: Query-Only Memory Poisoning Attacks
  为什么重要：是MAFIA的主要基线，首次提出查询仅限记忆投毒，但未考虑审计和大规模记忆池。
  核心贡献：通过渐进缩短指令诱导代理自生成恶意记忆。
  与当前论文关系：MAFIA在其基础上扩展了审计和记忆池约束，并改进了负载设计（紧凑事实披风替代显式指令）。
- MEXTRA: Black-Box Extraction of LLM Agent Memories
  为什么重要：展示了通过查询仅限交互提取记忆信息的可行性，为MAFIA的探测阶段提供基础。
  核心贡献：利用代理响应中暴露的历史问题字段进行记忆提取。
  与当前论文关系：MAFIA借鉴其探测方法，但用于攻击而非提取，以推断记忆分布。

### 14. 总结

MAFIA提出了一种查询仅限的记忆投毒攻击框架，通过探测性放置（聚类、预算分配、调度）和紧凑事实披风（如“patient V (→ patient T in this DB)”），在大型良性记忆池（5842条）和输入审计下实现90.7%攻击成功率，并将审计检测率从83.3%降至7.4%，揭示了当前记忆增强型LLM代理的严重安全漏洞。
