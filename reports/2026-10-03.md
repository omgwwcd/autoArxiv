## 1. Where-OPD: Spatially Guided On-Policy Self-Distillation of MLLMs with Synthetic Scenes

**Topics:** 多模态大语言模型, 自蒸馏, 空间引导, 合成场景, 视觉感知
**Authors:** Sophia Sirko-Galouchenko, Monika Wysoczanska, Andrei Bursuc, Nicolas Thome, Spyros Gidaris
**Venue / Year:** arXiv preprint 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02117v1) | [PDF](http://arxiv.org/pdf/2610.02117v1.pdf) | [Code](https://github.com/sirkosophia/Where-OPD)

### 1. 一句话结论

通过向教师模型提供文本空间引导提示，在合成场景上进行策略自蒸馏，可显著提升多模态大模型在真实世界视觉任务上的表现。

### 2. 为什么重要

该方法无需人工标注或外部教师模型，利用程序化生成的合成场景和空间引导，实现了从合成到真实的跨任务迁移，为提升MLLM的细粒度视觉感知能力提供了一种可扩展且高效的训练范式。

### 3. 研究问题

1. 在MLLM的on-policy自蒸馏中，除了视觉裁剪，能否利用文本空间引导作为特权信息来提升视觉感知能力？
2. 基于合成场景训练得到的空间引导能力能否迁移到真实世界的多种视觉任务上？

### 4. 背景与问题设定

On-policy自蒸馏（OPSD）通过让教师模型获得特权信息来提升学生模型的推理能力，但在多模态大语言模型（MLLM）中的应用尚不充分。现有方法如Vision-OPD依赖图像裁剪，需要人工标注或外部模型，且提升局限于特定任务。本文提出一种新的特权信息形式：文本空间引导，即告知教师与问题相关的视觉元素及其位置，从而在不改变视觉输入的情况下，引导学生模型学会定位和整合多区域证据。

### 5. 方法概览

- 任务 / 环境: 使用程序化生成的合成场景，包含彩色几何形状（7种形状、12种颜色），每个场景有12-40个对象，背景和对象属性随机变化。任务为计数问题，例如“有多少个绿色十字？”。
- 变量 / 干预设计: 学生模型接收图像和问题；教师模型额外接收文本空间引导提示，该提示列出所有相关对象的位置和计数。通过最小化学生与教师预测分布之间的广义Jensen-Shannon散度进行蒸馏，教师模型冻结。
- 评价指标: 在15个基准上评估，包括计数（CountQA）、文档理解（DocVQA、OCRBench）、图表理解（ChartQA、EvoChart）、一般视觉感知（CVBench、BLINK、MME-RealWorld、GQA）、幻觉（HallusionBench、AMBER）以及细粒度理解（V*、HR-Bench 4K/8K、ZoomBench）。
- 模型比较: 与基线模型（Qwen3.5-4B、Qwen3.5-9B、Qwen3-VL-4B）以及现有OPSD方法（Vision-OPD、OPD-V、Imagine-OPD、S2VOPD）进行比较。
- 我的理解: 该方法的核心在于利用合成场景中已知的对象位置信息，构造文本提示作为特权信号，使教师模型能够“看见”证据位置，而学生模型必须学会自己寻找。通过蒸馏，学生模型学会了从图像中定位相关证据，从而提升了在真实图像上的感知能力。

### 6. 关键发现

- 跨任务和跨模型的一致性提升: 在Qwen3.5-4B上，Where-OPD在CountQA、DocVQA、OCRBench、ChartQA、EvoChart等任务上均有提升，平均提升3.23个百分点（在CVBench、V*、ZoomBench、BLINK、HR-Bench、MME-RealWorld上）。在Qwen3.5-9B和Qwen3-VL-4B上分别平均提升1.07和1.29个百分点。
- 合成到真实的迁移: 尽管仅在合成场景上训练，但提升显著迁移到真实世界图像任务，如CVBench、V*、ZoomBench等，表明空间引导蒸馏可诱导通用视觉感知能力。
- 优于视觉裁剪方法: 与Vision-OPD相比，Where-OPD在CountQA上提升2.53点，而Vision-OPD下降10.73点，表明文本空间引导比视觉裁剪更具泛化性。

**Topics:** Text-to-Image Generation, Multimodal Large Language Models, AI Agent

### 4. 背景与问题设定

正负空间是视觉构图的基本原则，要求两个语义概念共享边界，但现有文本到图像模型和MLLM在零样本单次生成中难以实现。该工作提出FaV-A，通过分阶段流程分解任务，逐步实现结构发现和语义细化。

## 3. CARM: Cancellation-Aware Response Masking for LLM Reinforcement Learning

**Topics:** LLM 强化学习, 离策略控制, 序列级掩码
**Authors:** Yafei Zhang, Songshuo Lu, Sicong Liao, Zhi Chen, Yaohua Tang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02039v1) | [PDF](http://arxiv.org/pdf/2610.02039v1.pdf)

### 1. 一句话结论

CARM 通过取 token 对数概率比的绝对值再平均，防止正负漂移相互抵消，从而更准确地过滤离策略响应，提升数学推理和代码生成的性能。

### 2. 为什么重要

在 LLM 强化学习后训练中，策略更新与 rollout 引擎差异导致离策略响应，现有几何平均掩码因符号抵消而失效。CARM 提供理论保证的序列级过滤，显著提升数学与代码任务表现，且不改变 token 级代理损失，易于集成到现有 PPO/GRPO 流程。

### 3. 研究问题

1. 几何平均掩码中，正负对数概率比抵消会如何掩盖策略漂移？
2. CARM 能否在数学推理和代码生成任务上超越现有基线？
3. CARM 的过滤阈值如何解释为 token 级约束？

### 4. 背景与问题设定

LLM 强化学习后训练中，策略更新与 rollout 引擎差异导致离策略响应。现有序列级掩码（如 GeoMean）使用几何平均 token 概率比，但正负对数比可能抵消，掩盖双向策略漂移。CARM 通过取绝对值平均来防止抵消，并证明接受响应满足联合边界。

### 5. 方法概览

- 任务 / 环境: 数学推理（AIME 2024/2025/2026, BeyondAIME）和代码生成（TACO, LiveCodeBench-v6, HumanEval+, MBPP+）
- 变量 / 干预设计: 在 GRPO 训练中，对每个响应计算 CARM 分数（平均绝对对数概率比），若超过阈值则拒绝该响应，不参与梯度更新。
- 评价指标: 数学推理：mean@16；代码生成：pass@1
- 模型比较: 基线包括 Null（无掩码）、IcePop、TRM（信任区域掩码）、GeoMean（几何平均掩码）
- 我的理解: CARM 是一种序列级过滤机制，通过计算每个 token 对数概率比的绝对值平均，避免正负抵消，从而更准确地识别离策略响应。

### 6. 关键发现

- CARM 提升数学推理性能: 在 Qwen3.5-4B 和 9B 上，CARM 的 AIME 平均分分别比 GeoMean 高 1.25 和 3.47 个百分点，BeyondAIME 上分别提升 3.68 和 2.13 个百分点。
- CARM 提升代码生成性能: 在 Qwen3.5-9B 上，CARM 的平均 pass@1 比 GeoMean 高 3.03 个百分点，比最强基线 IcePop 高 2.88 个百分点。
- CARM 提供理论保证: 证明接受响应满足 token 比例带违规的联合边界，阈值具有 token 级解释。

## 4. Counting Moves, Weighing Voices: Bayesian Dialectical Argumentation for Calibrated Multi-LLM Councils under Persistent Adversaries

**Topics:** 多智能体系统, 大语言模型, 贝叶斯推理, 鲁棒性, 校准
**Authors:** Ionel Eduard Stan, Paolo Napoletano
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.02005v1) | [PDF](http://arxiv.org/pdf/2610.02005v1.pdf)

### 1. 一句话结论

提出贝叶斯辩证论证（BDA），将多LLM委员会的对话轨迹转化为带权重的证据，通过推断每个智能体的可靠性实现校准的置信度，并能识别和反转持续对抗性智能体的影响。

### 2. 为什么重要

多LLM委员会在推理任务中日益普及，但其置信度往往未校准且易受持续不可靠智能体影响。BDA提供了一种零额外LLM调用的方法，同时提升校准性和鲁棒性，对构建可信赖的AI系统具有重要意义。

### 3. 研究问题

1. 如何将多LLM委员会的对话轨迹转化为可校准的置信度？
2. 如何识别并削弱持续对抗性智能体对委员会决策的影响？

### 4. 背景与问题设定

现有委员会聚合方法（如多数投票、MoA）的置信度反映的是决策确定性而非正确概率，且无法应对持续对抗性成员。BDA将对话中的类型化动作（提议、挑战、让步）视为带噪声的标注，利用经典标注者模型推断每个智能体的可靠性，从而加权证据。

### 5. 方法概览

- 任务 / 环境: 多LLM委员会在三个回合内就问题（二分类或K分类）进行辩论，每个智能体可提出、挑战或让步于候选答案。
- 变量 / 干预设计: BDA将每个智能体的动作计数为对候选答案的认可或反对，通过Beta先验（或Dirichlet先验）推断可靠性，并计算后验概率。
- 评价指标: 准确率、期望校准误差（ECE，包括等宽和等频分箱）、Brier分数。
- 模型比较: 与多数投票、MoA、Self-MoA、ArgLLMs、逻辑回归堆叠、门控投票、无监督Dawid-Skene EM等基线比较。
- 我的理解: BDA的核心是将对话中的结构化动作视为可量化的证据，通过贝叶斯推断每个智能体的可靠性，从而在聚合时自动降低或反转不可靠智能体的影响。

### 6. 关键发现

- 校准性最优: 在干净环境下，BDA的ECE低至0.016，优于所有零成本聚合方法，且准确率比多数投票提升1.7个百分点。
- 对抗鲁棒性: 面对持续对抗性联盟，BDA通过负权重反转其影响，在二分类和K分类任务上均优于基线，且无需额外LLM调用。
- 理论保证: BDA的决策等价于对数几率加权多数投票，当智能体可靠性低于0.5时权重为负，从而将对抗性认可转化为反证。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: BDA提供了一种轻量级、可解释的聚合机制，可嵌入多智能体系统，提升决策的可靠性和校准性。
- 对 Skill: BDA可视为一种技能，用于从对话中提取可靠证据，适用于需要置信度估计的推理任务。
- 对 Memory: BDA不依赖长期记忆，但可扩展为利用历史对话更新智能体可靠性估计。
- 对评测: BDA的校准性使其成为评估多LLM系统性能的更好指标，尤其在安全关键场景。

### 11. 局限性

- 依赖对话协议的结构化动作，不适用于自由形式对话。
- 需要少量标注数据来拟合先验，且假设智能体可靠性在部署期间稳定。
- 对抗性智能体若在训练后改变行为（如旋转攻击），BDA可能失效。

### 12. 我的看法 / 个人笔记

BDA是一个优雅的框架，将经典标注者模型应用于多LLM对话，解决了校准和鲁棒性问题。其零成本特性使其实用，但依赖结构化协议可能限制其通用性。未来可探索自动提取动作或放宽协议约束。

  核心贡献：通过多个LLM的迭代生成和聚合提高性能。
  与当前论文关系：BDA作为零成本替代方案，提供校准和鲁棒性。
- Self-MoA
  为什么重要：Self-MoA通过自举提高鲁棒性，但依赖额外LLM调用。
  核心贡献：使用单个模型多次采样并聚合。
  与当前论文关系：BDA在零成本下达到类似鲁棒性。

### 14. 总结

BDA通过贝叶斯推断智能体可靠性，将对话动作转化为加权证据，实现了校准的置信度和对抗鲁棒性，在零成本聚合方法中表现最佳。

## 5. Mapping the RAG Landscape: A Four Axis Taxonomy of Efficiency, Defense, Interactivity, and Reasoning

**Topics:** Retrieval-Augmented Generation, Large Language Models, Information Retrieval, Efficiency, Robustness, Interactivity, Reasoning
**Authors:** Meghana Sunil, Shravya V, Shravan Venkatraman, Joe Dhanith PR
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.01936v1) | [PDF](http://arxiv.org/pdf/2610.01936v1.pdf)

### 1. 一句话结论

本文提出一个四轴分类法（效率、防御、交互、推理）来系统梳理RAG领域的最新进展，并指出超越传统检索-生成流水线的关键研究方向。

### 2. 为什么重要

该综述为快速发展的RAG领域提供了结构化视角，帮助研究者理解效率、安全、交互和推理等新兴维度，并识别尚未解决的挑战，为未来研究指明方向。

### 3. 研究问题

1. RAG系统如何在大型异构语料库的推理时间约束下保持高事实准确性，并有效权衡准确性与成本？
2. 外部检索引入的主要漏洞（如语料库投毒、偏见放大、隐私泄露）有哪些，现有防御架构的效果如何？
3. RAG系统在多大程度上能适应不断变化的用户意图和交互历史，哪些机制能平衡个性化与事实准确性？
4. 将检索集成到迭代、步骤条件化的推理流程中，如何提升多跳和知识密集型任务的表现，并防止错误累积？

### 4. 背景与问题设定

大型语言模型（LLM）虽然生成流畅，但受限于静态参数知识，容易产生幻觉。检索增强生成（RAG）通过外部检索将模型输出锚定在可验证的最新信息上，解决了这一问题。然而，现有综述多聚焦于核心架构，忽略了效率、安全、交互和推理等新兴维度。本文旨在填补这一空白，提出四轴分类法，系统梳理2020至2025年间的相关研究。

### 5. 方法概览

- 任务 / 环境: 综述论文，覆盖2020年1月至2025年1月间发表的RAG相关研究，检索来源包括Google Scholar、Semantic Scholar和arXiv，共筛选约780篇文献。
- 变量 / 干预设计: 采用PRISMA 2020原则进行系统综述，通过关键词搜索和引文雪球法（以Lewis et al. 2020、RAPTOR、SELF-RAG、Chat-REC、GenGround等为种子）补充文献，并基于四轴分类法（效率、防御、交互、推理）组织分析。
- 评价指标: 不涉及具体实验，但综述中总结了RAG系统的评估实践，包括检索质量、生成准确性、鲁棒性、用户满意度等指标。
- 模型比较: 比较了Naive、Advanced和Modular RAG架构，并对比了稀疏检索（如BM25）与密集检索（如DPR）的优缺点，以及不同防御机制（如SELF-RAG）和推理增强方法（如GenGround）的差异。
- 我的理解: 该综述通过四轴分类法，将RAG研究从传统的检索-生成流水线扩展到效率优化、安全防御、用户交互和复杂推理等维度，强调了这些维度之间的权衡与协同，为构建更可靠、自适应和透明的RAG系统提供了框架。

### 6. 关键发现

- 四轴分类法: 将RAG研究分为效率、防御、交互和推理四个正交维度，每个维度对应一个研究问题（RQ1-RQ4），并总结了各维度的代表性方法。
- 效率与压缩: 综述了通过上下文压缩、检索重排序和强化学习优化检索策略等方法，以在保持准确性的同时降低推理成本。
- 防御性RAG: 分析了RAG系统面临的语料库投毒、偏见放大和隐私泄露等漏洞，并总结了SELF-RAG、RuleRAG等防御机制。
- 交互与个性化: 探讨了如何利用用户反馈和交互历史来动态调整检索和生成，以提升个性化体验，同时保持事实准确性。
- 复杂推理: 研究了多跳检索和迭代推理方法（如GenGround）在知识密集型任务中的优势，以及如何防止错误累积。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 四轴分类法为设计RAG增强的智能体提供了指导：智能体需在效率、防御、交互和推理之间权衡，例如通过压缩上下文降低延迟，同时利用自我反思机制增强可靠性。
- 对 Skill: 研究者应关注跨维度的技能组合，如将交互反馈用于优化检索策略，或将推理链与防御机制结合，以提升整体系统能力。
- 对 Memory: 效率轴中的压缩和索引技术（如HippoRAG）对记忆管理至关重要，可帮助智能体在有限上下文中存储和检索长期信息。
- 对评测: 现有评估多聚焦于单一维度，未来需开发综合基准，同时衡量效率、安全性、交互质量和推理能力，以全面评估RAG系统。

### 11. 局限性

- 综述覆盖时间截至2025年1月，可能遗漏之后的最新进展。
- 四轴分类法可能无法完全涵盖所有RAG研究方向，如多模态RAG。
- 对防御维度的分析可能受限于现有文献，实际攻击和防御的对抗性动态未充分讨论。

### 12. 我的看法 / 个人笔记

该综述的价值在于将RAG研究从技术细节提升到战略层面，通过四轴分类法揭示了各维度间的张力与协同。未来研究应注重跨维度集成，例如开发同时优化效率和防御的框架，并加强实证评估。此外，交互和推理维度的结合可能催生更智能的RAG系统，值得深入探索。
