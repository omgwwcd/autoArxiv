## 1. MANTA: Multi-Agent Network Topology Adaptation for Self-Evolving Multi-Agent Systems

**Topics:** 多智能体系统, 拓扑自适应, 自演化系统, 大语言模型
**Authors:** Mao-xun Huang, Jerry Wang, Yi-Cheng Lai, Zhengxin Zhang, Claire Cardie, Hen-Hsen Huang
**Venue / Year:** AAAI 2027
**Links:** [Abstract](http://arxiv.org/abs/2607.28527v1) | [PDF](http://arxiv.org/pdf/2607.28527v1.pdf)

### 1. 一句话结论

MANTA 提出了一种在推理时自适应演化多智能体通信拓扑的框架，在五个基准上平均得分 74.0，超过最强基线 5.8 个百分点。

### 2. 为什么重要

现有方法将通信拓扑视为固定设计或离线优化目标，MANTA 首次实现了拓扑在任务执行过程中的在线自改进，将自改进从个体智能体扩展到协作架构本身。

### 3. 研究问题

1. 多智能体系统能否在求解每个任务的同时改进其通信拓扑？
2. 如何利用中间协作轨迹进行实例条件的拓扑变异？
3. 如何跨运行传递拓扑选择经验而不更新模型权重？

### 4. 背景与问题设定

基于大语言模型的多智能体系统通过任务分解、智能体专门化、信息交换和中间验证来提升复杂问题求解能力。然而，现有系统通常将通信拓扑视为固定设计或离线优化目标，在任务执行前就确定了结构。MANTA 旨在解决这一局限，使通信结构能在推理时自演化。

### 5. 方法概览

- 任务 / 环境: 五个基准测试：BrowseComp（信息检索与工具使用）、StableToolBench（工具选择与执行）、PlanCraft（长程规划）、WorkBench（多步工作流）、MATH（数学推理）。使用 Gemma 4 31B 作为骨干模型。
- 变量 / 干预设计: MANTA 包含两层：目标多智能体系统求解任务，编排层选择智能体、通信链路和信息可见性。编排层由 Topology Planner、Trace Auditor 和 Skill Reflector 组成，结合确定性代码进行拓扑验证、智能体运行、消息路由、修复控制和停止决策。
- 评价指标: 成功率（Success Rate），每个基准 30 个问题，重复 3 次独立运行。
- 模型比较: 与单智能体方法（Single Agent、CoT、Self-Consistency、Self-Refine）、静态多智能体工作流（投票、群聊辩论、全连接辩论、编排器变体）以及自适应 MAS 方法（AFlow、ADAS、AgentSquare、MASS）进行比较。
- 我的理解: MANTA 的核心创新在于将拓扑视为可在线演化的对象，通过规划、审计、修复和跨运行记忆实现自改进。其方法设计精巧，将 LLM 的推理能力与确定性代码的可靠性结合，避免了完全依赖 LLM 可能带来的不可控性。

### 6. 关键发现

- MANTA 在五个基准上取得最佳平均性能: MANTA 平均得分 74.0，超过最强基线 ADAS（68.2）5.8 个百分点，并在 PlanCraft 上取得最佳结果（76.7）。
- 初始拓扑规划贡献最大，修复和跨运行经验提供额外增益: 消融实验显示，移除初始拓扑规划导致最大性能下降（从 71.7 降至 57.5），移除拓扑修复降至 60.8，冻结或移除长期剧本导致较小但一致的下降。
- MANTA 使用最少的 token 数: 在评估的多智能体系统中，MANTA 的 token 消耗最低（平均每运行 100,315 token），表明其高效性。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: MANTA 表明多智能体系统的协作架构可以在任务执行过程中自适应演化，这为构建更灵活、更鲁棒的智能体系统提供了新范式。
- 对 Skill: 拓扑自适应可以视为一种元技能，使系统能够根据任务需求和执行反馈动态调整协作策略。
- 对 Memory: 双时间尺度记忆（短期运行内日志和长期跨运行原则）的设计为智能体系统如何积累和复用协作经验提供了有效方案。
- 对评测: MANTA 的 Trace Auditor 仅基于过程信号（而非答案正确性）进行审计，这为评估协作质量提供了新视角，可能减少对最终答案标签的依赖。

### 11. 局限性

- MANTA 的拓扑修复限制为每次运行最多一次突变，可能不足以应对需要多次调整的复杂任务。
- 长期剧本的更新仅基于过程标签（如“程序干净”），未使用基准反馈，可能限制了经验的质量。
- 实验仅使用 Gemma 4 31B 一个骨干模型，未验证在不同模型规模或架构上的泛化性。

### 12. 我的看法 / 个人笔记

MANTA 提出了一种优雅且实用的多智能体拓扑自适应框架，其核心贡献在于将拓扑自改进从离线优化扩展到在线执行。方法设计合理，消融实验充分，性能提升显著。未来工作可探索多次修复、更丰富的经验反馈机制以及跨模型泛化。

### 13. 这篇工作引用的近期高影响力相关文章

### 14. 总结

MANTA 是一个多智能体网络拓扑自适应框架，使通信结构能在推理时自演化。它通过任务条件化初始拓扑规划、协作轨迹审计和有限的结构修复，结合双时间尺度记忆，在五个基准上取得平均 74.0 的得分，超过最强基线 5.8 个百分点。该工作将自改进从个体智能体扩展到协作架构本身，为构建自适应多智能体系统提供了新方向。

## 2. PathView-Bench: Can Multimodal Large Language Models Achieve Fine-grained Multiscale Understanding of Pathology Images?

**Topics:** Multimodal Large Language Models, Computational Pathology, Visual Understanding Benchmark
**Authors:** Zongyi Chen, Yu Liang, Jie Lin, Liansheng Wang
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2607.28318v1) | [PDF](http://arxiv.org/pdf/2607.28318v1.pdf)

### 1. 一句话结论

PathView-Bench 是一个面向病理图像细粒度多尺度视觉理解的新型基准，揭示了现有 MLLM 在定位、计数、空间推理等基础视觉任务上的显著不足。

### 2. 为什么重要

现有病理 MLLM 基准多依赖文本答案正确性，无法评估模型是否真正理解图像内容。PathView-Bench 通过双视野（Region-FOV 和 Slide-FOV）和视觉锚定任务，将评估从“答案正确”转向“证据可追溯”，为构建可信的病理 AI 助手提供了关键评测工具。

### 3. 研究问题

1. 多模态大语言模型在病理图像上能否实现细粒度的多尺度视觉理解？
2. 模型在区域定位、视觉识别、数量估计、空间推理和上下文充分性判断等基础视觉任务上的表现如何？

### 4. 背景与问题设定

病理图像分析中，MLLM 被越来越多地用于全切片分析，但现有基准主要评估最终诊断答案、描述或报告的正确性，忽略了模型是否真正理解多尺度视觉内容。病理图像尺寸巨大，局部细节与全局语义可能差异显著，而现有基准多局限于单一视野，无法评估模型跨尺度的理解能力。因此，需要一种能够衡量视觉推理基础的新基准。

### 5. 方法概览

- 任务 / 环境: 基于 23 个公开病理影像数据集，包含 61,673 张图像和 7,253,526 个标注，覆盖 28 个器官。任务分为 Region-FOV（高分辨率局部区域）和 Slide-FOV（宏观全切片视图）两类视野。
- 变量 / 干预设计: 将原始标注通过确定性规则转换为 14 个 VQA 风格的任务目标，包括区域定位、视觉识别、数量估计、空间推理和视野陷阱（FOV Trap）判断。所有任务均采用程序化评分，避免 LLM 作为评判者。FOV Trap 任务设计为：Region-FOV 陷阱中，模型收到高倍放大图像（如恶性细胞），但被问及器官来源，正确答案为“信息不足”；Slide-FOV 陷阱中，模型收到全切片视图，但被问及细胞级计数，正确答案也为“信息不足”。
- 评价指标: 使用 Dice、Accuracy、F1、MAE、Entity Recall 和 SRR（Sufficiency Response Rate）等指标进行程序化评分。
- 模型比较: 评估了 18 个代表性通用、医学领域和病理专用 MLLM，包括 GPT-4o、LLaVA-Med、PathLLM 等。
- 我的理解: 该基准的核心创新在于将视觉理解任务分解为可程序化验证的子任务，并通过双视野设计覆盖病理诊断中从细胞形态到组织结构的完整推理链条。FOV Trap 任务尤其巧妙，能检测模型是否在信息不足时做出合理判断。

### 6. 关键发现

- 模型在命名视觉类别上表现较好，但在定位、计数和空间推理上显著不足: 所有 18 个模型在分类任务（如器官分类、区域分类）上准确率较高，但在对象定位（Object Grounding）、计数（Object Counting）和空间关系（Spatial Relation）任务上表现大幅下降，表明模型缺乏真正的视觉基础能力。
- 正确的幻灯片级诊断答案可能掩盖基础视觉操作的失败: 通过匹配幻灯片分析发现，即使模型在 Slide-FOV 分类任务上正确（如正确识别器官），其在同一幻灯片上的 Region-FOV 定位或计数任务可能失败（如无法定位肿瘤细胞或错误计数炎症细胞），说明诊断正确性并不保证视觉理解。
- 模型规模增大或病理专用训练并不能一致地缩小视觉基础能力差距: 更大规模的模型（如 GPT-4o）在某些任务上表现更好，但在定位和计数任务上仍存在明显不足；病理专用模型（如 PathLLM）在分类任务上略有优势，但在基础视觉任务上并未显著优于通用模型。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: 病理 AI 助手需要具备跨尺度的视觉基础能力，不能仅依赖语言先验；基准中的 FOV Trap 任务提示系统应具备主动判断信息充分性的能力。
- 对 Skill: 模型在定位、计数和空间推理上的不足表明需要专门训练这些基础视觉技能，而非仅优化分类或生成能力。
- 对 Memory: 多尺度视觉理解可能需要显式的记忆机制来整合局部和全局信息，例如通过注意力或图结构建模跨视野关系。
- 对评测: 未来评估应包含视觉锚定任务，避免仅依赖文本答案；程序化评分可提高可重复性和公平性。

### 11. 局限性

- 基准仅覆盖 28 个器官，可能未包含罕见或特殊病理类型。
- 任务目标基于确定性规则转换，可能无法完全反映真实病理诊断中的模糊性和专家判断。
- 未评估模型在连续多视野推理或交互式诊断场景下的表现。

### 12. 我的看法 / 个人笔记

PathView-Bench 是病理 MLLM 评估的重要进步，其视觉锚定设计直击当前基准的软肋。然而，基准任务仍为静态 VQA，未来可考虑引入动态交互或序列决策任务，以更贴近临床实践。此外，FOV Trap 任务的设计值得在其他领域（如遥感、安防）推广。

### 13. 这篇工作引用的近期高影响力相关文章

- PathVQA
  为什么重要：最早建立病理 VQA 基准之一，但仅基于 patch 图像，缺乏多尺度视野。
  核心贡献：提供病理图像问答数据集，推动 MLLM 在病理领域的应用。
  与当前论文关系：PathView-Bench 在其基础上扩展了双视野和视觉锚定任务，弥补了其缺乏多尺度和视觉基础评估的不足。
- WSI-Bench
  为什么重要：首个全切片级别的病理 MLLM 基准，但主要评估报告生成和问答，未深入视觉基础。
  核心贡献：引入 WSI 级交互和评估，推动病理 MLLM 从 patch 走向全切片。
  与当前论文关系：PathView-Bench 进一步要求模型在 WSI 级别进行定位、计数等基础视觉操作，补充了 WSI-Bench 在视觉基础方面的缺失。
- PathVG
  为什么重要：专注于病理图像视觉定位，但仅限于区域级，未覆盖全切片视野。
  核心贡献：提供区域级定位标注和评估，强调视觉基础。
  与当前论文关系：PathView-Bench 将其定位任务扩展到 Slide-FOV，并增加了计数、空间推理和 FOV Trap 等任务，形成更全面的视觉理解评估。

### 14. 总结

PathView-Bench 是一个面向病理图像细粒度多尺度视觉理解的基准，通过双视野（Region-FOV 和 Slide-FOV）和 14 个视觉锚定任务，系统评估了 18 个 MLLM 在定位、计数、空间推理等基础视觉操作上的能力。结果表明，即使先进模型在分类任务上表现良好，在基础视觉任务上仍存在显著不足，且模型规模或领域专用训练无法一致弥补这一差距。该基准为构建可信的病理 AI 提供了可重复的评估框架。

## 3. Rethinking Inference-Time Scaling in Local Computer-Use Agents: Failure Modes and Compute Tradeoffs

**Topics:** GUI Agent, Inference-time Scaling, Local Computer-Use Agent
**Authors:** Woongkyu Lee, Jungwook Choi
**Venue / Year:** Preprint 2026
**Links:** [Abstract](http://arxiv.org/abs/2607.28573v1) | [PDF](http://arxiv.org/pdf/2607.28573v1.pdf)

### 1. 一句话结论

在本地计算机使用代理中，推理时扩展往往改变失败模式而非提升任务成功率，且收益递减。

### 2. 为什么重要

该研究揭示了在资源受限的本地模型中，推理时扩展的边际效用有限，为设计高效、低成本的本地GUI代理提供了关键指导。

### 3. 研究问题

1. 推理时扩展在本地计算机使用代理中是否有效？
2. 不同扩展维度（上下文、时间、结构、并行）如何影响任务成功率和失败模式？

### 4. 背景与问题设定

本地部署自主计算机使用代理（CUA）对隐私、成本和实用性至关重要，但硬件约束下性能提升困难。近期研究表明推理时扩展可提升前沿CUA性能，但其对资源受限本地模型的效果尚不明确。本文系统研究本地CUA在上下文、时间、结构和并行维度上的推理时扩展行为。

### 5. 方法概览

- 任务 / 环境: OSWorld基准测试，包含361个真实Ubuntu任务（排除8个Google Drive任务），代理仅基于截图操作，无辅助接口。
- 变量 / 干预设计: 评估四种扩展维度：上下文扩展（历史截图数H∈{0,1,4,8}）、时间扩展（最大步数S∈{15,50,100}）、结构分解（单代理 vs. 两阶段代理）、并行扩展（候选计划数P）。
- 评价指标: 任务成功率、每任务平均步数、提示令牌使用量。
- 模型比较: 单代理：Qwen3-VL-8B/30B-A3B、UI-TARS-1.5-7B、OpenCUA-7B；两阶段代理：规划器为Qwen3模型，接地器固定为GTA-1-7B。
- 我的理解: 实验设计系统性地覆盖了四种扩展维度，并采用多模型对比，但仅基于OSWorld单一基准，可能限制泛化性。

### 6. 关键发现

- 最小历史是本地代理稳定性的基本前提: 提供单张历史截图（H=1）使成功率从约18%跃升至25%以上，H=4进一步改善，但H=8时收益饱和。
- 历史扩展减少停滞但增加虚假成功: 增加H减少最大步数停滞，但失败模式转向过早虚假成功（代理提前终止但任务未完成），导致H=4后准确率不再提升。
- 时间扩展在有限推理能力下无效: 将最大步数从15增至100，任务成功率几乎不变，但成本线性增长，失败模式从停滞转向虚假成功。

## 4. ScaFE: Data-Efficient Scar Classification with LLM-Generated Clinical Feature Programs

**Topics:** 计算机视觉, 医学图像分类, 大语言模型, 特征工程, 程序合成
**Authors:** Ruman Wang, Hangting Ye
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2607.28538v1) | [PDF](http://arxiv.org/pdf/2607.28538v1.pdf)

### 1. 一句话结论

ScaFE 利用 LLM 生成可执行的 Python 特征程序，在留一医院验证中达到 81.0% 平衡准确率，比最强基线 BiomedCLIP 高 10.0 个百分点，且仅用 10% 数据时优势扩大至 11.8 个百分点。

### 2. 为什么重要

该方法解决了医学图像分类中专家标注稀缺、跨医院采集差异大以及直接使用 VLM 存在的隐私和可审计性问题，通过将 LLM 知识转化为确定性本地代码，实现了数据高效、可解释且可复现的临床决策支持。

### 3. 研究问题

1. LLM 能否在不观察患者图像或做出最终诊断的情况下，为数据高效的医学图像分类贡献临床知识？
2. 如何将 LLM 的临床知识转化为确定性、可执行且可审计的局部特征程序，而不是直接进行图像诊断？

### 4. 背景与问题设定

瘢痕疙瘩和增生性疤痕的临床照片分类面临两大挑战：一是专家标注数据有限且跨医院采集差异大（如相机、光照、肤色等变化），二是直接使用 VLM 诊断存在隐私风险（需传输图像）、结果难以复现和审计（黑箱决策）。现有端到端图像模型（如 ResNet、BiomedCLIP）数据依赖性强，而直接 VLM 诊断（如 Shiraishi 等 2024 年研究）准确率低。ScaFE 旨在通过 LLM 生成可执行的特征程序，在本地进行确定性测量，从而分离知识提供、特征计算和分类决策三个角色。

### 5. 方法概览

- 任务 / 环境: 基于 600 张来自三家医院的去标识临床照片（每院 200 张，各含 100 例 KD 和 100 例 HS），采用留一医院交叉验证，每折以 80% 开发数据拟合、20% 验证，测试集完全密封。
- 变量 / 干预设计: ScaFE 框架：LLM 通过联网检索临床证据（如 VSS、POSAS 指南），生成候选 Python 特征程序（测量颜色、纹理、边界等属性）；程序在受限本地环境执行（无网络、文件、标签访问），仅返回聚合验证统计（如混淆矩阵、平衡准确率、无效/常数特征率）和全局 SHAP 重要性；通过多轮迭代（T 轮，每轮 M 个候选）修复和精炼，最终选择最优程序并训练固定配置的随机森林分类器。
- 评价指标: 主要指标为站点宏平均平衡准确率（site-macro balanced accuracy），同时报告宏 F1、AUROC、灵敏度、特异度、Brier 分数和期望校准误差。
- 模型比较: 与经典特征（手工设计）、监督迁移学习（ResNet-50 微调）、视觉基础模型（BiomedCLIP、DINOv2）和直接 VLM 推理（GPT-4V）等基线比较。ScaFE 在平衡准确率上达到 81.0%，比最强基线 BiomedCLIP 高 10.0 个百分点。
- 我的理解: ScaFE 的核心创新在于将 LLM 作为知识驱动的特征工程师，而非直接诊断者。通过生成可执行的 Python 代码，将临床概念（如色素沉着、血管分布）转化为可测量的视觉属性，并在本地执行，既保护了数据隐私，又保证了结果的可审计性和可复现性。迭代精炼机制通过聚合反馈（仅统计信息，无图像级细节）逐步提升程序质量，最终随机森林在低维结构化特征上学习决策边界。

### 6. 关键发现

- ScaFE 在跨医院泛化上显著优于所有基线: 在留一医院交叉验证中，ScaFE 达到 81.0% 的站点宏平均平衡准确率，比最强基线 BiomedCLIP（71.0%）高出 10.0 个百分点，且优于其他基线如 ResNet-50 微调（65.2%）和直接 VLM 推理（58.3%）。
- ScaFE 在数据极少时仍保持高准确率: 仅使用 10% 的开发数据（40 张图像）时，ScaFE 仍保持 72.0% 的平衡准确率，领先 BiomedCLIP 11.8 个百分点，展示了卓越的数据效率。
- 迭代精炼显著提升程序可执行性和证据基础: 经过多轮精炼，程序可执行率从 66.7% 提升至 95.0%，最终特征中 91.7% 具有可验证的临床证据支持（通过证据门控过滤），且所有保留特征均 100% 覆盖证据。

- 对 Agent 系统: ScaFE 展示了 LLM 作为知识工程师而非直接决策者的潜力，可启发设计更安全、可审计的 AI 辅助诊断系统，其中 LLM 负责知识提取和代码生成，而本地系统负责执行和决策。
- 对 Skill: 该方法将临床知识转化为可执行代码，有助于标准化和传播专家技能，降低对稀缺专科医生的依赖，尤其适合基层医疗机构。

### 11. 局限性

- 仅针对疤痕分类任务验证，泛化到其他医学图像任务（如皮肤病、放射学）需进一步研究。
- 依赖 LLM 的临床知识检索和代码生成能力，LLM 的偏见或错误（如检索不准确、代码逻辑缺陷）可能影响特征质量，尽管迭代精炼可缓解。

- 仅使用随机森林作为下游分类器，未探索其他轻量级模型（如逻辑回归、SVM）的适用性。
