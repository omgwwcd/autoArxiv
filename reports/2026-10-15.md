## 1. STP-GUI: Spatially-Aware Token Pruning for Efficient Web-GUI Agents

**Topics:** GUI Agent, Token Pruning, Vision-Language Models, Efficiency
**Authors:** Shuo Wang, Sifan Zhou, Xiaobo Wang, Tianyu Fu, Chenxu Zhao, Anyang Su, Hanning Wang, Ping Jiang, Minghui Wu
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.20390v1) | [PDF](http://arxiv.org/pdf/2610.20390v1.pdf)

### 1. 一句话结论

STP-GUI 通过空间感知的窗口级 token 剪枝，在保留 GUI 元素局部结构的同时，显著降低推理开销，在低 token 预算下保持较高任务成功率。

### 2. 为什么重要

Web-GUI 代理依赖高分辨率截图，导致视觉 token 数量庞大，推理延迟高。现有剪枝方法忽略 GUI 元素的空间连续性，容易破坏关键证据。STP-GUI 提出解耦评分与选择粒度，实现高效且性能损失小的剪枝，对实际部署具有重要意义。

### 3. 研究问题

1. 如何在不破坏 GUI 元素空间结构的前提下进行视觉 token 剪枝？
2. 如何设计轻量级选择器，在冻结 VLM 的情况下通过策略学习优化剪枝策略？

### 4. 背景与问题设定

视觉语言模型（VLM）驱动的 Web-GUI 代理通过截图进行交互，但高分辨率输入和交互历史导致视觉 token 数量巨大，推理开销高。现有 token 剪枝方法多针对自然图像，独立选择 token，可能破坏 GUI 中按钮、图标等小元素的空间连续性。因此，需要一种既能保留局部结构又能高效剪枝的方法。

### 5. 方法概览

- 任务 / 环境: Web 和移动 GUI 环境，包括 Online-Mind2Web（实时网站任务）和 Android in the Wild（移动界面任务）。
- 变量 / 干预设计: STP-GUI 使用轻量级指令条件评分器生成 token 级重要性分数，然后在空间窗口内聚合分数，通过 Plackett-Luce 策略学习选择完整窗口，保留空间连续性。
- 评价指标: 任务成功率（SR）和相对全 token 模型的性能保持率（ACC），同时报告推理延迟和 FLOPs 减少。
- 模型比较: 与 HiPrune、FlashVLM、PDrop、IVC 和 Attention 等剪枝方法比较，在相同或不同保留率下评估。
- 我的理解: STP-GUI 的核心在于将 token 评分和选择粒度解耦：评分是细粒度的，选择是窗口级的，从而兼顾局部重要性和空间完整性。训练时使用策略梯度优化选择器，推理时贪心选择高分窗口。

### 6. 关键发现

- 效率与性能的平衡: 在 Online-Mind2Web 上，STP-GUI 在 21% token 保留率下达到 0.290 的成功率，保留全 token 性能的 77.7%，同时减少 57% FLOPs 和 31% 延迟。
- 跨领域泛化: 在 Android in the Wild 上，STP-GUI 在 50% 保留率下显著优于 Attention 基线（General 0.741 vs 0.338），表明方法可迁移至移动 GUI 环境。

- 图来源: 图 1：STP-GUI 与现有剪枝方法的对比示意图
- 为什么重要: 该图直观展示了 STP-GUI 如何通过窗口级选择保留完整 GUI 元素，而现有方法可能产生碎片化 token，导致信息丢失。

### 8. 如何读这张图

图中对比了不同剪枝策略在 GUI 截图上的效果：现有方法（如 Attention）可能只保留零散 token，而 STP-GUI 选择连续窗口，覆盖完整按钮或图标，从而保留局部语义。

### 9. 次重要图

- 为什么也重要: 图 2 展示了 STP-GUI 的整体流程，包括评分、窗口聚合和策略学习，有助于理解方法的具体实现。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: STP-GUI 可显著降低 GUI 代理的推理延迟，使其更适合实时交互场景，同时保持较高的任务成功率。
- 对 Skill: 该方法不依赖特定 VLM 架构，可作为一种通用剪枝模块，提升代理在资源受限环境下的可用性。
- 对 Memory: 通过减少视觉 token 数量，降低 KV 缓存和内存占用，支持更长的交互历史或更大批次的处理。
- 对评测: 为 GUI 代理的效率评估提供了新指标（如 ACC），并展示了在低 token 预算下性能保持的重要性。

### 11. 局限性

- 仅在 Qwen3-VL 上验证，未测试其他 VLM 架构的泛化性。
- 剪枝策略依赖训练数据，可能对未见过的界面布局适应性有限。
- 未与最新的自适应剪枝方法（如基于强化学习的动态预算）进行对比。

### 12. 我的看法 / 个人笔记

STP-GUI 提出了一种实用的 token 剪枝方案，通过空间窗口保留 GUI 元素结构，在效率和性能之间取得良好平衡。未来可探索动态窗口大小或与自适应预算结合，进一步提升灵活性。

### 14. 总结

STP-GUI 是一种针对 Web-GUI 代理的空间感知 token 剪枝方法，通过解耦 token 评分与窗口选择，在冻结 VLM 的情况下训练轻量级选择器。实验表明，在低 token 预算下，STP-GUI 能保持较高任务成功率，并显著降低推理开销，且能泛化到移动 GUI 环境。

## 2. Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents

**Topics:** 软件工程, AI Agent, 基准测试
**Authors:** Yuyao Ge, Shenghua Liu, Peizhong Gao, Chendi Ge, Chenxu Liu, Yiwei Wang, Lingrui Mei, Baolong Bi, Jiayu Yao, Jiafeng Guo, Xueqi Cheng
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.20344v1) | [PDF](http://arxiv.org/pdf/2610.20344v1.pdf)

### 1. 一句话结论

Doc2Harness 首次以确定性基准测试直接评估 LLM 在长时程编码智能体框架工程中的能力，发现最强模型 GPT-6 Astra 的通过率仅为 53.05%，且失败集中在跨模块功能拆分上。

### 2. 为什么重要

随着 LLM 驱动的编码智能体在复杂任务中的部署，智能体框架（harness）本身的质量对最终性能至关重要。现有基准测试在固定框架下评估下游任务，忽略了框架工程这一关键环节。Doc2Harness 填补了这一空白，为衡量和提升 LLM 的框架工程能力提供了首个确定性基准，对递归自我改进和智能体系统的发展具有重要意义。

### 3. 研究问题

1. LLM 在长时程框架工程任务中的表现如何？
2. 不同模型在框架工程上的能力差异有多大？
3. 框架工程中的常见失败模式是什么？

### 4. 背景与问题设定

现有基准测试（如 SWE-bench Pro）在固定框架下评估 LLM 完成下游任务的能力，但框架本身的设计和实现（如工具调用、权限管理、会话状态等）对智能体性能影响巨大。然而，框架工程本身未被系统评估。Doc2Harness 提出两阶段基准：第一阶段，构建模型在固定构建框架（OpenCode）中根据开发文档和接口骨架构建候选框架；第二阶段，用模拟模型驱动候选框架，通过四个可观察通道（请求、文件、退出码、命令输出）评估其行为正确性，并引入阳性对照防止虚假通过。

### 5. 方法概览

- 任务 / 环境: 隔离容器环境，构建阶段使用 OpenCode 作为固定构建框架，评估阶段每个测试用例在独立容器中运行。
- 变量 / 干预设计: 两阶段设计：构建阶段（模型根据文档和骨架生成框架）和评估阶段（模拟模型驱动框架，检查行为）。
- 评价指标: 通过率（pass rate），基于四个通道的断言和阳性对照。
- 模型比较: 评估了 19 个前沿模型，每个模型构建 3 个候选框架，计算平均通过率。
- 我的理解: 该方法将框架工程视为一个可测试的软件工程任务，通过黑盒测试评估框架的功能正确性，避免了直接评估代码质量的复杂性。

### 6. 关键发现

- 模型间性能差距显著: 最强模型 GPT-6 Astra 通过率为 53.05%，最弱模型为 27.44%，差距约 26 个百分点，表明基准具有区分度。
- 失败集中在跨模块功能拆分: 分析发现，得分较高的候选框架倾向于将跨切功能放在更少的模块中，而失败案例往往在模块间接口处理上出现问题。
- 模型排名在不同类别上波动: 模型在六个主要类别上的排名变化可达 16 位，说明不同模型在不同功能领域的表现差异较大。

## 3. Co-Evolving Acting and Forecasting for Language Agents

**Topics:** GUI Agent, 语言智能体, 强化学习
**Authors:** Haofei Yu, Yixing Chen, Yining Zhao, Xuyan Ye, Yuxiang Liu, Zhigang Hua, Yan Xie, Shuang Yang, Jiaxuan You
**Venue / Year:** 预印本
**Links:** [Abstract](http://arxiv.org/abs/2610.20597v1) | [PDF](http://arxiv.org/pdf/2610.20597v1.pdf) | [Code](https://github.com/ulab-uiuc/CoPE)

### 1. 一句话结论

COPE通过共享骨干网络同时优化策略与多步动作预测，利用成功轨迹的后续动作作为辅助监督，显著提升语言智能体的样本效率与性能。

### 2. 为什么重要

长程任务中强化学习采样成本高昂，而现有方法未能充分利用中间步骤的监督信息。COPE引入多步动作预测目标，在不增加推理开销的前提下，通过时间集成提升策略学习效率，为语言智能体的高效训练提供了新思路。

### 3. 研究问题

1. 如何利用成功轨迹中的中间动作序列作为额外监督信号，提升语言智能体的强化学习样本效率？
2. 多步动作预测与策略优化共享参数时，如何实现两者的协同进化并避免干扰？

### 4. 背景与问题设定

训练语言智能体进行长程任务时，强化学习（如GRPO）仅依赖终端稀疏奖励，中间步骤的监督信息被浪费。现有工作通过价值目标（估计每步成功概率）或观测目标（预测下一步观测）来利用中间监督，但前者因共享最终结果而缺乏步骤特异性，后者因观测噪声大且仅覆盖单步而效果有限。

### 5. 方法概览

- 任务 / 环境: 五个基准：ALFWorld、ScienceWorld、WebShop（模拟环境）以及τ²-bench、AppWorld（真实应用），均为稀疏奖励的长程任务。
- 变量 / 干预设计: 在GRPO基础上，增加多步动作预测损失（LAF），仅在成功轨迹上训练，预测当前历史之后的K步动作序列（K>0），并与GRPO损失加权联合优化。
- 评价指标: 任务成功率（或任务得分）以及样本效率（达到特定性能所需的训练步数）。
- 模型比较: 与GRPO基线、观测预测基线（ECHO、RWML）比较，并分析不同K值的影响。
- 我的理解: COPE的核心在于将成功轨迹中的动作序列作为“事后”目标，通过共享骨干网络让预测任务与策略优化相互促进，形成隐式时间集成，从而在不改变推理行为的情况下提升策略质量。

### 6. 关键发现

- 性能提升: 在五个基准上，COPE的聚合性能优于GRPO和带预测辅助目标的RL基线，在真实应用（τ²-bench和AppWorld）上也取得整体改进。
- 样本效率提升: 在ScienceWorld上，COPE相比ECHO和GRPO分别实现了高达1.9倍和2.0倍的样本效率提升。
- 低开销: 在ScienceWorld上，动作预测仅增加约11%的训练时间，且由于更短的rollout，端到端步时间反而减少9%；推理时无额外开销。

## 4. PhySGA: A Physics-Space Grounded Agentic Framework for Generalizable and Interactive 3D Composition

**Topics:** 3D object composition, physical intelligence, agentic framework, physics simulation, LLM/VLM agents
**Authors:** Weichen Lyu, Chong Xia, Mingyu Dong, Long Xu, Shengjun Zhang, Yueqi Duan
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.20560v1) | [PDF](http://arxiv.org/pdf/2610.20560v1.pdf) | [Code](https://agenticei.github.io/PhySGA-page/)

### 1. 一句话结论

PhySGA通过将3D组合任务锚定在物理空间中，利用前馈-反馈双智能体架构和自进化技能库，实现了复杂3D物体组合的通用、可交互且物理可信的组装。

### 2. 为什么重要

该工作突破了以往依赖静态先验（语言或扩散模型）进行3D组合的局限，将物理模拟作为核心反馈信号，使AI智能体能够处理需要交互式构建的复杂任务（如精确悬挂、重力沉降、隐藏包含），为评估和增强基础模型的物理智能提供了新范式。

### 3. 研究问题

1. 如何让AI智能体在物理空间中通过交互式探索完成复杂的3D物体组合？
2. 如何利用物理模拟反馈来纠正大语言模型/视觉语言模型在空间推理上的不足？

### 4. 背景与问题设定

3D物体组合是数字内容创作和机器人仿真的关键，也是检验基础模型物理智能的试金石。现有方法要么用LLM直接预测坐标，要么用扩散模型生成合成图像来指导对齐，但都依赖静态先验，难以处理需要全局规划、精细对齐和物理模拟的复杂组合（如悬挂、沉降、隐藏包含）。

### 5. 方法概览

- 任务 / 环境: 在Isaac Sim物理仿真环境中，给定自然语言指令和两个独立的3D资产（刚体、铰接体、可变形体），目标是构建物理上可实现的组合。
- 变量 / 干预设计: 采用前馈-反馈架构：Assembly Agent负责全局规划和粗调（基于度量），Critic Agent负责基于模拟反馈的细调（基于像素）。Action Routers将语义决策转换为可执行的物理命令（几何、铰接、速度）。Self-Evolving Skill Library存储历史经验，避免重复错误。
- 评价指标: 关系保真度（relation fidelity）、物理合理性（physical plausibility）、视觉质量（visual quality），以及成功率（success rate）和探索次数（exploration attempts）。
- 模型比较: 与现有方法（如直接LLM预测、扩散先验方法）在Isaac Sim中进行对比，PhySGA在各项指标上显著超越。
- 我的理解: 该框架的核心创新在于将物理模拟作为闭环反馈，让智能体在仿真中试错并修正，而不是一次性预测最终位姿。这类似于人类组装物体时的“尝试-调整”过程，通过前馈规划提供初始猜测，再通过反馈修正达到物理稳定。

### 6. 关键发现

- 物理空间锚定优于静态先验: 在Isaac Sim中的实验表明，PhySGA在关系保真度、物理合理性和视觉质量上显著优于现有方法，尤其是在复杂组合任务上。
- 前馈-反馈架构有效: Assembly Agent的粗调和Critic Agent的细调结合，能够处理需要精确对齐的任务，如将杯子挂在挂钩上，通过像素级修正实现物理稳定。
- 自进化技能库提升效率: 通过蒸馏历史经验，PhySGA在后续任务中减少了探索次数，提高了成功率，表明经验重用对智能体学习物理交互至关重要。

## 5. PerSo: Investigating Facets of LLMs' Social Intelligence in Real-World Persuasion Scenarios

**Topics:** cs.CL, cs.AI, cs.SI
**Authors:** Ali Zamani, Soroush Esfahanian, Erfan Shahabi, Mohammad Taher Pilehvar, Azadeh Shakery, Yadollah Yaghoobzadeh
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2610.20548v1) | [PDF](http://arxiv.org/pdf/2610.20548v1.pdf)

### 1. 一句话结论

PerSo基准利用真实Reddit说服对话，同时评估LLM的认知与行为社会智能，发现最强模型在行为任务上略超人类最佳，但在认知任务上仍落后。

### 2. 为什么重要

现有社会智能基准多基于合成场景且孤立评估认知或行为方面，PerSo首次在真实世界说服对话中联合评估两者，为构建更贴近实际的人机交互和多智能体系统提供了更可靠的评测工具。

### 3. 研究问题

1. LLM在真实世界说服场景中的认知社会智能（推断信念、情感、意图）表现如何？
2. LLM在真实世界说服场景中的行为社会智能（选择有效说服策略）表现如何？
3. 模型规模、推理能力等因素如何影响这两方面的社会智能？

### 4. 背景与问题设定

社会智能对LLM在人际交互和多智能体环境中的应用至关重要，包含认知智能（推断他人心理状态）和行为智能（基于推断选择适当行动）。说服是同时涉及两者的自然测试场景，但现有基准要么使用合成数据，要么只评估单一维度。PerSo基于Reddit ChangeMyView社区的真实对话，通过LLM辅助管道构建任务，并用人工标注验证，旨在填补这一空白。

### 5. 方法概览

- 任务 / 环境: 使用Reddit ChangeMyView社区的真实说服对话，筛选出872个合格线程，随机抽取200个构成最终数据集。每个线程包含原始帖子、成功说服者和未成功说服者的回复，以及原帖者的后续回复。
- 变量 / 干预设计: 设计两个任务：行为智能任务要求模型从两个候选回复中选择更可能成功说服原帖者的一个；认知智能任务要求模型预测原帖者在看到说服者回复后的信念、情感和意图（多选题）。
- 评价指标: 行为任务使用选择准确率（正确识别成功说服回复的比例）；认知任务使用多选题准确率（正确预测心理状态的比例）。
- 模型比较: 评估了多个开源和闭源LLM，包括Gemma、Qwen、DeepSeek、Claude和Gemini系列，并比较了不同规模、推理/非推理变体。同时招募了三名人类参与者进行相同任务作为参考。
- 我的理解: 该方法通过真实对话数据，将认知和行为社会智能的评估统一在同一数据集上，避免了合成场景的偏差。行为任务通过对比成功与失败的说服回复，直接测试模型选择有效社交行动的能力；认知任务则要求模型在未见后续回复的情况下预测心理状态，更贴近实际交互中的实时推断。

### 6. 关键发现

- 模型规模与行为智能正相关: 在Gemma和Qwen系列中，模型规模越大，行为任务准确率越高。例如Gemma从4B的60.5%提升到27B的71%。
- 最强开源模型接近闭源模型: Qwen-3.5-397B在行为任务上达到72.5%，与Claude-4.5-Sonnet并列最高，略超人类最佳（65%）。
- 认知任务上人类仍领先: 最佳模型Gemini-2.5-Pro在认知任务上准确率为85%，而人类最佳为85%，但模型在情感和意图维度上仍低于人类。
- 推理能力对行为智能有影响: Qwen-3.5-32B在推理模式下行为准确率从67.5%提升到72%，但认知任务上推理模式反而略有下降。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: PerSo为多智能体系统中的社交智能评估提供了真实场景基准，有助于开发更擅长说服和协作的智能体。
- 对 Skill: 行为智能任务可用来训练和评估模型的说服策略选择能力，认知任务则有助于提升模型对用户心理状态的实时推断能力。
- 对 Memory: 认知任务要求模型基于对话历史预测未来心理状态，这需要模型有效利用上下文信息，与记忆机制相关。
- 对评测: PerSo提供了一种联合评估认知和行为社会智能的方法，可作为标准测试集，推动社会智能研究的发展。

### 11. 局限性

- 数据集仅来自Reddit单一社区，可能无法代表所有说服场景。
- 认知任务的多选题可能简化了真实心理状态的复杂性。
- 人类参与者数量有限（3人），且为计算机科学背景，可能影响泛化性。

### 12. 我的看法 / 个人笔记

PerSo是一个设计精良的基准，通过真实对话数据同时评估认知和行为社会智能，填补了现有研究的空白。其发现表明模型在行为任务上已接近人类，但认知推断仍有差距，这为未来研究指明了方向。不过，数据集规模和多样性有限，未来可扩展至更多平台和场景。
