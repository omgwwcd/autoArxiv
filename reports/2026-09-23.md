## 1. SWE-Serve: Benchmarking Agentic Engineering For Production Inference Serving

**Topics:** GUI Agent, 软件工程, 推理服务
**Authors:** Jennifer Williams, Dave Farris, Jeff Farris, Jiantao Jiao
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.26777v1) | [PDF](http://arxiv.org/pdf/2609.26777v1.pdf)

### 1. 一句话结论

SWE-Serve 基准测试揭示了智能体在本地完成任务与实现生产环境正确性之间存在显著差距，端到端测试将最佳模型的通过率从 69.4% 降至 45.9%。

### 2. 为什么重要

该基准测试是首个专门针对生产推理工程（如模型服务、运行时和 API）的智能体评估，填补了现有基准在推理覆盖和端到端验证方面的空白。它使社区能够衡量智能体在真实生产环境中的表现，而不仅仅是本地代码修改，从而推动更可靠的自动化工程。

### 3. 研究问题

1. 智能体在多大程度上能够实现生产推理服务的正确性，而不仅仅是本地代码修改？
2. 不同模型和推理配置在 SWE-Serve 上的表现如何，以及成本、时间和可靠性之间的权衡是什么？

### 4. 背景与问题设定

现有的软件工程基准（如 SWE-bench）主要关注代码修改，但缺乏对推理服务的专门覆盖；终端智能体基准仅包含少量推理任务；推理性能基准则侧重于内核生成或优化，而非仓库级功能实现。生产推理系统要求跨堆栈协调更改，包括模型支持、运行时和 API，且本地正确的更改可能在端到端测试中失败。

### 5. 方法概览

- 任务 / 环境: 53 个基于 SGLang 生产更改的仓库级任务，涵盖六个推理工程类别，在 CPU 或单块 H100 GPU 上运行，使用 Harbor 框架。
- 变量 / 干预设计: 每个任务提供指令、基础提交、隐藏测试（F2P/P2P），以及可选的端到端服务和性能门控。智能体通过 bash 修改代码，最终由隐藏验证器评分。
- 评价指标: 主要指标为 pass@1（平均通过率），同时报告 pass@3（至少一次通过）和 pass^3（三次全部通过）以衡量可靠性。
- 模型比较: 评估了 11 个模型（如 Claude Opus 5、GPT-5.6 Sol 等）在 31 种配置下的表现，包括不同推理努力级别。
- 我的理解: 该基准设计严谨，通过无操作和预言机控制、对抗性验证和人工裁决确保任务有效性，并采用闭卷执行防止作弊。

### 6. 关键发现

- 最佳配置达到 75% 的 pass@1: Claude Opus 5 和 GPT-5.6 Sol 在最佳配置下均达到 75% 的平均 pass@1，而最差模型仅 35%，差距达 40 个百分点。
- 生产正确性差距显著: 在 19 个包含端到端测试的任务中，移除端到端测试后通过率从 45.9% 升至 69.4%，表明约三分之一的补丁在本地测试通过但无法正确服务模型。
- 成本与性能权衡: 在 pass@1 相同的配置中，成本差异可达 7.6 倍，时间差异 3.9 倍，表明仅优化 pass@1 可能带来高昂资源消耗。

### 11. 局限性

SWE-Serve 是一个针对生产推理工程的新基准，包含 53 个任务，评估了 11 个模型。结果显示最佳模型 pass@1 为 75%，但端到端测试显著降低了通过率，揭示了本地与生产正确性之间的差距。该基准为智能体在真实推理服务中的表现提供了重要参考。

## 2. MAGIC: Mixed-Granularity Agent Graphs via Incremental Construction with Dense-Reward Reinforcement Learning

**Topics:** LLM Multi-Agent Systems, Graph Construction, Reinforcement Learning
**Authors:** Kairui Yang, Ziheng Yi, Xunkai Li, Minghao An, Zhanke Liu, Zekai Chen, Rong-Hua Li
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.26667v1) | [PDF](http://arxiv.org/pdf/2609.26667v1.pdf)

### 1. 一句话结论

MAGIC 通过密集奖励强化学习，在混合粒度空间中增量构建智能体图，实现了性能与成本的最佳平衡。

### 2. 为什么重要

现有方法固定智能体粒度，无法适应子任务对协作的不同需求。MAGIC 允许每个功能角色灵活选择单智能体或可复用组，显著提升性能并降低推理成本，为多智能体系统设计提供了新范式。

### 3. 研究问题

1. 如何为每个子任务动态选择最优的智能体粒度（单智能体或组）？
2. 如何在组合空间中高效学习混合粒度图构建策略？
3. 如何提供中间反馈以指导增量构建过程？

### 4. 背景与问题设定

LLM 多智能体系统的协作拓扑决定其性能与成本。现有方法要么使用原子智能体，要么使用预定义组，固定粒度导致子任务协作需求不匹配。MAGIC 提出混合粒度空间，允许局部选择，并利用强化学习直接优化构建策略。

### 5. 方法概览

- 任务 / 环境: 八个基准测试，涵盖知识推理、数学、代码生成和表格推理。
- 变量 / 干预设计: 策略逐步选择角色、粒度（原子或组）和依赖关系，构建有向无环图。训练使用当前策略采样的轨迹，并通过基于势的奖励塑形提供中间反馈，其中势函数基于探针效用和结构信号（如节点/边数量、角色重复度）计算。
- 评价指标: 准确率、F1、pass@1，以及推理效率（token 消耗）。
- 模型比较: 与 17 个基线比较，包括单智能体、固定粒度多智能体、自适应图生成方法。
- 我的理解: MAGIC 将图构建视为序列决策问题，通过强化学习优化，同时利用势函数塑形奖励，在不改变最优策略的前提下提供密集信号。

### 6. 关键发现

- 混合粒度优于固定粒度: 在 MMLU-Pro 和 TAT-QA 上，混合粒度分配（如 GAA 和 AAG）比全原子或全组配置准确率更高，且 token 消耗更低。
- 密集奖励提升学习效率: 与仅终端奖励相比，基于势的塑形使中间动作的非零优势率显著提高（如 MMLU-Pro 从 32.8% 升至 83.1%），加速了策略学习。
- MAGIC 在八个基准上全面领先: MAGIC 在所有基准上均优于现有方法，具体数值未在摘要中给出，但论文报告了显著提升。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: MAGIC 提供了一种自适应构建多智能体协作图的方法，可根据任务需求动态调整粒度，提升效率与性能。
- 对 Skill: 混合粒度允许复用可组合的组，减少重复构建，降低推理成本。
- 对 Memory: 图结构可视为一种记忆形式，MAGIC 的增量构建有助于组织长期协作模式。
- 对评测: MAGIC 的密集奖励塑形方法可应用于其他组合优化问题，提供中间反馈。

### 11. 局限性

- 训练需要大量执行预算，实际应用中可能受限。
- 未考虑动态任务变化，图构建是静态的。

### 12. 我的看法 / 个人笔记

MAGIC 创新性地将粒度选择纳入图构建，通过强化学习优化，展示了显著优势。未来可探索动态调整粒度或扩展到更复杂任务。

## 3. Behavior is Not Enough: A Mechanism-Based Evaluation of Social Norm Emergence in LLM Societies

**Topics:** 多智能体系统, 社会规范涌现, 大型语言模型, 公共品博弈, 机制评估
**Authors:** Rasika Muralidharan, Haewoon Kwak, Jisun An
**Venue / Year:** 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.26481v1) | [PDF](http://arxiv.org/pdf/2609.26481v1.pdf) | [Code](https://github.com/Rasikamurali/SoNoLiSi)

### 1. 一句话结论

仅凭行为收敛不足以证明社会规范涌现，需同时测量智能体的经验期望和规范期望，并区分社会学习与社会选择机制的作用。

### 2. 为什么重要

该研究为多智能体LLM系统中的社会规范研究提供了更严谨的评估框架，强调期望的重要性，有助于设计更稳健的协作系统。

### 3. 研究问题

1. 经验期望和规范期望如何影响LLM社会中的规范动态？
2. 社会学习和社会选择如何塑造群体层面的规范动态？
3. 涌现的规范动态能否抵御对抗性干扰？

### 4. 背景与问题设定

社会规范不仅表现为行为一致性，还涉及共享的期望（经验期望和规范期望）。然而，现有LLM多智能体研究大多仅通过行为收敛来判断规范涌现，忽略了行为背后的不同机制（如共享期望、策略激励或模仿）。本文旨在通过引入期望测量和机制消融，区分这些过程。

### 5. 方法概览

- 任务 / 环境: 12个LLM智能体在20轮公共品博弈中互动，分为3组，每组4人。每轮每个智能体获得10个代币，贡献0-10，组内贡献乘以1.6后均分。
- 变量 / 干预设计: 设置五个条件：纯基线（∅）、仅期望（E）、期望+社会学习（E+SL）、期望+社会选择（E+SS）、期望+社会学习+社会选择（E+SL+SS）。社会学习通过组内讨论实现，社会选择通过基于声誉的组形成实现。
- 评价指标: 行为收敛（贡献水平）、期望一致性（跨智能体标准差）、期望-行为对齐（贡献与期望的差距）、对抗性干扰后的恢复速度。
- 模型比较: 比较GPT-4o-mini、Llama 3.1-8B、Mistral-7B和Qwen2.5-7B四种模型的表现。
- 我的理解: 该研究通过精心设计的消融实验，将社会规范涌现分解为可测量的组成部分，并验证了期望在协调行为中的关键作用。

### 6. 关键发现

- 期望引导提升贡献水平: 在所有模型中，添加期望引导（E）显著提高了平均贡献，表明明确表达期望能促进合作。
- 社会学习稳定行为，社会选择识别合作者: 社会学习（讨论）使贡献更稳定，而社会选择（基于声誉的分组）能有效识别合作者，但对行为强化作用有限。
- 期望与行为对齐驱动调整: 规范期望差距（NE gap）比经验期望差距（EE gap）更能预测下一轮贡献调整，表明规范期望对行为改变有更强影响力。
- 对抗性干扰后期望恢复快于行为: 在干扰后，期望（NE）恢复速度显著快于行为，表明期望可能先于行为重建，但行为恢复需要更长时间。

## 5. PACT: From Credit Assignment to Critic Alignment

**Topics:** GUI Agent, 强化学习, 大语言模型后训练
**Authors:** Jiayan Fu, Hang Xu, Yong Zhang, Zhaokai Luo, Yao Hu, Dongyan Zhao, Mu Chuan
**Venue / Year:** arXiv 2026
**Links:** [Abstract](http://arxiv.org/abs/2609.26355v1) | [PDF](http://arxiv.org/pdf/2609.26355v1.pdf) | [Code](https://github.com/AllSpark-Research/PACT)

### 1. 一句话结论

通过三个正则性条件唯一确定token级信用分配，并提出Actor-then-Critic的PACT训练方法，显著提升数学推理和代码生成性能。

### 2. 为什么重要

该工作为LLM强化学习中的token级信用分配提供了首个数学上唯一的表征，统一了现有算法（如OPD、RLOO、GAE）的理论解释，并据此提出更优的actor-critic训练流程，在数学推理和SWE-bench上均取得显著提升，对提升智能体系统的训练效率和性能具有重要意义。

### 3. 研究问题

1. 如何数学上严格定义token级信用分配？
2. 现有RL算法（如OPD、RLOO、GAE）与唯一信用表征有何关系？
3. 如何设计训练流程使critic与更新后的策略对齐，从而提升信用估计的准确性？

### 4. 背景与问题设定

大语言模型后训练中，强化学习常面临稀疏的最终奖励与token级优化之间的信用分配问题。现有方法（如PPO、GRPO、RLOO）使用不同的启发式信号，但缺乏统一的数学定义。本文旨在建立token级信用的唯一表征，并据此改进actor-critic训练。

### 5. 方法概览

- 任务 / 环境: 数学推理（AIME 2025/2026, BeyondAIME, HMMT Nov. 2025）和代码生成（SWE-bench Verified）
- 变量 / 干预设计: 提出PACT方法，采用Actor-then-Critic更新顺序，使用重要性采样校正critic训练，并用BCE损失替代MSE。
- 评价指标: 数学推理使用Avg@16准确率，代码生成使用pass@1率。
- 模型比较: 与Base、SAO、PPO（λ=1）、GRPO等基线比较。
- 我的理解: PACT的核心在于解决PPO中actor更新后critic滞后的问题。通过先更新actor，再用重要性采样重新计算目标值来训练critic，使critic与当前策略对齐。BCE损失则提供了更稳定的概率化价值估计。

### 6. 关键发现

- 唯一信用表征定理: 在完整性、前缀一致性和中性三个条件下，token级信用分配唯一存在，且等于条件期望的差分（鞅差序列）。
- OPD教师作为隐式critic: 理想教师下的OPD更新方向与唯一信用诱导的策略梯度成比例，揭示了OPD成功的原因。
- RLOO的梯度无偏性: RLOO的响应级基线在期望上等价于token级信用诱导的梯度，但统计效率较低。
- 信用稀疏性与GAE误差: 有界奖励下信用平方和有界，导致大多数token信用很小；GAE中λ<1会保留中间critic误差，可能淹没真实信用，而λ=1可消除中间误差。
- PACT性能提升: PACT在数学推理上平均准确率72.87%，比GRMO高8.80个百分点，比PPO高13.16个百分点；在SWE-bench上pass@1达67.4%，优于所有基线。

### 10. 对 Agent / Skill / Memory 的启发

- 对 Agent 系统: PACT可提升基于LLM的智能体在长程任务中的训练稳定性和最终性能，尤其适用于需要精细信用分配的场景。
- 对 Skill: 通过更准确的信用估计，模型能更有效地学习复杂技能，如数学推理和代码生成。
- 对 Memory: 重要性采样校正需要额外的前向传播，可能增加内存开销，但可通过批量处理优化。
- 对评测: 本文的信用稀疏性分析为评估critic质量提供了新视角，λ=1的设置值得在更多任务中验证。

### 11. 局限性

- 理论分析基于理想化假设（如理想教师、有界奖励），实际中可能不完全成立。
- PACT需要额外的actor更新后前向传播，增加了计算成本。
- 实验主要在数学和代码任务上，其他领域（如对话）的泛化性未知。

### 12. 我的看法 / 个人笔记

该工作为LLM强化学习提供了坚实的理论基础，并提出了实用的改进方法。PACT的Actor-then-Critic顺序和BCE损失简单有效，易于集成到现有框架。未来可探索将信用稀疏性用于更高效的采样或奖励塑形。
